折射率的測定（插針法）

課本實驗：在軟木板上的方格紙插大頭針，透過裝水的半圓形透明盒或長方形玻璃磚看針的像，讓針的像排成一直線，找出光走的路徑。再拿走透明塊，畫出光線與法線，用量角器量角度，畫出 sin θ1 對 sin θ2 的圖——斜率就是折射率。

試試看：拖曳眼睛讓 A、B 的像重疊，再從針插拖出 C、D 插在同一條視線上。

    實驗說明

    實驗目的

    1. 觀察光由空氣進入透明物質時的偏折，驗證司乃耳定律。
    2. 用插針法找出光在水、壓克力、玻璃中走的路徑，測出它們的折射率。
    3. 延伸：量長方形透明塊造成的側向位移；用半圓形透明塊找出臨界角。

    實驗器材

    保麗龍板（或軟木板）、方格紙、長的大頭針數支、透明半圓形盒（裝水到半滿）、長方形玻璃磚或壓克力磚、量角器、直尺、圓規、鉛筆。

    原理

    在空氣（\(n \approx 1\)）與折射率 \(n\) 的物質的界面上，空氣中的角 \(\theta_1\) 與物質中的角 \(\theta_2\)（都由法線量起）遵守司乃耳定律：

    \[ \sin\theta_1 = n\sin\theta_2 \] \[ n = \frac{\sin\theta_1}{\sin\theta_2} \]

    插針為什麼有用？我們看到一根針，是看到它射進眼睛的光從哪個方向來。兩根針看起來前後重疊，表示兩者的光沿同一條直線進入眼睛——這條線就是一條真實的光路。所以觀察側的針標出光離開透明塊後的路徑，另一側的針標出光進入前的路徑。光路可逆，光從哪一頭走都一樣。

    半圓形透明盒：讓光射向平面的圓心 \(O\)。折射後的光在盒內沿著半徑走，碰到圓弧時與弧面垂直，不再偏折，所以只需要考慮一次折射。以 \(O\) 為圓心畫半徑 \(R\) 的圓，兩條光線與圓的交點到法線的距離 \(x_1\)、\(x_2\) 直接給出 sin 值，用直尺就能代替量角器：

    \[ \sin\theta_1 = \frac{x_1}{R} \] \[ \sin\theta_2 = \frac{x_2}{R} \] \[ n = \frac{x_1}{x_2} \]

    長方形透明塊：光在上表面 \(L\) 的 \(O\) 點與下表面 \(L'\) 的 \(O'\) 點各折射一次。兩面平行時，塊內的光在兩面的角相同（\(\theta_3 = \theta_2\)），所以射出時 \(\theta_4 = \theta_1\)：出射光與入射光平行，只是往旁邊錯開。塊內的光路長 \(OO' = t/\cos\theta_2\)，側向位移是以 \(\theta_1 - \theta_2\) 為角的直角三角形的對邊：

    \[ \frac{\sin\theta_1}{\sin\theta_2} = \frac{\sin\theta_4}{\sin\theta_3} = n \] \[ d = \frac{t\,\sin(\theta_1 - \theta_2)}{\cos\theta_2} \]

    用全部的數據：因為 \(\sin\theta_1 = n\sin\theta_2\)，以 \(\sin\theta_2\) 為橫軸、\(\sin\theta_1\) 為縱軸作圖，是一條通過原點、斜率為 \(n\) 的直線。過原點的最佳直線（最小平方法）的斜率為

    \[ n = \frac{\sum \sin\theta_1 \sin\theta_2}{\sum \sin^{2}\theta_2}, \qquad \text{百分誤差} = \frac{n_\text{測} - n_\text{公認}}{n_\text{公認}} \times 100\% \]

    臨界角：若光由弧面射入、沿半徑到達 \(O\)，就是從塊內射向平面。只有當 \(\theta_2\) 小於臨界角 \(\theta_c\) 時光才出得去；超過臨界角，光全部反射回塊內：

    \[ \sin\theta_c = \frac{1}{n} \]

    步驟

    半圓形透明盒（裝水）：

    1. 在方格紙上畫直線 L，以及在 O 點與它垂直的法線 N；以 O 為圓心、盒子的半徑畫圓，在左上方的圓周上標出到 N 的距離為 1、2、3、4、5 cm 的五個點。
    2. 把紙鋪在板上，盒子裝水約半滿，直徑的一邊對齊 L、中心對準 O，在 O 點垂直插一根針。
    3. 在第一個點插針。在弧面那一側用單眼透過水看，移動頭的位置直到兩根針重疊，再插第三根針，使它把前兩根都擋住。
    4. 其餘四個點照做。拿走盒子，畫出光線，量 x1、x2（或量角度）。

    長方形玻璃磚：

    1. 畫直線 L，把玻璃磚的長邊靠在 L 上，沿另一個長邊描出 L′。
    2. 在 L 後方近處插針 B，斜後方遠一點插針 A。
    3. 從 L′ 那一側透過玻璃磚看，移動眼睛直到 A、B 的像重疊；在這條視線上插 C、D，使四根針看起來像同一根。
    4. 拿走玻璃磚。延長 AB 交 L 於 O、延長 CD 交 L′ 於 O′，連接 OO′，過 O 畫法線，量 θ1 與 θ2。
    5. B 不動、移動 A 的位置，重做幾次。

    注意事項

    • 針要垂直插。對齊的是透過透明塊看到的下半段；露在透明塊上方的針頭沒有被折射，不會對齊。
    • 用單眼看，眼睛放低、接近紙面。
    • 同一側的兩根針要離遠一點（幾公分）：插歪一點點時，畫出的直線方向誤差比較小。
    • 一次實驗中透明塊不可移動。入射角取約 15° 到 70°：角度太小相對誤差大，太大則像變暗、反射變強。

    問題與討論

    1. 半圓形透明盒為什麼要讓光從圓心射入？
      參考答案

      這樣折射光在盒內沿半徑前進，碰到弧面時與弧面垂直、不會再偏折，只需考慮平面上的一次折射，θ2 直接在 O 點量。

    2. 同一側兩根針靠近一點比較準，還是離遠一點比較準？用薄的還是厚的透明塊比較準？
      參考答案

      離遠一點：同樣插偏一點點，直線轉動的角度比較小。厚的透明塊使塊內的光路 OO′ 比較長，O′ 位置的同樣誤差造成的 θ2 誤差比較小。

    3. 如果玻璃磚的兩個長邊不平行，還能測折射率嗎？出射光還會和入射光平行嗎？
      參考答案

      可以，只要量 O 點的入射角與折射角（或在 O′ 點對 L′ 的法線量 θ3、θ4）。但出射光不再與入射光平行，所以由四根針也能判斷兩面是否平行。

    4. sin θ1–sin θ2 的直線不通過原點，而且左側入射與右側入射的斜率不同，可能是什麼原因？
      參考答案

      法線的方向有系統誤差，例如透明塊沒有對準 L：在一側量到的角度都偏大，另一側都偏小。左右兩側都取數據一起作圖，誤差大部分會抵消。

    5. 光由弧面射入時，P 的角度超過多少就再也看不到 P 的像通過 O？這和折射率有什麼關係？
      參考答案

      超過臨界角 \(\theta_c\)（\(\sin\theta_c = 1/n\)）：水約 48.6°、壓克力約 42.2°、冕牌玻璃約 41.1°。接近臨界角時像會變得很暗，因為大部分的光都被反射了。

    觀察重點

    • 斷掉的針：在「眼睛看到的景象」中，透過透明塊看到的下半段和上面的針頭錯開了。要讓下半段排成一直線，才是在光路上。
    • 拿走透明塊再看一次：A、B 不再和 C、D 對齊，因為光不再偏折。
    • 平行但錯開：長方形透明塊的側向位移 \(d\) 量出來和公式比一比；\(\theta_1\) 越大、厚度 \(t\) 越厚，\(d\) 越大。
    • 直尺還是量角器？半圓形的數據可以切換用量角器或直尺（\(x/R\)）計算，比較數據點散開的程度。
    • 全反射：改由弧面射入、打開光路提示，讓 P 沿圓弧移動：折射光越來越暗，到 \(\theta_c\) 時消失。
    • 找出系統誤差：選「含誤差」，分別把 A 插在法線的左邊和右邊取數據，比較兩邊的斜率。

    模擬方法

    • 光線在紙面上做二維追跡：每個界面都用向量形式的司乃耳定律決定新的方向，超過臨界角就全反射；像的亮暗由非偏振光的菲涅耳穿透率決定。
    • 針的像用眼睛看到它的方式求出：從針向各方向發出光線，用二分法找出穿過透明塊後恰好進入眼睛的那一條。所以「對齊」是真正依折射計算的結果，不是事先畫好的線。
    • 眼睛幾乎貼著紙面（高約 1 cm）看；離眼睛很近的針看起來又粗又有點模糊，和真實情況一樣。「眼睛看到的景象」中水平方向的角度依比例並放大，上下方向是透視示意。針身直徑 0.6 mm，兩個像相差不到約半根針寬就算重疊。
    • 讀數：量角器取到 1° 或 0.5°，直尺取到 0.01 cm。選「含誤差」時，每個讀數再加上隨機誤差（標準差 0.25° 或 0.02 cm），而且透明塊放歪了一個隱藏的 0.6°～1.4°（沒對準 L）——這是系統誤差，按「全部清除」前都不變。
    • 公認值（黃光 589 nm、室溫）：水 1.333（CRC Handbook of Chemistry and Physics），壓克力（PMMA）1.49、冕牌玻璃 1.52（BK7 為 1.517；Schott 光學玻璃資料、E. Hecht《Optics》）。未知樣品的折射率在 1.42～1.68 之間隨機。忽略色散，也忽略水盒的薄壁。
