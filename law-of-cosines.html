正弦定理、餘弦定理與解三角形

拖曳三角形的頂點，看餘弦定理怎麼讓三個正方形的面積對上帳，正弦定理怎麼把每一邊都綁在外接圓上。再給三個條件，讓三角形自己長出來——有時長不出來，有時長出兩個。

挑戰：解三角形

三角形上標了三個已知條件，算出標著問號的那一個（可以用計算機），打進答案。邊長誤差 1% 以內、角度 0.5° 以內算對。

背後的數學

餘弦定理

\[ c^2 = a^2 + b^2 - 2ab\cos C,\qquad \cos C = \frac{a^2 + b^2 - c^2}{2ab} \]

當 \(C = 90^\circ\) 時最後一項消失，就是畢氏定理。畫面說明原因：三條高把每個邊上的正方形切成兩個長方形，靠在同一個頂點旁的兩個長方形面積相同，例如靠近 \(C\) 的兩塊面積都是 \(ab\cos C\)。所以 \(c\) 上的正方形，就是另外兩個正方形扣掉這兩塊。\(C\) 是鈍角時 \(\cos C < 0\)，扣掉就變成加上。

正弦定理

\[ \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R \]

每個三角形都恰好有一個通過三個頂點的圓。角 \(A\) 是弦 \(BC\) 所對的圓周角，所以 \(a = 2R\sin A\)；另外兩邊也一樣，三個比值都等於直徑。面積是 \(\tfrac12 ab\sin C = \dfrac{abc}{4R}\)。

解三角形

  • SSS：三邊只要任兩邊和大於第三邊，三角形就確定了；角用餘弦定理求。
  • SAS：先用餘弦定理求第三邊，再求角。
  • ASA：第三個角是 \(180^\circ - A - B\)，再用正弦定理求另外兩邊。
  • SSA 是「可能兩解」的情形。畫好角 \(A\) 與邊 \(b = CA\)，\(B\) 就要在從 \(A\) 出發的射線上、離 \(C\) 恰好 \(a\)。以 \(C\) 為圓心、\(a\) 為半徑的圓，可能碰不到射線（\(a < h = b\sin A\)）、剛好相切（\(a = h\)，直角）、交兩點（\(h < a < b\)）或只交一點（\(a \ge b\)）。

觀察重點

  • 跨過 90°：拖曳 \(C\)，讓角 \(C\) 跨過 \(90^\circ\)。就在那一刻，外心離開三角形，\(-2ab\cos C\) 也變號。
  • 同一個比：不管怎麼拖，\(a/\sin A\)、\(b/\sin B\)、\(c/\sin C\) 三個數永遠相等，而且等於直徑 \(2R\)。
  • 兩個答案：SSA 的兩個解有相同的 \(A\)、\(b\)、\(a\)，兩個三角形在 \(B\) 的角加起來是 \(180^\circ\)。

計算方法

  • 角由餘弦定理求（cos 值夾在 \([-1, 1]\) 之間），外心是三條中垂線的交點。SSA 解 \(c^2 - 2bc\cos A + b^2 - a^2 = 0\)，得到 \(B\) 在射線上的位置。
