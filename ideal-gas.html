理想氣體分子模擬

數百個原子在立體容器裡飛來飛去，彼此碰撞、撞擊器壁。由分子撞牆傳給器壁的動量量出壓力，驗證 PV = NkT、平均動能 (3/2)kT、方均根速率與馬克士威速率分布；再用活塞與恆溫槽做等溫、等容、等壓與絕熱過程。

試試看：在「等溫」下把活塞往左拖到體積減半，看壓力和 P–V 圖怎麼變。

背後的物理

氣體動力論把氣體看成極多個做無規則運動的微小分子：分子本身的大小比彼此的距離小得多，除了碰撞以外沒有交互作用，所有碰撞都是完全彈性碰撞。氣體的壓力，就是分子不斷撞擊器壁時，器壁單位面積受到的平均作用力。

由分子撞牆求壓力

質量 \(m\) 的分子在 \(x\) 方向長 \(L\) 的容器中運動，每次撞到端面，\(x\) 方向動量改變 \(2mv_x\)，每隔 \(2L/v_x\) 撞一次，所以平均作用力是 \(2mv_x \div (2L/v_x) = mv_x^2/L\)。把 \(N\) 個分子加起來，並利用 \(\langle v_x^2\rangle = \langle v^2\rangle/3\)（沒有哪個方向特別）：

\[ P = \frac{F}{A} = \frac{N m\langle v_x^2\rangle}{L A} = \frac{1}{3}\,\frac{N}{V}\,m\langle v^{2}\rangle = \frac{2}{3}\,\frac{N}{V}\,\langle E_k\rangle \]

與理想氣體方程式 \(PV = NkT = nRT\) 比較，就得到溫度在分子層次的意義——分子平均移動動能：

\[ \langle E_k\rangle = \frac{1}{2}m\langle v^2\rangle = \frac{3}{2}kT, \qquad v_{\text{rms}} = \sqrt{\langle v^2\rangle} = \sqrt{\frac{3kT}{m}} = \sqrt{\frac{3RT}{M}} \]

其中 \(k = 1.380649\times10^{-23}\ \mathrm{J/K}\) 為波茲曼常數、\(N_A = 6.022\times10^{23}\ \mathrm{mol^{-1}}\)、\(R = N_A k = 8.314\ \mathrm{J/(mol\,K)}\)，\(n = N/N_A\) 是莫耳數、\(M\) 是莫耳質量。模擬由六面器壁受到的衝量量出 \(P\)，由分子動能算出 \(T\)，再互相比較。

馬克士威速率分布

碰撞讓分子的速率不斷改變，但達到平衡後，速率介於 \(v\) 與 \(v + dv\) 之間的分子比例固定為 \(f(v)\,dv\)：

\[ f(v) = 4\pi\left(\frac{m}{2\pi kT}\right)^{3/2} v^{2}\,e^{-mv^{2}/2kT}, \qquad \int_0^\infty f(v)\,dv = 1 \]

直方圖上標出三個特徵速率（比值 \(\sqrt2 : \sqrt{8/\pi} : \sqrt3 \approx 1 : 1.13 : 1.22\)）：

\[ v_p = \sqrt{\frac{2kT}{m}}\ \ (\text{最可能速率}), \qquad \bar v = \sqrt{\frac{8kT}{\pi m}}\ \ (\text{平均速率}), \qquad v_{\text{rms}} = \sqrt{\frac{3kT}{m}} \]

氣體定律

\[ \underbrace{PV = \text{常數}}_{\text{波以耳（}T\text{ 固定）}}, \qquad \underbrace{\frac{V}{T} = \text{常數}}_{\text{查理（}P\text{ 固定）}}, \qquad \underbrace{\frac{P}{T} = \text{常數}}_{\text{給呂薩克（}V\text{ 固定）}} \]

三者都來自 \(PV = NkT\)。注意 \(T\) 必須用絕對溫度：P–T 圖與 V–T 圖上的直線都指向原點 \(T = 0\ \mathrm{K}\)（−273.15 °C）。壓力與分子質量無關——相同的 \(N\)、\(V\)、\(T\)，任何氣體的壓力都相同（亞佛加厥）。混合氣體中，各成分各自貢獻分壓 \(P_i = N_i kT/V\)，總壓 \(P = P_1 + P_2\)（道耳頓分壓定律）。

混合氣體：動能相同、速率不同

溫度 \(T\) 的混合氣體中，輕分子與重分子的平均動能相同，都是 \(\tfrac32 kT\)（能量均分），所以輕的分子跑得比較快：

\[ \tfrac12 m_1\langle v_1^2\rangle = \tfrac12 m_2\langle v_2^2\rangle \quad\Longrightarrow\quad \frac{v_{\text{rms},1}}{v_{\text{rms},2}} = \sqrt{\frac{m_2}{m_1}} \]

功、熱與絕熱過程

單原子理想氣體的內能就是原子的動能 \(U = \tfrac32 NkT = \tfrac32 nRT\)。內能的改變來自器壁傳入的熱 \(Q\) 與活塞對氣體作的功 \(W\)（熱力學第一定律）。分子撞上以速度 \(u\) 移動的活塞，反彈後的速度由 \(v_x\) 變成 \(2u - v_x\)：活塞迎面推進時分子變快（壓縮使氣體升溫），活塞後退時分子變慢。

\[ \Delta U = Q + W, \qquad \text{絕熱（}Q = 0\text{）}:\quad PV^{\gamma} = \text{常數},\quad TV^{\gamma - 1} = \text{常數},\quad \gamma = \frac{C_P}{C_V} = \frac{5}{3} \]

觀察重點

  • 壓力就是撞擊：打開音效，每一聲「滴答」都是分子撞上活塞。增加分子數或提高溫度，撞擊更頻繁、更猛烈，量到的 \(P\) 與 \(NkT/V\) 一致。
  • 波以耳定律：在等溫過程中把體積減半（8000 → 4000 nm3），壓力加倍，P–V 圖上的點沿著雙曲線 \(PV = \text{常數}\)。
  • 給呂薩克與查理定律：在等容過程中改變 \(T\)，看 P–T 圖；在等壓過程中活塞自動移動，V–T 圖是一條通過原點的直線。
  • 壓力與氣體種類無關：在相同的 \(N\)、\(V\)、\(T\) 下切換氦與氙。氙原子重了 33 倍、慢得多，壓力卻一樣。
  • 動能相同、速率不同：混合氦與氬，兩組直方圖都符合同一個溫度的馬克士威曲線，平均動能相等，\(v_{\text{rms}}\) 卻相差 \(\sqrt{39.95/4.00} \approx 3.16\) 倍。
  • 由混亂走向平衡：選絕熱過程，按「改成同一速率」。直方圖一開始是一根尖峰，只靠分子間的碰撞就散開成馬克士威分布；混合氣體則會讓兩種分子的平均動能變得相等。
  • 絕熱與等溫：在絕熱過程中壓縮氣體。沒有熱量流出，外界作的功全部變成內能，溫度上升，所以 P–V 曲線比等溫線陡（\(PV^{5/3} = \text{常數}\)），而且 \(\Delta U = W\)。
  • 熱機：在 P–V 圖上繞一個封閉的循環（例如等容加熱 → 等壓膨脹 → 等容冷卻 → 等壓壓縮）。氣體回到原來的狀態，\(\Delta U = 0\)，卻對外作了淨功，大小等於循環圍成的面積。

模擬方法

  • 分子是三維的硬球。每一對分子都解二次方程式求出接觸的精確時刻，碰撞沿兩球連心線交換動量，動量與動能守恆到捨入誤差；撞牆也在精確的時刻處理。
  • 單位：長度 nm、時間 ps、質量 u（\(1\ \mathrm{u} = 1.6605\times10^{-27}\ \mathrm{kg}\)），所有讀數都是真實的 SI 數值。200 個氦原子在 8000 nm3、300 K 時，壓力約為 1 大氣壓。
  • 壓力是「量」出來的，不是算出來的：\(P = \sum(\text{所有器壁受到的衝量}) \div (\text{器壁面積} \times \text{時間})\)；不確定度由把平均時間分成數批、比較各批的差異求得。\(V\) 指分子中心可以到達的空間。
  • 真實原子的直徑約 0.26～0.4 nm；這裡取 0.44～0.56 nm，讓碰撞頻繁到看得見。分子本身佔一點空間，量到的壓力會比 \(NkT/V\) 略大，倍數為 \(Z = 1 + \tfrac{2\pi}{3}\tfrac{N}{V}d^{3}\)（本模擬最多約 3%），這正是真實氣體不完全理想的原因之一。
  • 恆溫槽：等溫、等容、等壓過程中，五面固定的器壁與恆溫槽接觸。撞上這些牆的分子，會依恆溫槽溫度的馬克士威分布重新射出，能量就在牆與氣體之間流動，直到氣體與恆溫槽同溫。絕熱過程中器壁不導熱：分子撞牆後速率不變、方向隨機（器壁在分子尺度上是粗糙的），沒有能量交換。
  • 分子只有數百個，瞬間的溫度與壓力會在平均值附近起伏，幅度約為 \(\sqrt{2/3N}\)（\(N = 200\) 時約 6%）。所以讀數都取一段時間的平均，並附上統計不確定度；切換到絕熱過程時，氣體保有那一瞬間的能量。
  • 3D 檢視顯示的是同一個模擬，不是另外算的：每一幀把每顆球放在該分子算出來的位置、用它真實的半徑來畫，活塞內面也在算出來的活塞位置。玻璃畫在「分子中心可到達的空間」（體積 \(V\)）外面一個分子半徑處，所以分子反彈時剛好碰到玻璃。活塞上的閃光是模擬記錄到的撞擊；固定器壁上則標出速度剛被器壁反彈的分子，只顯示約 8 次中的 1 次。旋轉視角不會改變模擬。3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才會下載。
  • 活塞相對分子移動得很慢（最多為分子平均速率的 1%），所以過程是準靜態的；活塞移動時時間會自動快轉，畫面上會標示「快轉」。等壓過程中，由控制器依壓力計讀數移動活塞，使壓力保持在設定值，相當於活塞上放了固定重量的砝碼。
