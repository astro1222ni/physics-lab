背後的數學

怎麼看蛛網圖

從鏡子 y = x 上的點 \((a_n, a_n)\) 垂直走到曲線，那裡的高度就是 \(f(a_n) = a_{n+1}\)；再水平走回鏡子，新的項就搬到 \((a_{n+1}, a_{n+1})\)。兩個動作一直重複就畫出蛛網，鏡子上的轉角就是一項一項的數列。

不動點與穩定性

\[ \lim_{n\to\infty} a_n = L \ \Rightarrow\ L = f(L),\qquad a_{n+1} - L = f(a_n) - f(L) \approx f'(L)\,(a_n - L). \]

函數 \(f\) 連續時，遞迴數列如果有極限，極限一定是不動點，也就是 \(y = f(x)\) 和 \(y = x\) 的交點。在交點附近，每走一步，和 \(L\) 的距離大約乘上 \(f'(L)\)。所以 \(|f'(L)| < 1\) 會把附近的項吸進來：\(0 < f'(L) < 1\) 走樓梯，\(-1 < f'(L) < 0\) 繞螺旋；\(|f'(L)| > 1\) 則把它們推開。

一次式的遞迴

\[ a_{n+1} = p\,a_n + q,\qquad L = \frac{q}{1 - p},\qquad a_n - L = (a_1 - L)\,p^{\,n-1}. \]

把 \(L = pL + q\) 從規則裡減掉，得到 \(a_{n+1} - L = p\,(a_n - L)\)：和 \(L\) 的距離是公比 \(p\) 的等比數列。\(p = 1\) 時是等差數列，兩條直線平行、沒有交點。

邏輯斯諦遞迴

\(a_{n+1} = r\,a_n(1 - a_n)\) 是食物有限時族群數量的簡單模型。\(1 < r < 3\) 時數列停在 \(1 - \frac1r\)。\(r = 3\) 時那裡的斜率變成 \(-1\)，數列開始在兩個值之間交替；到 3.449 附近分成四個、再分成八個，越分越快，大約 3.57 以後就不再重複（混沌）。混沌裡也有平靜的窗口，例如 \(r = 3.83\) 附近的三點循環。\(r = 4\) 時，起點只差 0.001，二三十步之後就完全不一樣。

費氏型遞迴

\[ a_{n+2} = a_{n+1} + a_n,\qquad \frac{a_{n+1}}{a_n} \to \varphi = \frac{1 + \sqrt5}{2} \approx 1.618. \]

把 \(a_n = x^n\) 代進去，規則變成 \(x^2 = x + 1\)，兩個根是 \(\varphi\) 和 \(-\frac1\varphi \approx -0.618\)。這種數列都可以寫成 \(A\varphi^n + B\left(-\frac1\varphi\right)^n\)，第二部分越來越小，所以相鄰兩項的比趨近 \(\varphi\)——除非 \(A = 0\)，這時數列是公比 \(-0.618\) 的等比數列，越來越小。

觀察重點

  • 樓梯或螺旋：一次式的 \(p\) 在 0 和 1 之間走樓梯，\(p\) 是負的繞螺旋；\(p = -1\) 時蛛網變成一個封閉的正方形。
  • 計算機的把戲：在弧度模式下對任何數一直按 cos，最後都會停在 0.739085…，它是 \(\cos x = x\) 唯一的解。
  • 巴比倫開方法：\(\frac12\left(a_n + \frac{b}{a_n}\right)\) 在 \(\sqrt b\) 的斜率是 0，所以每走一步，對的位數大約加倍。

計算方法

  • 每一項都用雙精度浮點數由前一項算出；某一項沒有定義（根號裡是負的、分母是 0）時數列就停下。邏輯斯諦的長期週期是先走 20 000 步，再找 64 以內最短的重複。分岔圖對每一行像素的 r 走 600 步，畫出最後 120 步。
