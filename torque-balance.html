力矩與靜力平衡

把砝碼、磚塊和人放上蹺蹺板，看每個力的力臂與力矩、淨力矩、支點的力與重心；放開木板，它會依 Iα = Στ 轉動。再讓梯子靠在牆上，找出不會滑倒需要多少摩擦力，以及為什麼人爬得越高越容易滑。

試試看：支點左邊 1 m 放 2 kg，右邊 2 m 放 1 kg，按「放開」看會不會平衡。

把工具箱的物體拖到木板的格點上：放在板子上方就放上去，放在下方就吊在板下（只有砝碼能吊）。拖曳物體可以移動，拖離木板就移除；拖曳三角形可以移動支點。位置與力臂依比例，物體大小只是示意。逆時針力矩為正。

梯子底端一開始有小擋塊頂住。按「放手」移開擋塊：只有摩擦力供應得起需要的力，梯子才站得住。拖曳梯子頂端可以改變角度，拖曳人可以移動位置。力的箭頭依比例畫（比例尺在地板上）。

木板與支點

4 m 長的均勻木板，每 0.25 m 一個格點；M = 0 就是輕桿。改變木板質量或支點時，支架會重新撐住木板。點一下數字可直接輸入精確數值。

精確放置

同一格最多疊 3 個砝碼或磚塊；人要獨占一格。只有砝碼能吊掛，每個掛鉤掛一個。

背後的物理

力矩與力臂

力讓物體繞轉軸轉動的效果用力矩表示：力的大小乘以力臂，也就是轉軸到力的作用線的垂直距離。重力鉛直向下，所以它的力臂是與支點的水平距離，不是沿著傾斜木板量的距離。本實驗以逆時針力矩為正：

\[ \tau = rF\sin\phi = F\,d_{\perp}, \qquad \tau_i = -m_i g\,(x_i - p)\cos\theta \]

吊在板下的砝碼經由繩子把掛鉤鉛直往下拉，作用線和放在板上同一格的砝碼相同，力矩也相同。

靜力平衡的條件

剛體要保持靜止，合力與（對任一點的）合力矩都必須為零。對蹺蹺板而言，第二個條件就是槓桿原理，第一個條件決定支點的力：

\[ \sum \vec F = 0, \qquad \sum \tau = 0 \;\Rightarrow\; \sum_{\text{左}} m_i g\,d_i = \sum_{\text{右}} m_j g\,d_j, \qquad N + F_{\text{秤}} = W_{\text{總}} \]

木板本身的重量作用在中心（\(x = L/2\)）。支點不在中心時，木板自己就有力矩 \(-Mg(L/2 - p)\)：所以只用一個砝碼也能讓這種「不對稱」的配置平衡，也能反過來用槓桿秤出木板的質量。換個說法：整個系統的重心在支點正上方時，木板就平衡：

\[ x_{\text{cm}} = \frac{M\,\frac{L}{2} + \sum m_i x_i}{M + \sum m_i} = p \quad\Longleftrightarrow\quad \sum \tau = 0 \]

彈簧秤只能往上拉。在離支點 \(s_k\) 的地方要讓木板保持水平，讀數必須是 \(F = -\sum\tau / s_k\)；離支點越遠，需要的力越小（槓桿省力但不省功）。

不平衡時：轉動

放開之後，木板依轉動的牛頓第二定律繞支點轉動。轉動慣量 \(I\) 只由質量對轉軸的分布決定，與木板轉得多快無關：

\[ I\alpha = \sum\tau, \qquad I = M\!\left(\frac{L^2}{12} + \Big(\frac{L}{2} - p\Big)^{2}\right) + \sum m_i (x_i - p)^2 \]

淨力矩小而 \(I\) 大（重物離支點遠）時，木板慢慢傾斜；淨力矩大而 \(I\) 小時，板端重重撞向地面。轉動中重心在加速，所以支點的力不等於總重。

靠牆的梯子

梯子受五個力：梯子與人的重量、地面的正向力 \(N_{\text{地}}\) 與摩擦力 \(f_{\text{地}}\)、牆的正向力 \(N_{\text{牆}}\)，以及（牆粗糙時）牆的摩擦力 \(f_{\text{牆}}\)。對梯子底端取力矩，地面的兩個力就消失了：

\[ f_{\text{地}} = N_{\text{牆}}, \qquad N_{\text{地}} + f_{\text{牆}} = W, \qquad N_{\text{牆}}\,L\sin\theta + f_{\text{牆}}\,L\cos\theta = \Big(W_{\text{梯}}\tfrac{L}{2} + W_{\text{人}}\,d\Big)\cos\theta \]

牆光滑時 \(f_{\text{牆}} = 0\)：地面要提供 \(f = (W_{\text{梯}}/2 + W_{\text{人}}\,d/L)\cot\theta\)，但最多只能提供 \(\mu_s W\)。所以梯子的角度至少要達到臨界角才不會滑：

\[ \tan\theta_c = \frac{m_{\text{梯}}/2 + m_{\text{人}}\,d/L}{\mu_s\,(m_{\text{梯}} + m_{\text{人}})} \;\xrightarrow{\text{沒有人}}\; \tan\theta_c = \frac{1}{2\mu_s} \]

分子隨 \(d\) 變大：人爬得越高，梯子就要放得越陡。牆也有摩擦時，臨界角變成 \(\tan\theta_c = \tau_w(1 + \mu_s\mu_w)/(\mu_s W) - \mu_w\)，其中 \(\tau_w = W_{\text{梯}}/2 + W_{\text{人}}\,d/L\)；沒有人時為 \(\tan\theta_c = (1 - \mu_s\mu_w)/(2\mu_s)\)。

觀察重點

  • 槓桿原理：支點在中央，左邊 0.5 m 放 5 kg、右邊 1.25 m 放 2 kg，兩邊力矩大小相等、方向相反，放開後木板保持水平。
  • 吊著和放著一樣：把砝碼從板上某一格移到同一格下方的掛鉤，力矩不變。
  • 秤木板：不放物體、把支點移離中央，找出單一砝碼放在哪裡能讓它平衡，就能由 \(M = m\,(p - x)/(L/2 - p)\) 算出木板質量。
  • 支點的力：平衡時 \(N\) 等於總重。放開不平衡的木板，看轉動中的 \(N\) 比總重小。
  • 慢慢轉或很快轉：同樣小的不平衡，把重的人放在兩端（\(I\) 大），木板傾斜得慢很多。
  • 梯子：沒有人、牆光滑時，一點一點降低角度直到梯子滑倒，和 \(\tan\theta_c = 1/(2\mu_s)\) 比較。再讓人往上爬：爬到某個高度時，需要的摩擦力超過 \(\mu_s N\)，梯子就滑倒。

模擬方法

  • 薄板近似：忽略木板與物體的厚度，每個重量都作用在板子中心線的該格點上；吊掛的砝碼作用在掛鉤上，繩子保持鉛直。位置與力臂依比例，物體大小只是示意。\(g = 9.80665\ \mathrm{m/s^2}\)（標準重力加速度）。
  • 平衡（\(\sum\tau = 0\)、支點的力、彈簧秤讀數、梯子的力與臨界角）都用解析公式精確計算。
  • 放開後，用四階龍格–庫塔法（每步不超過 0.5 ms）積分 \(\theta'' = -(g S/I)\cos\theta\)（\(S\) 為質量對支點的一次矩），能量 \(\tfrac12 I\omega^2 + gS\sin\theta\) 的漂移小於百億分之一。板端碰地、吊掛砝碼碰到地面、彈簧秤拉緊的時刻用二分法找出。
  • 板端碰地時立即停住。吊掛的砝碼碰到地面就停在地上（繩子變鬆），再被提起時對支點的角動量守恆。彈簧秤由手拿著，掛鉤固定在木板水平時的高度。
  • 梯子滑倒（簡化）：兩端先保持接觸，動摩擦係數取與靜摩擦係數相同；牆的正向力降到零時頂端離開牆面，之後底端滑到停下，梯子再繞底端倒下。
