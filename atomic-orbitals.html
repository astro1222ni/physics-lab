原子軌域的形狀

電子在原子裡的哪裡？量子力學只能告訴我們「在某處找到電子的機率」，而這個機率有形狀：s 是球、p 是啞鈴、d 像四葉草。這裡的形狀都由氫原子的精確波函數算出來。用平面把電子雲切開，找出電子永遠不會出現的節面，沿著徑向分布找最可能的半徑，再到 3D 把電子雲轉一圈。

試試看：選 3s，看切面上有兩圈全暗的環——那是電子雲消失的徑向節面，3s 有 n − l − 1 = 2 個。再切換到「3D 立體」，勾選「切開一角」，看看像洋蔥一樣的球殼。

在切面上點一下或拖曳，放下探針讀出那一點的機率密度。3D 立體時拖曳可旋轉，雙指或滾輪可縮放。

徑向分布

徑向分布 \(P(r) = r^2R^2\) 是在距離 r 的薄球殼內找到電子的機率（每單位半徑）。從 0 到游標的陰影面積，就是電子出現在這個半徑以內的機率。

認軌域

畫面換成一個不知名的軌域，名稱都藏起來。數一數它的徑向節面和角節面，說出它是哪一個軌域。自己換軌域就算放棄這一題。

實驗目的

  1. 認識 s、p、d（以及 f）軌域的形狀與在空間中的方向。
  2. 找出徑向節面與角節面，並把它們的數目和量子數 n、l 連起來。
  3. 讀懂徑向分布：最可能半徑、平均半徑，以及電子出現在某個球以內的機率。

原理

波函數與軌域

解單一電子原子（H、He+、Li2+）的薛丁格方程式，得到波函數 ψ。每一個都能拆成只和距離 r 有關的徑向部分，與只和方向有關的角度部分。一個波函數就是一個軌域；\(|\psi|^2\) 是機率密度——在某點附近一個小體積內找到電子的機率，除以這個體積。

\[ \psi_{n\ell m}(r,\theta,\phi) = R_{n\ell}(r)\,Y_{\ell m}(\theta,\phi), \qquad \int |\psi|^2\,dV = 1 \]

四個量子數

量子數可以是決定什麼
主量子數 n1, 2, 3, …能量（單一電子時只看 n）與大小
角量子數 l0, 1, …, n − 1（s, p, d, f）形狀；角節面的數目
磁量子數 ml−l, …, 0, …, +l方向；一個副層有 2l + 1 個軌域
自旋量子數 ms+½, −½每個軌域最多 2 個電子（不影響形狀，所以不畫）

課本上的 px、py、dxy…是 \(m_l = +|m|\) 與 \(-|m|\) 兩個波函數組合成的實數軌域；pz、dz2、fz3 則是 \(m_l = 0\)。

能量

\[ E_n = -\frac{Z^2}{n^2}\times 13.6\ \text{eV} = -\frac{Z^2}{n^2}\times 1312\ \text{kJ/mol} \]

只有一個電子時，3s、3p、3d 的能量完全相同。多電子原子中，內層電子對外層電子的遮蔽不一樣，同一層內才變成 s < p < d。

節面

節面是 ψ = 0 的曲面：電子絕不會出現在上面。徑向部分為 0 的地方是球面（徑向節面）；角度部分為 0 的地方是通過原子核的平面或圓錐（角節面）。每穿過一個節面，ψ 就變號一次。

\[ \text{radial} = n-\ell-1 \] \[ \text{angular} = \ell \] \[ \text{total} = n-1 \]

例如：2s 在 \(r = 2a_0/Z\) 有一個球形節面；2pz 的節面是 xy 平面；dz2 的節面是兩個圓錐，在 \(3\cos^2\theta - 1 = 0\) 的 \(\theta = 54.7^\circ\)。（公式中 radial 是徑向節面、angular 是角節面、total 是總數。）

徑向分布

\[ P(r) = r^2 R_{n\ell}(r)^2 \] \[ \langle r \rangle = \frac{a_0}{2Z}\left[3n^2 - \ell(\ell+1)\right] \] \[ R_{1s} = 2\left(\frac{Z}{a_0}\right)^{3/2} e^{-Zr/a_0} \]

1s 的 \(|\psi|^2\) 在原子核處最大，但薄球殼的體積 \(4\pi r^2\,dr\) 隨 r 變大。兩者相乘，最大值在 \(r = a_0/Z\)：氫原子剛好是波耳半徑 \(a_0 = 52.9\) pm。\(\ell = n - 1\) 的軌域（1s、2p、3d、4f）最可能半徑是 \(n^2a_0/Z\)，正好是波耳軌道的半徑。

觀察重點

  • 1s、2s、3s：同樣是球形，卻越來越大，徑向節面 0、1、2 個。保留三條曲線比較看看。
  • 2pz 在 xz 平面像啞鈴；在通過原子核的 xy 平面上卻完全消失，因為整個平面就是它的節面。
  • 切換到「波函數 ψ（正負）」：p 軌域兩瓣的正負號相反。正負號不是電荷，而是軌域重疊形成化學鍵時才有意義。
  • dz2 和其他四個 d 軌域長得不一樣：沿 z 軸兩瓣，中間繞一圈環。
  • 勾選「整個副層加總」：px、py、pz 加起來（或五個 d 軌域加起來）是完美的球形。這就是填滿或半填滿的副層呈球對稱的原因。
  • He+、Li2+：形狀一樣，只是縮小成 1/Z，因為原子核拉得更緊。

想一想

  1. 2pz 上下兩瓣之間的平面上機率是 0，電子要怎麼從上面那瓣到下面那瓣？
  2. 1s 的 |ψ|² 在原子核處最大，可是徑向分布在那裡卻是 0。這矛盾嗎？
  3. 4d 軌域有幾個節面？各是哪一種？
  4. 2s 電子有一小部分時間非常靠近原子核（內側的小峰），2p 卻沒有。這怎麼解釋鋰原子中 2s 的能量比 2p 低？
看參考答案
  1. 電子不是沿著軌跡移動的小球。軌域描述的是一個同時分布在兩瓣上的駐波；問它怎麼「穿過」節面，是把它當成有軌跡的粒子，而量子力學並不給電子軌跡。
  2. 不矛盾。|ψ|² 是每單位體積的機率；1s 的 P(r) = 4πr²|ψ|² 是每單位半徑的機率。靠近原子核的球殼體積非常小，密度再大，機率還是很小。兩者平衡，峰值落在 a0。
  3. 共 n − 1 = 3 個：n − l − 1 = 1 個球形（徑向）節面，l = 2 個角節面（兩個平面；4dz² 是兩個圓錐）。
  4. 2s 電子靠近原子核時，幾乎沒有被 1s 電子遮住，感受到接近 +3 的完整核電荷。這種穿透效應讓它的平均能量比 2p 低。

模擬方法

  • 用類氫原子的精確波函數：\(R_{n\ell}\) 由廣義拉蓋爾多項式與標準歸一化常數組成，角度部分用化學課本的實數球諧函數。切面、節面、徑向曲線、等值面與機率雲全部由這些公式算出，沒有任何形狀是手畫的。長度以波耳半徑 \(a_0 = 52.9177\) pm 為單位；原子核質量視為無限大（氫原子真正的游離能是 1312.0 kJ/mol，這裡是 1312.75）。
  • 2D 切面：在所選平面的格點上計算 ψ。顏色深淺 ∝ |ψ|（= √|ψ|2），讓外圍較淡的部分也看得到。虛線圓是徑向節面（解析解），虛線直線與曲線是角節面（角度部分變號的地方），實線輪廓是 3D 等值面和切面的交線。
  • 等值面：選一個值 c，使 \(|\psi| > c\) 的區域剛好包住指定的機率（預設 90%）——把可分離的 \(R^2Y^2\) 對 4000 個方向與細的徑向格點積分求得；再從 3D 格點取出 \(\psi = \pm c\) 的曲面（surface nets 法）。紅色是 ψ > 0，藍色是 ψ < 0。
  • 機率雲：依 |ψ|² 精確地隨機抽 15000 個點：半徑由徑向分布的累積積分反查，方向由角度部分用拒絕抽樣決定。
  • 「整個副層加總」畫的是副層中 2l + 1 個軌域的平均，結果是球形（Unsöld 定理）。「認軌域」從 n ≤ 4 的 30 個軌域中抽題。
  • 限制：只有單一電子的原子是精確的。多電子原子的軌域形狀相似，但大小與能量因遮蔽而改變。3D 立體使用 three.js 函式庫（MIT 授權，切換時才下載），每個軌域都自動縮放到填滿畫面，真正的大小寫在角落。
