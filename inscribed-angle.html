圓周角與圓冪

讓一個點沿著圓走，它看一條弦的角度始終不變；圓上四個點連成的四邊形，對角加起來永遠 180°；過一個固定點隨便畫一條線，被圓截出的兩段相乘，結果永遠一樣。

試試看：在「圓周角」裡慢慢把 P 繞著圓拖。角度一直不變，直到 P 越過 A 或 B，才跳成它的補角。在「圓冪」裡轉動第一條線，QA、QB 都在變，QA·QB 卻不變。

背後的數學

圓周角定理

\[ \angle APB = \tfrac12\,\angle AOB \]

頂點 \(P\) 在圓上的角，看弦 \(AB\) 的角度等於「不含 \(P\) 那段弧」所對圓心角的一半。把 \(P\) 和圓心連起來：\(\triangle OPA\)、\(\triangle OPB\) 都是等腰三角形（\(OP = OA = OB = R\)），再用「外角等於兩個不相鄰內角的和」就得到。推論：同弧所對的圓周角都相等；半圓（直徑）所對的圓周角是 \(90^\circ\)（泰勒斯）；在兩側的點看 \(AB\) 的兩個角互補。

圓內接四邊形

\[ \angle A + \angle C = \angle B + \angle D = 180^\circ,\qquad AC\cdot BD = AB\cdot CD + AD\cdot BC \]

\(\angle A\)、\(\angle C\) 分別對著弧 \(BCD\) 和弧 \(DAB\)，兩段弧合起來是整個圓，所以兩角的和是 \(360^\circ\) 的一半。反過來，對角互補的凸四邊形一定有外接圓。第二個式子是托勒密定理（約西元 150 年）。

圓冪

\[ QX\cdot QY = \left|\,OQ^2 - R^2\,\right|,\qquad QT^2 = OQ^2 - R^2 \]

過點 \(Q\) 畫任一條直線，交圓於 \(X\)、\(Y\)。把直線寫成 \(Q + s\,\mathbf u\) 代入 \(|P|^2 = R^2\)，得到 \(s^2 + 2(Q\cdot\mathbf u)\,s + (OQ^2 - R^2) = 0\)；不管方向 \(\mathbf u\) 怎麼選，兩根的乘積都是 \(OQ^2 - R^2\)。\(Q\) 在圓內就是相交弦定理，在圓外是割線定理，直線和圓相切時兩個交點合成切點 \(T\)。

觀察重點

  • 同弧同角：固定 \(A\)、\(B\)，拖動 \(P\)。只有越過 \(A\) 或 \(B\) 時角度才改變，變成 \(180^\circ\) 減去原來的角。
  • 優角的圓心角：\(P\) 在短弧上時，它看的那段弧比半圓長，圓心角變成優角，仍然恰好是圓周角的兩倍。
  • 每條線都是同一個數：圓冪 \(OQ^2 - R^2\) 在圓內是負的、圓上是 0、圓外是正的。它和直線無關，只看 \(Q\) 在哪裡。

計算方法

  • 每個角都直接用點的座標（內積）量，每段長度都用真正算出來的交點量，所以畫面上的定理是驗證出來的，不是先假設好的。圓上的點用拖的每次 \(0.5^\circ\)，用方向鍵每次 \(0.1^\circ\)。
