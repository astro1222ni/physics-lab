顯示

背後的物理

小車受兩個力：重力 \(m\vec g\) 與軌道的作用力。軌道的力分成垂直軌道的正向力 \(N\)，與（有摩擦時）沿著軌道的摩擦力 \(f = \mu N\)。正向力永遠和速度垂直，不作功。由功能定理，只有重力（與摩擦力）會改變動能：

\[ W_{\text{gravity}} + W_{f} = \Delta K, \qquad W_{\text{gravity}} = -mg\,\Delta y = -\Delta U \]

沒有摩擦時，重力作的功正好等於位能的減少，所以軌道上任意兩點的力學能相等，與軌道形狀無關：

\[ \tfrac12 m v_1^{2} + m g y_1 = \tfrac12 m v_2^{2} + m g y_2 \quad\Rightarrow\quad v = \sqrt{v_0^{2} + 2 g h} \]

\(h\) 是小車下降的高度。質量消掉了，所以重的車與輕的車在同一高度速率相同。由靜止出發（\(v_0 = 0\)）時，到了月球（\(g = 1.62\ \mathrm{m/s^2}\)），每一點的速率都變慢，但走的路線完全一樣，只是花的時間比較長。（有初速時就不成立了：\(v_0^2 + 2gh\) 不和 \(g\) 成正比。）

位能零點可以自己選

只有位能的差才有物理意義。把零點放在高度 \(y_0\)，位能 \(U = mg(y - y_0)\)：所有的 \(U\) 與總能都差同一個常數 \(-mgy_0\)，\(U\) 也可以是負的，但 \(\Delta U\)、速率與運動完全不變。

摩擦力把力學能變成熱能

動摩擦力 \(f = \mu N\) 永遠和運動方向相反。它減少的力學能變成熱能 \(Q\)，總能不變：

\[ Q = \int \mu N\, ds, \qquad K + U + Q = \text{constant} \]

在彎曲的軌道上，正向力不是 \(mg\cos\theta\)：其中一部分要提供轉彎所需的向心力 \(mv^2/r\)。以 \(\kappa\) 表示曲率（谷底為正、山頂為負、迴圈中為 \(1/R\)）：

\[ N = m\left(g\cos\theta + \kappa v^{2}\right) \]

所以小車快速通過谷底時被用力壓向軌道（那裡摩擦生熱也較多），越過山頂時則比重量輕。小車停在夠平緩的地方（\(\tan\theta \le \mu\)）時，摩擦力會讓它停在那裡。

繞過鉛直迴圈

半徑 \(R\) 的迴圈頂點，軌道只能往下推自由小車（\(N \ge 0\)），所以至少要讓重力單獨就能提供向心力：\(mv_{\text{top}}^{2}/R \ge mg\)。配合由迴圈底部以上高度 \(h\) 靜止出發的能量守恆：

\[ v_{\text{top}}^{2} = 2g(h - 2R) \ge gR \quad\Rightarrow\quad h \ge \tfrac52 R, \qquad \frac{N_{\text{top}}}{mg} = \frac{2h}{R} - 5 \]

若 \(R < h < 2.5R\)，自由小車會在 \(N\) 降到 0 的地方離開軌道，那裡比迴圈底部高 \((R + 2h)/3\)，之後變成拋體。軌道車的輪子夾住軌道兩側，軌道也能把它拉向軌道（\(N < 0\)），所以不會掉下來。比較迴圈底部與頂點（無摩擦）可得 \(N_{\text{bottom}} - N_{\text{top}} = 6mg\)，與速率無關。

觀察重點

  • 速率只看下降多少：在 U 形谷由靜止從不同位置出發，比較紀錄表中量到的最低點速率與 \(\sqrt{2gh_0}\)。改變質量——什麼都沒變。
  • 兩邊一樣高：μ = 0 時小車一定在出發的高度（能量水位線）折返。改變軌道形狀，折返高度仍然不變。
  • 熱能：把 μ 調大，看熱能長條變長、總能長條始終一樣高。切到能量–位置圖：力學能那條線一段一段往下降。
  • 2.5R 規則：選圓形迴圈與自由小車，找出還能繞過去的最低出發點，把它比迴圈底部高多少與 \(2.5R\) 比較。
  • 地球與月球：在跳台上由靜止出發（\(v_0 = 0\)、μ = 0），小車在月球與地球落在同一個地方，因為起跳速率的平方與 \(g\) 成正比、落下時間的平方與 \(g\) 成反比，兩者抵消。
  • 移動零點：小車跑的時候拖曳藍色零點線。\(U\) 與 \(E\) 長條跳動相同的量，\(K\) 與 \(Q\) 不動，小車的運動也完全不受影響。

模擬方法

  • 軌道是均勻三次 B 樣條 \(y = f(x)\)，經過第一個與最後一個控制點，斜率與曲率處處連續。迴圈是半徑 \(R\) 的正圓，底部接上水平的軌道（那裡曲率由 0 跳到 \(1/R\)，和課本的迴圈一樣；真正的雲霄飛車用回旋曲線過渡，避免這個衝擊）。
  • 在軌道上，小車是沿弧長 \(s\) 運動的質點：\(m\ddot s = -mg\sin\theta - \mu N\,\mathrm{sgn}(v)\)，\(N = m(g\cos\theta + \kappa v^2)\)。用四階 Runge–Kutta 法、固定步長 0.5 ms 積分；到達一段軌道的端點、自由小車的正向力降到 0 以下、速度變號等事件，用二分法找到發生的瞬間（誤差小於 \(10^{-12}\) s）。
  • 沒有任何能量修正。無摩擦時，跑 120 s 後 \(K + U\) 的相對漂移約 \(10^{-11}\)（單元測試要求小於 \(10^{-6}\)）；有摩擦時，熱能另外用 \(\mu N\,ds\) 的數值積分核對。
  • 離開軌道後小車是拋體，用解析解計算。落回軌道時，垂直軌道的速度分量完全損失（完全非彈性），損失的動能算進熱能；落到地面時，動能全部變成熱能並停住。
  • 簡化：靜摩擦係數取與 μ 相同；忽略空氣阻力、滾動阻力與輪子的轉動；畫面上小車的大小只是為了看得清楚。
