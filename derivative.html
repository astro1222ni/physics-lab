背後的數學

從割線到切線

在曲線上取點 \(A = (a, f(a))\) 和另一點 \(B = (a + h, f(a + h))\)。通過這兩點的直線叫割線，它的斜率叫差商：

\[ \frac{\Delta y}{\Delta x} = \frac{f(a + h) - f(a)}{h} \]

讓 \(B\) 沿著曲線往 \(A\) 靠近。如果不論 \(B\) 從哪一邊靠近，割線都趨近同一條直線，這條直線就是 \(A\) 點的切線，它的斜率就是 \(f\) 在 \(a\) 的導數：

\[ f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h} \]

切線方程式是 \(y = f'(a)(x - a) + f(a)\)。注意 \(h\) 從來沒有真的等於 0（那樣會變成 \(\tfrac00\)）。極限問的是：\(h\) 夠小的時候，差商可以多接近哪一個值。把光滑的曲線放大來看，它越來越像一條直線，切線就是那條直線。

導數本身也是一個函數

每一個點 \(a\) 都有自己的切線斜率，所以 \(x \mapsto f'(x)\) 是一個新的函數，叫導函數。\(f\) 上升的地方 \(f' > 0\)，下降的地方 \(f' < 0\)，山頂和谷底的切線是水平的，\(f' = 0\)。下方的圖會在 \(A\) 沿著曲線走的時候，一點一點描出 \(f'\)。這裡五種函數的導函數是：

\[ (ax^3 + bx^2 + cx + d)' = 3ax^2 + 2bx + c, \quad (\sin x)' = \cos x, \quad (e^x)' = e^x, \quad (\ln x)' = \frac1x, \quad |x|' = \begin{cases} 1 & x > 0 \\ -1 & x < 0 \end{cases} \]

例如 \(f(x) = x^3\)：\(\dfrac{(a + h)^3 - a^3}{h} = 3a^2 + 3ah + h^2\)，\(h \to 0\) 時趨近 \(3a^2\)。而 \(e^x\) 是每一點的斜率都等於自己高度的函數。

尖角沒有切線

\(|x|\) 的圖形在 \(x = 0\) 有一個尖角。從右邊靠近，割線斜率永遠是 \(1\)；從左邊靠近，永遠是 \(-1\)。左右極限不相等，極限不存在，所以 \(|x|\) 在 0 不可微——雖然它在 0 是連續的。可微一定連續，連續卻不一定可微。

差商有多準？

在 \(a\) 附近，光滑的函數可以寫成 \(f(a + h) = f(a) + f'(a)h + \tfrac12 f''(a)h^2 + \tfrac16 f'''(a)h^3 + \cdots\)（泰勒展開），所以

\[ \frac{f(a + h) - f(a)}{h} = f'(a) + \tfrac12 f''(a)\,h + \cdots, \qquad \frac{f(a + h) - f(a - h)}{2h} = f'(a) + \tfrac16 f'''(a)\,h^2 + \cdots \]

單邊差商大約差 \(\tfrac12 f''(a)h\)：\(h\) 減半，誤差也減半。對稱差商左右各取一點，把 \(h\) 的項消掉，大約只差 \(\tfrac16 f'''(a)h^2\)：\(h\) 減半，誤差剩四分之一。在兩軸都是對數刻度的誤差圖上，它們分別是斜率 1 和斜率 2 的直線。計算機和電腦算數值微分常用對稱差商，就是這個原因——但在 \(|x|\) 的尖角，它會算出 \(0\)，一個根本不存在的「斜率」。

斜率就是速度

如果 \(f(t)\) 是車子在時刻 \(t\) 的位置，割線斜率 \(\dfrac{f(t + h) - f(t)}{h}\) 就是這段時間 \(h\) 的平均速度，導數 \(f'(t)\) 就是瞬時速度，也就是速率表上的讀數。勾選「當成位置－時間圖來看」，圖上的名稱會換成物理的說法，下方的圖就是速度－時間圖。速度再對時間微分，就是加速度。

觀察重點

  • 左右兩邊：把 \(B\) 放在右邊縮小 \(h\)，再放到左邊縮小。兩條割線最後是不是同一條？到 \(|x|\) 的尖角再試一次。
  • 山頂與谷底：下方的 \(f'(x)\) 在哪裡等於 0？那裡上方的曲線長什麼樣子？
  • 似曾相識：沿著 \(\sin x\) 走一遍，下面描出來的像哪一個函數？\(e^x\) 呢？
  • 減半還是剩四分之一：\(h\) 從 0.1 變到 0.01 時，差距變成幾分之一？勾選對稱差商再看一次。
  • 通過原點：\(e^x\) 在哪一點的切線會通過 \((0, 0)\)？\(\ln x\) 呢？

計算方法

  • 頁面上所有的導數都用上面的公式直接算，不用數值近似；差商另外計算，用來和導數比較。單元測試在上千個隨機點，用高精度的數值微分檢查公式，也檢查誤差項 \(\tfrac12 f''h\)、\(\tfrac16 f'''h^2\)、\(|x|\) 的尖角、\(\ln x\) 的定義域，以及每一道挑戰題都有解。
  • 挑戰時，\(A\) 和「\(f'(x)\) 等於目標斜率」的點相差不超過 0.02 就算對準。\(h\) 最小是 0.001，離電腦的捨入誤差會造成影響的範圍還很遠。
