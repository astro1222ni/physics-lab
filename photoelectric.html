密立坎圖：最佳直線

背後的物理

頻率 \(f\) 的光由一份一份的能量——光子——組成，每個光子的能量 \(E = hf = hc/\lambda\)，其中 \(h = 6.626\times10^{-34}\ \mathrm{J\,s}\) 是普朗克常數。一個光子把全部能量交給一個電子；電子要離開金屬，至少要付出功函數 \(\phi\)，剩下的變成動能。所以最快的光電子動能為（愛因斯坦，1905）：

\[ K_{\max} = hf - \phi \qquad (hf > \phi) \]

如果 \(hf \le \phi\)，不論光多強都打不出電子：每個光子的能量都不夠，光子再多也沒用。能打出電子的最低頻率稱為截止頻率：

\[ f_0 = \frac{\phi}{h}, \qquad \lambda_0 = \frac{c}{f_0} = \frac{hc}{\phi}, \qquad hc \approx 1240\ \mathrm{eV\,nm} \]

停止電壓

讓陽極的電位比陰極低（\(V < 0\)）。兩板間的電場把電子往回推，電子要到達陽極必須花掉動能 \(e|V|\)。當 \(|V|\) 達到停止電壓 \(V_s\) 時，連最快的電子也會折返，電流變成零：

\[ eV_s = K_{\max} = hf - \phi \quad\Longrightarrow\quad V_s = \frac{h}{e}\,f - \frac{\phi}{e} \]

所以 \(V_s\) 對 \(f\) 的圖（密立坎圖，來自密立坎 1916 年的實驗）是一條直線：斜率 \(h/e\) 對每種金屬都一樣，在 \(f\) 軸的截距是 \(f_0\)，在 \(V_s\) 軸的截距是 \(-\phi/e\)。把斜率乘上 \(e = 1.602\times10^{-19}\ \mathrm{C}\) 就得到 \(h\)。

電流與光的強度

功率 \(P\) 的光每秒帶來 \(N = P/hf\) 個光子；每個光子以很小的機率 \(\eta\)（量子效率）打出一個電子。當所有光電子都被陽極收集時，電流達到飽和電流：

\[ I_{\text{sat}} = \eta\, e N = \eta\, e\,\frac{P}{hf} \;\propto\; P \]

光的強度加倍，電子數加倍，每個電壓下的電流都加倍；但 \(K_{\max}\) 與 \(V_s\) 不變。功率相同時，頻率越高的光每個光子能量越大、光子數越少，所以飽和電流反而較小。

觀察重點

  • 有門檻，不是越亮越好：選鈉、紅光（650 nm），把光調到最強——一個電子也沒有。再把波長往短的方向調，一過 \(\lambda_0 = 544\ \mathrm{nm}\) 就突然有電子射出，即使光很弱也一樣。
  • \(K_{\max}\) 與光的強度無關：先找到停止電壓，再改變光的強度：電流變了，但仍在同一個 \(V\) 剛好歸零。
  • 電流與光的強度成正比：在任一固定電壓，\(P\) 加倍、電流表讀數也加倍；整條 \(I\)–\(V\) 曲線在垂直方向等比例拉長。
  • 飽和電流：\(V > 0\) 時電場把斜向飛出的電子也拉向陽極；當所有光電子都到達陽極，電流就不再增加，達到 \(I_{\text{sat}}\)。
  • 測量普朗克常數：同一種金屬，在三個以上、相差很大的頻率記錄停止電壓；最佳直線的斜率乘上 \(e\) 就是 \(h\)。換另一種金屬再做：直線互相平行（\(h\) 相同），但左右平移（\(\phi\) 不同）。
  • 多數金屬要紫外線：鋅、銅、鉑都要紫外線（\(\lambda_0 < 300\ \mathrm{nm}\)）才打得出電子——這正是赫茲（1887）發現紫外線讓火花更容易跳過的原因；只有鹼金屬在可見光下就有光電效應。

模擬方法

  • 光子能量、\(K_{\max}\)、\(V_s\)、\(f_0\)、\(\lambda_0\) 直接由上面的公式計算，\(h\)、\(e\)、\(c\) 用 SI 定義值；功函數採課本常用值（Cs 2.1、K 2.3、Na 2.28、Zn 4.3、Cu 4.7、Pt 5.6 eV）。有些課本的鉑寫 6.35 eV：功函數的實測值會隨金屬表面狀態（晶面、乾淨程度）與量測方法而不同，所以不同的表會有差異。
  • 光電管簡化為相距 1.0 cm 的兩片平行板（陰極寬 1.4 cm、陽極寬 3.0 cm），板間為均勻電場 \(E = V/d\)。每個電子從陰極上隨機一點出發，動能在 0 到 \(K_{\max}\) 之間均勻分布（簡化），方向依餘弦定律隨機，之後做加速度 \(a = eV/(m_e d)\) 的等加速度運動，軌跡用精確公式計算。
  • 電流表顯示期望的電流 \(I = \eta e N F\)，\(F\) 是落在陽極上的電子比例，由所有出發點、能量與方向積分而得（誤差小於 0.01%）。量子效率取 \(\eta = 10^{-3}\)（乾淨金屬的典型數量級），並假設與波長無關；電流表解析度 0.001 nA。
  • 「記錄停止電壓」只接受「電流表讀數為零，但電壓往正方向 0.05 V 時不為零」的電壓，所以密立坎圖上的每一點都是真正測到「電流剛好歸零」的位置；最佳直線用最小平方法求出。
