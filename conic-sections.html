圓錐曲線：用平面切圓錐

用一個平面去切雙圓錐，切口會是圓、橢圓、拋物線或雙曲線——是哪一種，只看平面和圓錐比起來傾斜得多陡。轉動、移動切平面，再拖曳曲線上的點 P，看它到兩個焦點的距離「和」、「差」以及到準線的距離「比」怎麼保持不變。兩顆丹德林球告訴你焦點和準線是從哪裡來的；切換到 3D 可以在空間中看清楚。

試試看：把切平面的角度 β 從 90° 慢慢轉到 0°，看切口怎麼從圓變成橢圓、拋物線，最後變成雙曲線。

左邊是過圓錐軸的剖面（點 P 與過 P 的母線是投影上去的）；右邊是正對切平面看到的切口，x′ 軸沿著主軸。長度以「單位長」計，格線間距標在各圖角落。

拖曳旋轉，滾輪或雙指縮放，右鍵或雙指拖曳平移；拖曳綠色的點 P 可以沿曲線移動。

背後的數學

把圓錐的每一條母線都越過頂點延長，就得到上下兩個尖端相接的雙圓錐；母線與軸的夾角 α 稱為半頂角。用一個不通過頂點的平面去切它，切口只可能是四種曲線之一：圓、橢圓、拋物線、雙曲線，所以它們合稱圓錐曲線。會切出哪一種，只取決於切平面與軸的夾角 β 和 α 誰大誰小：

  • \(\beta = 90^\circ\)（平面垂直於軸）：圓；
  • \(\alpha < \beta < 90^\circ\)：橢圓——平面整個橫切過一個錐；
  • \(\beta = \alpha\)（平面與一條母線平行）：拋物線；
  • \(0^\circ \le \beta < \alpha\)：雙曲線——平面同時切到上下兩個錐，所以曲線有兩支。

頂點到切平面的距離 \(d\) 只改變大小：整個圖形依 \(d\) 等比例縮放，形狀（離心率）不變。

丹德林球：焦點從哪裡來

在圓錐裡放一顆球，讓它沿著一整圈圓貼住錐面，同時剛好碰到切平面上的一點。這樣的球最多兩顆（切平面兩側各一顆），稱為丹德林球，因比利時數學家丹德林（G. P. Dandelin）在 1822 年用它們證明而得名。球碰到切平面的那一點就是焦點。整個證明只靠一件事：從球外一點畫到同一顆球的切線段，長度全都相等。

在曲線上任取一點 \(P\)，沿著過 \(P\) 的母線走，會碰到兩個相切圓於 \(K_1\)、\(K_2\)。\(PF_1\) 與 \(PK_1\) 都是從 \(P\) 到球 1 的切線段，所以 \(PF_1 = PK_1\)；同理 \(PF_2 = PK_2\)。橢圓的兩顆球在同一個錐裡，\(P\) 夾在兩個圓之間，因此

\[ PF_1 + PF_2 = PK_1 + PK_2 = K_1K_2 = 2a \]

\(K_1K_2\) 是兩個相切圓之間沿母線量的距離，每一條母線都一樣長，所以這個和永遠不變。雙曲線的兩顆球分在上下兩個錐，\(K_1K_2\) 穿過頂點，於是不變的是「差」：

\[ \left| PF_1 - PF_2 \right| = \left| PK_1 - PK_2 \right| = K_1K_2 = 2a \]

準線，以及為什麼 e = cos β ／ cos α

每一個相切圓都躺在一個水平面上，這個水平面和切平面交於一條直線，就是這個焦點的準線。設 \(P\) 到這個水平面的高度差為 \(h\)。沿母線走到 \(K\)，因為母線和鉛直的軸夾 \(\alpha\) 角，走了 \(PK = h/\cos\alpha\)；在切平面內筆直走到準線，因為平面上最陡的方向和軸夾 \(\beta\) 角，走了 \(PD = h/\cos\beta\)。所以

\[ \frac{PF}{PD} = \frac{PK}{PD} = \frac{h/\cos\alpha}{h/\cos\beta} = \frac{\cos\beta}{\cos\alpha} = e \]

曲線上每一點的這個比值都一樣，這個常數就是離心率 \(e\)。\(\beta > \alpha\) 時 \(e < 1\)（橢圓），\(\beta = \alpha\) 時 \(e = 1\)（拋物線），\(\beta < \alpha\) 時 \(e > 1\)（雙曲線）。圓（\(\beta = 90^\circ\)）的水平面和切平面平行，交不出準線（準線在無窮遠處），\(e = 0\)。

標準式與 a、b、c

把切平面攤平，以曲線的主軸為 \(x'\) 軸、中心（拋物線用頂點）為原點：

  • 橢圓：\(\dfrac{x'^{2}}{a^{2}} + \dfrac{y'^{2}}{b^{2}} = 1\)，\(c^{2} = a^{2} - b^{2}\)；
  • 雙曲線：\(\dfrac{x'^{2}}{a^{2}} - \dfrac{y'^{2}}{b^{2}} = 1\)，\(c^{2} = a^{2} + b^{2}\)，漸近線 \(y' = \pm\dfrac{b}{a}\,x'\)；
  • 拋物線：\(y'^{2} = 4p\,x'\)。

焦點在 \((\pm c, 0)\)，準線是 \(x' = \pm a/e\)，而 \(e = c/a\)；拋物線的焦點在 \((p, 0)\)、準線是 \(x' = -p\)。過焦點而且垂直主軸的弦稱為正焦弦，長度是 \(2b^{2}/a\)（拋物線是 \(4p\)）。把切平面 \(\vec m\cdot\vec X = d\) 代入圓錐的方程式再配方，所有長度都能直接由 \(\alpha\)、\(\beta\)、\(d\) 算出：

\[ a = \frac{d\sin\alpha\cos\alpha}{\left|\cos^{2}\alpha - \cos^{2}\beta\right|},\qquad b = \frac{d\sin\alpha}{\sqrt{\left|\cos^{2}\alpha - \cos^{2}\beta\right|}},\qquad p = \frac{d\tan\alpha}{2} \]

兩顆丹德林球的球心在軸上，離頂點 \(\dfrac{d}{\sin\beta + \sin\alpha}\) 與 \(\dfrac{d}{\left|\sin\beta - \sin\alpha\right|}\)，半徑是這個距離乘以 \(\sin\alpha\)。\(\beta = \alpha\) 時第二個距離變成無限大：拋物線只有一顆丹德林球、一個焦點。

退化的切口

切平面通過頂點（\(d = 0\)）時，切口就不再是真正的曲線：\(\beta > \alpha\) 只剩頂點一點；\(\beta = \alpha\) 時平面貼著錐面的一條母線，切口是一條直線；\(\beta < \alpha\) 時切出兩條在頂點相交的直線。它們都是 \(d \to 0\) 的極限：橢圓縮成一點，雙曲線縮到貼著自己的漸近線，漸近線與主軸的夾角 \(\varphi\) 滿足 \(\cos\varphi = 1/e\)。

觀察重點

  • 從圓到雙曲線：固定 \(\alpha\)，把 \(\beta\) 從 \(90^\circ\) 慢慢轉到 \(0^\circ\)。\(e\) 恰好在 \(\beta\) 越過 \(\alpha\) 時超過 1。切口快變成拋物線時，第二顆丹德林球跑到哪裡去了？
  • 和不變：拖曳 \(P\) 繞橢圓一圈，在幾個地方按「記下這一點」。\(PF_1\)、\(PF_2\) 各自改變，和卻永遠是 \(2a\)。
  • 另一支：在雙曲線上把 \(P\) 拖到另一支。現在哪個焦點比較近？差還是 \(2a\) 嗎？
  • 比值：打開準線，看 \(P\) 走到哪裡，\(PF_1/PD_1\) 都等於 \(e\)。
  • 只變大小：只改 \(d\)。曲線放大或縮小，\(e\)、漸近線的方向與丹德林球的配置形狀卻不變。為什麼？
  • 立體的證明：切換到 3D，打開「過 P 的母線與切點 K」，轉動視角，看出 \(PF_1\) 和 \(PK_1\) 為什麼一樣長。

計算方法

  • 全部由上面的公式精確計算（沒有數值近似）。頂點在原點、軸是 \(z\) 軸；切平面垂直於 \(xz\) 平面，所以左圖畫的正是過軸的真實剖面。
  • 丹德林球由兩個相切條件求出（球心到母線、到切平面的距離都等於半徑）；焦點是切點，準線是相切圓所在平面與切平面的交線。單元測試在上千條曲線的隨機點上檢查 \(PF_1 + PF_2 = 2a\)、\(\left|PF_1 - PF_2\right| = 2a\)、\(PF = e\cdot PD\)、\(PF = PK\) 與標準式，誤差都在 \(10^{-9}\) 左右。
  • 拖曳 P 時，程式找出曲線上離手指最近的點（先粗略掃描，再用黃金分割法細找）。
  • 每一張圖的縮放只依 α 和 β 決定（以 d = 3 的大小來安排），所以改變 d 時圖形真的會變大變小；需要換縮放比例時，畫面會平順地移過去。
  • 3D 檢視的圓錐、切平面、曲線與球，和 2D 用的是同一組計算結果，以 three.js 函式庫（MIT 授權）繪製，只有切換到 3D 時才會下載。圓錐只畫到有限的長度，數學上的圓錐是無限延伸的。
