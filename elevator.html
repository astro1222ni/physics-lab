電梯中的視重（超重與失重）

站在電梯裡的體重計上搭電梯：電梯加速、等速、減速時，體重計的讀數怎麼變？對照同步的 a–t、v–t、y–t 與讀數–t 圖，看出讀數由「加速度」決定，而不是由速度決定。最後剪斷纜繩體驗完全失重，再用緊急煞車讓電梯停下來。

背後的物理

實重與視重

不論電梯怎麼動，地球對你的吸引力都是重量 \(W = mg\)（實重）。體重計量的不是這個力，而是你壓在它上面的力，大小等於它把你往上推的正向力 \(N\)，這個讀數稱為視重。取向上為正，設電梯（和你）的加速度為 \(a\)。你只受兩個力，由牛頓第二定律：

\[ N - mg = ma \;\Rightarrow\; N = m(g + a) \]

體重計的刻度是公斤重（kgw）：1 公斤重是 1 kg 物體的重量，\(1\ \mathrm{kgw} = 9.8\ \mathrm{N}\)。所以體重計受到 \(N\) 的壓力時，顯示

\[ \text{讀數（kgw）} = \frac{N}{9.8\ \mathrm{N/kgw}} = m\left(1 + \frac{a}{g}\right) \]

靜止或等速（\(a = 0\)）時，讀數就是你的質量的公斤重數，例如 60 kg 的人顯示 60 kgw。若 \(a = +1.96\ \mathrm{m/s^2} = 0.2g\)，同一個人顯示 \(60 \times 1.2 = 72\ \mathrm{kgw}\)。

電梯的運動 a 的方向 讀數
加速上升；減速下降向上（a > 0）\(N \gt mg\)：超重
減速上升；加速下降向下（a < 0）\(N \lt mg\)：失重
靜止，或等速上升、等速下降a = 0\(N = mg\)：正常
自由落體（纜繩斷裂）——即使還在往上運動a = −g\(N = 0\)：完全失重

讀數只由加速度決定，與電梯往上或往下、速度多快都無關：以 6 m/s 等速上升時的讀數，和靜止時完全一樣。

哪一對才是作用力與反作用力？

體重計以 \(N\) 把你往上推；由牛頓第三定律，你以同樣大小的力 \(N'\) 往下壓體重計。\(N\) 與 \(N'\) 是一對作用力與反作用力：大小相等、方向相反、作用在不同物體上，而且永遠如此，電梯加速時也一樣。反觀 \(mg\) 與 \(N\) 都作用在你身上，它們不是一對，只有在 \(a = 0\) 時才相等。（重量的反作用力是你對地球的引力。）

\[ \begin{gathered} \vec{N}_{\text{秤對人}} = -\vec{N}'_{\text{人對秤}} \ \ \text{（永遠成立）} \\ N - mg = ma \ \ \text{（}a \ne 0 \text{ 時 } N \ne mg\text{）} \end{gathered} \]

一趟典型的行程

按下樓層按鈕後，電梯以「梯形」的 v–t 圖運動：以 \(A\) 加速到最高速率 \(V\)，等速前進，再以 \(A\) 減速，剛好停在樓層。行程距離為 \(d\) 時：

\[ \begin{gathered} t_{\text{加速}} = t_{\text{減速}} = \frac{V}{A} \\ t_{\text{總}} = \frac{d}{V} + \frac{V}{A} \quad \left(d \ge \frac{V^{2}}{A}\right) \end{gathered} \]

如果行程太短、來不及加速到 \(V\)（\(d \lt V^2/A\)），v–t 圖是三角形，最高速率 \(\sqrt{Ad}\)、總時間 \(2\sqrt{d/A}\)。無論哪一種，a–t 圖下的面積都是速度的變化（整趟為零），v–t 圖下的面積就是位移。

纜繩斷裂與緊急煞車

纜繩斷了以後，電梯只受重力，做 \(a = -g\) 的自由落體：車廂裡的東西一起落下，體重計讀數為 \(0\)、彈簧秤讀數也是 \(0\)，完全失重。下降速率達到 \(v_{\text{trip}}\)（或你按下緊急煞車）時，安全鉗夾住導軌，以 \(a_b\) 減速（這時 \(a = +a_b\)，向上），讀數跳到 \(m(1 + a_b/g)\)。從靜止開始，總共下降

\[ \Delta y = \frac{v_{\text{trip}}^{2}}{2g} + \frac{v_{\text{trip}}^{2}}{2a_b} \]

彈簧秤與落下的小球

吊在彈簧下的物體 \(m_s\) 也一樣：彈簧拉它的力 \(T = m_s(g + a)\)，彈簧伸長 \(x = T/k\)。在電梯裡，一切就像重力加速度變成了 \(g_{\text{eff}} = g + a\)。所以從高度 \(h\) 放開的小球，落到地板需要

\[ t = \sqrt{\frac{2h}{g + a}} \]

自由落體時 \(g + a = 0\)：小球浮在你面前，直到開始煞車才落下。

觀察重點

  • 從 1F 搭到 10F，看圖表的底色：加速時超重、等速時正常、減速時失重。再搭回 1F：順序剛好相反。
  • 速度不影響讀數：設 \(V = 6\ \mathrm{m/s}\)、\(A = 1\ \mathrm{m/s^2}\)。電梯以 6 m/s 等速前進時，讀數剛好等於你的質量的公斤重數。
  • 運動相反，讀數相同：加速上升與減速下降的讀數一樣，因為加速度都向上。
  • 由讀數算加速度：\(a = g\,(\text{讀數}/m - 1)\)。到「神秘電梯」試試看。
  • 剪斷纜繩：體重計、彈簧秤讀數與彈簧伸長量同時變成 0，指針指向 0。在落下途中放開小球——它會浮在空中。
  • 在電梯上升途中剪斷纜繩：電梯還會再往上衝一小段，但讀數已經是 0。完全失重代表 \(a = -g\)，不是「往下運動」。
  • 第三定律：受力圖中藍色的 \(N\)（作用在人）與 \(N'\)（作用在秤）永遠一樣長；紅色的 \(mg\) 只有在 \(a = 0\) 時才和 \(N\) 一樣長。

模擬方法

  • 運動由一段一段的等加速度運動組成（加速、等速、減速、自由落體、煞車），每一段都用 \(y = y_0 + v_0 t + \tfrac12 a t^2\)、\(v = v_0 + a t\) 精確計算，沒有累積的數值誤差；圖表也直接由這些公式畫出。
  • 人與吊掛物體隨電梯一起運動（相對電梯靜止），所以體重計與彈簧秤立即反映；真實的指針與彈簧在加速度突然改變時會短暫晃動。
  • 小球放開後只受重力。在電梯的每一段運動中，小球離地板的高度是時間的二次式，逐段精確解出落地時刻。
  • g = 9.8 m/s²，每層樓高 3.0 m（1F 在 y = 0、10F 在 y = 27 m）。不計空氣阻力與纜繩質量。真實的電梯會讓加速度平順地變化，這裡和課本題目一樣，加速度是一段一段的定值。
  • 動畫以真實時間播放（慢動作時為 0.25 倍）；讀數中的時間是物理時間。
