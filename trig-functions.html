三角函數：單位圓與正弦波

讓一個點繞著單位圓轉，把它的高度一路往右畫，就畫出正弦曲線。接著用 y = A sin(ωx + φ) + k 把波拉高、壓扁、平移，把一個正弦和一個餘弦疊合成一個波，再挑戰對準一條神祕的目標曲線。切換到 3D，會看到每一條正弦波其實都是一條螺旋線的影子。

試試看：按「播放」，看點 P 繞著圓轉、它的高度在右邊畫出正弦曲線；再自己拖曳 P 轉轉看。

兩格的縱軸用同一個比例，所以 P 的高度可以水平對到右邊的圖形上。圖形的 x 軸單位是弧度：沿 x 軸走多遠，就等於在單位圓上走了多長的弧。

拖曳旋轉，滾輪或雙指縮放，右鍵或雙指拖曳平移。從側面、從下面、從正面各看一次。

背後的數學

單位圓：任何角度都有 sin、cos、tan

以原點為圓心，畫一個半徑 1 的圓。從正 \(x\) 軸出發，逆時針轉 \(\theta\) 角，終邊和圓交於點 \(P\)。\(P\) 的坐標就是餘弦和正弦：

\[ P = (\cos\theta,\ \sin\theta), \qquad \tan\theta = \frac{\sin\theta}{\cos\theta}, \qquad \sin^{2}\theta + \cos^{2}\theta = 1 \]

銳角時，這和直角三角形的三角比一致（斜邊就是半徑 1）；但單位圓對任何角都適用：鈍角、負角、轉超過一圈都可以。正負號由 \(P\) 落在哪個象限決定；\(\tan\theta\) 是終邊的斜率，也就是終邊和鉛直線 \(x = 1\) 交點的高度，在 \(\cos\theta = 0\) 時沒有定義。多轉一整圈，\(P\) 回到原處，所以 \(\theta\) 和 \(\theta + 360^\circ\)（同界角）的三角函數值都一樣。

弧度：用走過的弧長量角度

在半徑 1 的圓上，\(x\) 弧度的圓心角所對的弧長恰好是 \(x\)。半圈的弧長是 \(\pi\)，所以 \(\pi\ \text{rad} = 180^\circ\)、\(1\ \text{rad} = \frac{180^\circ}{\pi} \approx 57.3^\circ\)。這就是函數圖形的 \(x\) 軸用弧度的原因：沿 \(x\) 軸走 \(x\) 的距離，等於在圓上走了長度 \(x\) 的弧——整個圓周被「攤開」成一條直線。

從圓到波

讓 \(P\) 一直轉，把它的高度一路往右畫，就是 \(y = \sin x\) 的圖形：每 \(2\pi\) 重複一次（週期），值永遠在 \(-1\) 和 \(1\) 之間。\(P\) 的左右位置畫出 \(y = \cos x\)，是同一條曲線往左平移四分之一個週期：\(\cos x = \sin\!\left(x + \frac{\pi}{2}\right)\)。正切每 \(\pi\) 重複一次，在 \(\cos x = 0\) 的地方衝向無限大。

y = A sin(ωx + φ) + k 的四個旋鈕

  • \(|A|\) 是振幅：最大值 \(k + |A|\)、最小值 \(k - |A|\)。\(A\) 是負的，波上下翻轉，效果和相位加上 \(\pi\) 一樣。
  • \(\omega\) 把波左右壓縮：週期 \(T = \dfrac{2\pi}{\omega}\)。
  • \(\varphi\) 是相位。把 \(\omega x + \varphi\) 寫成 \(\omega\left(x + \dfrac{\varphi}{\omega}\right)\)：\(y = \sin(\omega x)\) 的圖形往左平移 \(\dfrac{\varphi}{\omega}\)，不是平移 \(\varphi\)。
  • \(k\) 把整條波往上移；直線 \(y = k\) 是中線。

左邊的單位圓這時變成參考圓：半徑 \(|A|\)、圓心在高度 \(k\)。圓上一點以角速度 \(\omega\) 轉動、起始角是 \(\varphi\)，它的高度就是 \(y\)。物理裡的簡諧運動和波動，正是這樣描述的。

正弦與餘弦的疊合

同一個 \(x\) 的正弦加餘弦，仍然是一個正弦波。用和角公式展開 \(r\sin(x + \varphi) = r\cos\varphi\,\sin x + r\sin\varphi\,\cos x\)，比較係數得到

\[ a\sin x + b\cos x = r\sin(x + \varphi), \qquad r = \sqrt{a^{2} + b^{2}}, \quad \cos\varphi = \frac{a}{r}, \quad \sin\varphi = \frac{b}{r} \]

從幾何來看，\(a\sin x\) 是長度 \(a\)、轉了 \(x\) 角的箭頭的高度，\(b\cos x\) 是長度 \(b\)、轉了 \(x + 90^\circ\) 的箭頭的高度。兩支箭頭永遠互相垂直，所以合起來是一支長度 \(\sqrt{a^{2} + b^{2}}\) 的箭頭——就是畢氏定理。因此 \(a\sin x + b\cos x\) 的最大值是 \(r\)，最小值是 \(-r\)。

每一條正弦波都是螺旋線的影子

讓點一邊繞圓轉、一邊沿著第三個方向等速前進，就畫出一條螺旋線 \(\big(x,\ A\cos(\omega x + \varphi),\ A\sin(\omega x + \varphi) + k\big)\)。從側面看，它的影子是正弦波；從下面看，是餘弦波；從正前方看，只剩一個圓。3D 檢視把三個影子同時畫出來。

觀察重點

  • 各象限的正負：拖曳 \(P\) 繞一圈。\(\sin\theta\) 在哪些象限是正的？\(\cos\theta\) 呢？\(\tan\theta\) 呢？
  • 兩個角、同一個正弦：\(0^\circ\) 到 \(360^\circ\) 之間有兩個角的 \(\sin\theta = \frac12\)。為什麼一條水平線會和圓交於兩點？
  • 相位與週期一起看：把 \(\omega\) 設成 2，再改 \(\varphi\)。波移動的距離只有 \(\omega = 1\) 時的一半，為什麼？
  • 一條曲線、好幾種寫法：你能用負的 \(A\) 調出 \(y = 2\cos x\) 嗎？
  • 3、4、5：在疊合模式設 \(a = 3\)、\(b = 4\)。相加後最高到多少？在哪裡？
  • 三個影子：在 3D 裡把螺旋線轉到順著它的軸看過去，還剩下什麼？

計算方法

  • 所有數值直接由 \(\sin\)、\(\cos\) 算出；\(90^\circ\) 的整數倍用精確值 \(0\)、\(\pm1\)，\(15^\circ\) 的倍數另外顯示根式的精確值（例如 \(\sin 15^\circ = \frac{\sqrt6 - \sqrt2}{4}\)）。單元測試在上千個隨機點檢查 \(\sin^{2}\theta + \cos^{2}\theta = 1\)、各象限的正負號、\(-360^\circ\) 到 \(720^\circ\) 每一個精確值、週期、第一個最高點，以及 \(a\sin x + b\cos x = r\sin(x + \varphi)\)。
  • 挑戰時，只要你的曲線在整個畫面上和目標相差都不超過 0.05 就算對準，所以寫法不同、但畫出同一條曲線也算。
  • 縱軸的比例會分級調整，讓整條波放得下，比例看格線上的刻度。3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才下載。
