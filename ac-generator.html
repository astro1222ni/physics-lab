交流發電機與變壓器

讓線圈在磁場中轉動，穿過線圈的磁通量時增時減，就產生了交流電動勢。看看為什麼磁通量為零的那一刻電動勢反而最大；把滑環換成換向器，得到脈動直流；體會冷次定律——取用的電流越大，水輪機就要出越大的力。接著把電送進鐵心變壓器（順便弄清楚電池為什麼不能變壓），最後送上長長的輸電線：把電壓升高，看線電流與線損一起下降，再降回 110 V 送進家家戶戶。

試試看：在端視圖把線圈拖到 90°（磁通量為零），再按「播放」，看電動勢是不是正好在這一刻最大。

實驗模式

發電機

轉速由帶動轉軸的外力（例如水輪機）維持固定：它提供的力矩正好抵銷磁力造成的阻力矩。

變壓器

發電機的電動勢、頻率與線圈電阻 r 在「發電機」模式設定；接到變壓器時一律用滑環輸出。

輸電

用戶被當成一個大電阻 Ru = V額定2/P額定：實際拿到的電壓偏低，用電功率也跟著變小。

讀數

記錄表

實驗目的

  1. 了解線圈在均勻磁場中轉動，如何產生正弦變化的電動勢，以及為什麼磁通量為零時電動勢最大。
  2. 用冷次定律與能量守恆，說明發電機供應的電流越大、為什麼越難轉動。
  3. 驗證理想變壓器的關係式，看出變壓器為什麼不能用在直流上，並理解電力為什麼要用高壓輸送。

原理

1. 交流發電機

\(N\) 匝的矩形線圈，沿轉軸的邊長 \(L\)、寬 \(w\)，在均勻磁場 \(B\) 中以固定角速度 \(\omega = 2\pi f\) 轉動。令 \(\theta\) 為線圈面積向量與 \(\vec B\) 的夾角，\(\theta = \omega t\)，每一匝的磁通量是

\[ \Phi_B = BA\cos\theta, \qquad A = Lw \]

由法拉第定律，整個線圈的電動勢是

\[ \varepsilon = -N\frac{d\Phi_B}{dt} = NBA\omega\sin\theta, \qquad \varepsilon_{\max} = NBA\omega, \qquad \varepsilon_{\text{rms}} = \frac{\varepsilon_{\max}}{\sqrt2} \]

磁通量是餘弦、電動勢是正弦，兩者相差四分之一圈（90°）。線圈正對磁場（\(\theta = 0\)）時磁通量最大，但這一瞬間磁通量不變，所以 \(\varepsilon = 0\)；線圈平行磁場（\(\theta = 90^\circ\)）時沒有磁力線穿過，磁通量卻變化得最快，\(\varepsilon\) 最大。

另一個觀點：只有兩條長邊在切割磁力線。每條長邊沿半徑 \(w/2\) 的圓周運動，速率 \(v = \omega w/2\)，速度垂直於 \(\vec B\) 的分量是 \(v\sin\theta\)，所以每一匝的每一條長邊產生 \(BLv\sin\theta\)，兩邊相加：

\[ \varepsilon = 2NBLv\sin\theta = 2NBL\cdot\frac{\omega w}{2}\sin\theta = NBA\omega\sin\theta \]

兩個觀點得到同一個答案。\(\theta = 90^\circ\) 時長邊正好垂直切過磁力線；\(\theta = 0\) 時長邊順著磁力線走，什麼也沒切到。短邊永遠沒有貢獻：短邊裡的電荷受到的磁力垂直於導線，不會推動電荷沿導線走。

2. 滑環與換向器

用滑環時，線圈的兩端各接一個環，各有一個電刷在環上滑動，外電路得到的就是線圈原本的電動勢：交流電。換向器是一個切成兩半的環，每轉半圈（正好在 \(\varepsilon\) 經過零的時候）兩片半環就交換所接觸的電刷，外電路永遠得到 \(|\varepsilon|\)：在 0 與 \(\varepsilon_{\max}\) 之間脈動的直流電，平均值 \(2\varepsilon_{\max}/\pi\)。線圈裡面的電流仍然是交流。

3. 冷次定律與能量守恆

接上負載 \(R\)，線圈電阻 \(r\)，電流 \(i = \varepsilon/(R + r)\)（忽略線圈自感，\(i\) 與 \(\varepsilon\) 同相）。帶電流的長邊在磁場中受力，這兩個力形成的力矩永遠阻礙轉動，這就是冷次定律：

\[ \tau = NiAB\sin\theta = \frac{(NBA\omega)^2\sin^2\theta}{(R + r)\,\omega} \;\ge\; 0 \]

要維持轉速不變，水輪機必須剛好提供這個力矩。外力的機械功率每一瞬間都等於電功率：

\[ P_{\text{mech}} = \tau\omega = i^2(R + r) = \varepsilon\, i, \qquad \overline{P} = \frac{\varepsilon_{\text{rms}}^2}{R + r} \]

把電路斷開（\(R \to \infty\)）：沒有電流、沒有阻力矩，轉軸可以自由轉動。\(R\) 越小，電流越大，水輪機越吃力。負載本身得到的平均功率是 \(\overline{P}_R = \varepsilon_{\text{rms}}^2 R/(R + r)^2\)。

4. 理想變壓器

兩組線圈繞在同一個鐵心上。一次線圈加上交流電壓 \(v_1\)，鐵心中的磁通量 \(\Phi\) 跟著變化，使 \(v_1 = N_1\,d\Phi/dt\)；同一個變化的磁通量也穿過二次線圈，感應出 \(v_2 = N_2\,d\Phi/dt\)。理想變壓器（磁力線全部留在鐵心裡、鐵心與銅線都沒有能量損失、鐵心極容易磁化而且不飽和）滿足

\[ \frac{V_2}{V_1} = \frac{N_2}{N_1}, \qquad I_1V_1 = I_2V_2, \qquad R' = \frac{V_1}{I_1} = \left(\frac{N_1}{N_2}\right)^2 R_L \]

\(v_1\) 與 \(v_2\) 同相（兩組線圈繞的方向相同；把其中一組反過來繞，只是 \(v_2\) 變號）。從一次側看，負載就像一個電阻 \(R'\)：本頁用它解「發電機接變壓器」的電路，\(V_1 = \varepsilon_{\text{rms}}R'/(R' + r)\)。

鐵心中的磁通量峰值 \(\Phi_{\max} = \sqrt2\,V_1/(N_1\omega)\)。真實的鐵約在 1.8～2 T 飽和，所以為 60 Hz 設計的變壓器，若要用在更低的頻率，一次線圈就要更多匝；本頁的鐵心截面積 25 cm²，磁通密度峰值超過 1.7 T 時會提醒你。

5. 直流為什麼不能變壓

接上電池、接通開關：一次線圈的電流（以及鐵心的磁通量）先增加一小段時間，然後就固定不變。只有磁通量正在改變時，二次線圈才有感應電動勢，所以二次側只出現一個短暫的脈衝，之後就什麼都沒有，不管穩定的磁通量有多大。這時一次線圈的電流只受銅線電阻限制，線圈只是白白發熱。切斷開關時磁通量消失，二次側出現一個方向相反的脈衝。

6. 遠距輸電

電壓 \(V_g\) 的發電機，經過升壓變壓器 \(1 : k_1\)、總電阻 \(R_{\text{line}}\) 的輸電線、降壓變壓器 \(k_2 : 1\)，送到用戶 \(R_u\)。理想變壓器會把電阻乘上匝數比的平方，所以在輸電線上看，整條線就是一個串聯電路：

\[ I_{\text{line}} = \frac{k_1V_g}{R_{\text{line}} + k_2^2R_u}, \qquad P_{\text{loss}} = I_{\text{line}}^2R_{\text{line}}, \qquad V_u = \frac{I_{\text{line}}\,k_2^2R_u}{k_2}, \qquad \eta = \frac{k_2^2R_u}{R_{\text{line}} + k_2^2R_u} \]

要送出同樣的功率 \(P\)，電壓 \(V_L\) 的輸電線電流約為 \(P/V_L\)。把電壓提高 \(k\) 倍，電流約變成 \(1/k\)，線損 \(I^2R_{\text{line}}\) 約變成 \(1/k^2\)；最後再由降壓變壓器把電壓降回 110 V 或 220 V，送進家家戶戶。

臺灣的電網頻率是 60 Hz，家用電是 110 V 與 220 V。台電的輸電網以 345 kV 超高壓為骨幹，再經 161 kV、69 kV 逐級降壓，最後由配電系統降到家用電壓。

觀察重點

  • 在 Φ 曲線穿過零時暫停：線圈平行磁場，兩條長邊正好垂直切過磁力線，ε 最大。在 Φ 曲線的最高點暫停，ε 是零。
  • 把 N、B、面積或 f 加倍，電動勢峰值都跟著加倍；f 加倍時，示波器上的週期也減半。
  • 換成換向器：電動勢曲線全部翻到軸的上方，但線圈上的電流箭頭仍然每半圈反向一次。
  • 把 R 調小，看外力矩峰值與功率一起變大。勾選「開路」：力矩變成零、燈泡熄滅，電動勢卻還在。
  • 功率曲線 p(t) 永遠不是負的，而且每轉一圈重複兩次：水輪機一直都在出力，在 θ = 90° 與 270° 時最吃力。
  • 在變壓器模式改 N2，看 v2 曲線變大或變小，但始終和 v1 同步。把 R_L 調小：I2 與 I1 一起變大——一次側的電流是由二次側用多少來決定的。
  • 換成直流電源、接通開關：鐵心的磁通量箭頭亮起來並一直亮著，但只有一開始的瞬間二次側有電壓。
  • 輸電模式先不升壓（k1 = 1）：大部分的功率都損失在線上。把 k1 調高（k2 也跟著調），看線上的紅色光暈慢慢消失。
  • 在 3D 中轉到沿著轉軸看，停在 θ = 90°：長邊正好垂直切過磁力線，線圈裡流動的電荷跑得最快。

問題與討論

  1. 200 匝、面積 0.03 m² 的線圈在 0.2 T 的磁場中以 60 Hz 轉動，求電動勢的峰值與有效值。
    參考答案

    \(\varepsilon_{\max} = NBA\omega = 200 \times 0.2 \times 0.03 \times 2\pi \times 60 \approx 452\ \mathrm V\)；\(\varepsilon_{\text{rms}} = 452/\sqrt2 \approx 320\ \mathrm V\)。

  2. 為什麼腳踏車的發電機打開車燈之後，踩起來比較吃力？
    參考答案

    打開車燈後線圈中有電流，這個電流在磁場中受力，形成阻礙轉動的力矩（冷次定律）。你每秒多作的功 \(\tau\omega\)，正好等於送進燈泡與線圈的電功率。

  3. 理想變壓器 N1 = 500、N2 = 50，一次側接 110 V 交流，二次側接 2.2 Ω 的負載。求 V2、I2、I1。
    參考答案

    \(V_2 = 110 \times 50/500 = 11\ \mathrm V\)，\(I_2 = 11/2.2 = 5\ \mathrm A\)，\(I_1 = I_2 \times 50/500 = 0.5\ \mathrm A\)（檢查：\(110 \times 0.5 = 11 \times 5 = 55\ \mathrm W\)）。

  4. 10 MW 的電力經過 10 Ω 的輸電線送出。比較用 11 kV 與 161 kV 輸送時的線損。
    參考答案

    11 kV 時 \(I \approx 909\ \mathrm A\)，\(I^2R \approx 8.3\ \mathrm{MW}\)，幾乎全損失掉；161 kV 時 \(I \approx 62\ \mathrm A\)，\(I^2R \approx 39\ \mathrm{kW}\)，約 0.4%。（第一個估計太粗略，因為損失已經不小；本頁是用完整的電路解。）

模擬方法

  • 所有數值都由上面的解析式算出，不是一步一步積分。單元測試再用磁通量的數值微分、一個週期的數值平均、每個角度的 \(\tau\omega = i^2(R + r)\)、一個週期的能量收支，以及輸電線的 \(P_g = P_u + P_{\text{loss}}\) 檢查。
  • 簡化：磁極之間的磁場完全均勻、邊緣截然而止；忽略線圈自感（所以 \(i\) 與 \(\varepsilon\) 同相）；不論負載多大，轉速都固定，因為水輪機總是提供所需的力矩。線圈電阻 \(r\) 用滑桿直接設定，不由導線長度推算。
  • 慢動作：每秒 60 圈看不清楚，所以動畫放慢播放（倍率顯示在畫面上），示波器的時間軸是真實的秒數。燈泡亮度與它的瞬時功率成正比（200 W 時全亮）；真實的燈絲在兩個峰之間來不及冷卻，60 Hz 時幾乎看不出閃爍。
  • 變壓器：交流時用理想變壓器的關係（忽略很小的磁化電流）。理想變壓器在直流下沒有意義，所以電池模式另外給一次線圈每匝 0.01 Ω 的電阻，以及磁化電感 \(L_m = \mu_0\mu_rAN_1^2/l\)（\(\mu_r = 2000\)、\(A = 25\ \mathrm{cm^2}\)、\(l = 40\ \mathrm{cm}\)，小型疊片鐵心的示意值）。鐵心中的磁通量箭頭表示磁通量本身：方向跟著 \(\Phi\)，亮度跟著 \(|\Phi|\)。
  • 輸電：全部用理想變壓器當成一個電路解；用戶是純電阻 \(R_u = V_{\text{額定}}^2/P_{\text{額定}}\)。示意圖未依比例；移動的小點在電流越大的地方跑得越快（對數刻度），導線上的紅色光暈隨損失的比例增加。
  • 3D 檢視（使用 three.js 函式庫，MIT 授權，只有切換到 3D 時才下載）：發電機與變壓器由同一個物理核心、與 2D 相同的角度或時刻畫出。磁力線是兩極之間的直線；線圈裡的小點沿著導線移動，速率與電流成正比、方向隨電流反轉；長邊上的箭頭是磁力 \(NiLB\)，它們的力矩阻礙轉動。輸電模式只有 2D 示意圖。
  • 音效（預設關閉）：發電機運轉時有嗡聲，音量跟著 |ε| 起伏、音高隨 f 升高（音高只是示意：真正的 60 Hz 太低，手機喇叭播不出來）；變壓器通交流電時有輕微的嗡聲；直流開關接通或切斷時有喀一聲。
  • 鍵盤：點一下畫面（或用 Tab 移到畫面上）；發電機模式用左右方向鍵把線圈轉 1°（Shift：15°）並暫停。P 播放或暫停，R 記錄。
