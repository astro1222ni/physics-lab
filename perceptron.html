感知器：一條線分兩類

感知器是最早的「會學習的機器」之一：把輸入乘上權重加起來，看總和是正還是負，決定是哪一類。每遇到一個分錯的點，就把權重往正確答案的方向推一點。看分界線怎麼一次修正一點地轉到對的位置，為什麼 AND、OR 學得會，XOR 卻永遠學不會，再到 3D 裡看看「加權和」其實是一片斜面。

試試看：按幾次「單步」，看分錯的點怎麼把線推開；再按「XOR」和「學到收斂」，看看會發生什麼事。

背後的原理

加權和與它的正負

感知器收到兩個數 \(x_1, x_2\)（點的位置），各乘上一個權重，再加上偏差 \(b\)，最後只看結果的正負：

\[ z = w_1 x_1 + w_2 x_2 + b, \qquad \hat{y} = \begin{cases} +1 & z > 0 \\ -1 & z < 0 \end{cases} \]

讓 \(z = 0\) 的點排成一條直線，就是分界線（決策邊界）。向量 \(\mathbf{w} = (w_1, w_2)\) 和分界線垂直，指向 \(+1\) 那一側。偏差其實就是門檻：「\(w_1x_1 + w_2x_2 \ge \theta\) 時輸出 1」等於 \(b = -\theta\)。沒有偏差時，線一定要經過原點。

學習規則

把點一個一個拿給感知器看。類別是 \(y = \pm 1\) 的點如果分對了（\(y\,z > 0\)），什麼都不改；分錯了、或剛好落在線上（\(y\,z \le 0\)），就修正權重：

\[ \mathbf{w} \leftarrow \mathbf{w} + \eta\, y\, \mathbf{x}, \qquad b \leftarrow b + \eta\, y \]

\(\eta > 0\) 是學習率。很多書把同一條規則寫成 \(\mathbf{w} \leftarrow \mathbf{w} + \eta\,(t - \hat{y})\,\mathbf{x}\)，標籤 \(t \in \{0, 1\}\)、輸出 \(\hat{y} \in \{0, 1\}\)：答錯時 \(t - \hat{y}\) 是 \(+1\) 或 \(-1\)，正好就是這裡的 \(y\)。為什麼這樣改有用？修正之後，同一個點的

\[ y\,z_{\text{new}} = y\,z_{\text{old}} + \eta\,\bigl(x_1^2 + x_2^2 + 1\bigr) \]

所以它一定被往自己那一側推。所有點看過一次叫做一輪；一整輪都沒有分錯，就是收斂了，之後再也不會改變。

收斂定理

把偏差當成第三個權重：\(\tilde{\mathbf{x}} = (x_1, x_2, 1)\)、\(\tilde{\mathbf{w}} = (w_1, w_2, b)\)，於是 \(z = \tilde{\mathbf{w}}\cdot\tilde{\mathbf{x}}\)。令 \(R\) 是所有點裡最大的長度 \(\lVert\tilde{\mathbf{x}}\rVert\)，\(\gamma\) 是最大的間隔：存在某個單位向量 \(\mathbf{u}\)，讓每個點都有 \(y\,(\mathbf{u}\cdot\tilde{\mathbf{x}}) \ge \gamma\) 的最大的 \(\gamma\)。只要 \(\gamma > 0\)（資料能用一條直線分開），從 \(\tilde{\mathbf{w}} = \mathbf{0}\) 出發，不論順序、不論學習率，修正次數 \(k\) 一定滿足（Novikoff，1962）

\[ k \le \left(\frac{R}{\gamma}\right)^{2} \]

證明的想法：每修正一次，\(\tilde{\mathbf{w}}\cdot\mathbf{u}\) 至少增加 \(\eta\gamma\)，而 \(\lVert\tilde{\mathbf{w}}\rVert^2\) 最多增加 \(\eta^2R^2\)；所以修正 \(k\) 次之後 \(k\,\eta\gamma \le \tilde{\mathbf{w}}\cdot\mathbf{u} \le \lVert\tilde{\mathbf{w}}\rVert \le \sqrt{k}\,\eta R\)。注意 \(\eta\) 被約掉了：從零出發時，學習率只是把所有權重一起放大縮小，線永遠不變。

一條線做不到的事：XOR

XOR 是「剛好一個輸入是 1」時輸出 +1。把輸入放在 \(\pm 0.6\)，兩個 −1 的點要 \(-0.6w_1 - 0.6w_2 + b < 0\) 和 \(0.6w_1 + 0.6w_2 + b < 0\)，相加得 \(2b < 0\)；兩個 +1 的點要 \(-0.6w_1 + 0.6w_2 + b > 0\) 和 \(0.6w_1 - 0.6w_2 + b > 0\)，相加得 \(2b > 0\)。兩者不可能同時成立，所以沒有任何一條線能分開 XOR，感知器永遠不會收斂。Minsky 與 Papert（1969）證明了單層感知器一系列這類的限制；解法是把感知器疊成好幾層——有隱藏層的神經網路就能輕鬆學會 XOR。

加權和是一片斜面（3D 檢視）

在平面上每一點的上方畫出高度 \(z = w_1x_1 + w_2x_2 + b\)，會得到一片平平的斜面。分界線就是這片斜面切過地面 \(z = 0\) 的地方——所以它一定是直線。在 3D 檢視中，每個資料點都有一根柱子連到斜面：分對的 \(+1\) 點柱子朝上、分對的 \(-1\) 點柱子朝下。每次修正，斜面就跟著傾斜、抬高或壓低一點。

觀察重點

  • 拉過來或推開：分錯的 +1 點把自己加到 \(\mathbf{w}\) 上，分錯的 −1 點把自己減掉。看右邊的權重空間：每次修正都是在 \(\mathbf{w}\) 後面接上一支箭頭。
  • XOR 原地打轉：零初始、固定順序時，XOR 的四個點每一輪都全錯，而且每一輪結束時權重剛好回到 0。為什麼四次修正會互相抵消？
  • 3D 的柱子：+1 點的柱子應該朝哪邊？在分錯的點按「單步」時，斜面怎麼動？
  • 學習率：初始權重選「零」，改學習率再學一次。線會變嗎？修正次數呢？換成「隨機」初始權重又如何？
  • 上界與實際：上界 \((R/\gamma)^2\) 通常比實際的修正次數大很多。什麼樣的資料會讓 \(\gamma\) 變得很小？打開「最寬的走廊」看看 \(\gamma\)。
  • 拿掉偏差：取消「使用偏差 b」，線必須經過原點。AND、OR、NAND 還有哪個學得會？

計算方法

  • 點的座標吸附在 0.05 的格點上，存成整數 \(g = 20x\)。權重寫成 \(\tilde{\mathbf{w}} = \tilde{\mathbf{w}}_0 + \tfrac{\eta}{20}\,\mathbf{S}\)，\(\mathbf{S}\) 是整數向量 \(y\,(g_1, g_2, 20)\) 的總和。初始權重是零時，\(z\) 的正負由一個整數決定，所以「剛好在線上」「\(b\) 剛好是 0」「權重回到同一個值」都沒有捨入誤差。
  • 最大間隔 \(\gamma\) 等於原點到向量 \(y\,\tilde{\mathbf{x}}\) 的凸包的距離（距離是 0 表示不能用一條線分開）。頁面把凸包的每個頂點、每條邊、每個三角形都試過，精確找出最近點。單元測試把每個答案從兩個方向證明——一個方向 \(\mathbf{u}\) 做得到 \(\gamma\)，一個長度為 \(\gamma\) 的凸組合說明不可能更好——並和兩種獨立的迭代算法比對。
  • 單元測試也檢查：學習規則和 (t − ŷ) 的寫法逐步相同；可分的資料一定收斂，而且修正次數從不超過 (R/γ)²；XOR 和其他不可分的資料永遠不收斂；從零出發時改學習率只會放大權重、不改變線；拿掉偏差後 AND、OR、NAND 都變成不可分；同一個種子的隨機資料與打亂順序完全重現。
  • 3D 的斜面就是同一個 \(z\) 畫成高度。因為 \(z\) 可能變得很大，所有高度共用一個縮放比例，讓斜面最高的角維持固定高度；比例寫在 3D 畫面上。柱子用同一個比例，所以柱子長度和 \(z\) 精確成正比。
