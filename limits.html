背後的數學

數列的極限

「\(a_n\) 趨近 \(L\)」的意思是：不論帶子 \((L - \varepsilon,\, L + \varepsilon)\) 畫得多窄，從某一項開始，後面每一項都在帶子裡。

\[ \lim_{n\to\infty} a_n = L \iff \forall \varepsilon > 0,\ \exists N,\ n \ge N \Rightarrow |a_n - L| < \varepsilon. \]

例如 \(a_n = \frac1n\)、\(\varepsilon = 0.01\)：\(\frac1n < 0.01 \iff n > 100\)，最小的 \(N\) 是 101。\(\varepsilon\) 越小，\(N\) 就要越大，但總找得到。\((-1)^n\) 在 \(1\) 和 \(-1\) 之間跳，寬度不到 1 的帶子放在哪裡都關不住兩個值，所以沒有極限。

函數的極限

\[ \lim_{x\to a} f(x) = L \iff \forall \varepsilon > 0,\ \exists \delta > 0,\ 0 < |x - a| < \delta \Rightarrow |f(x) - L| < \varepsilon. \]

條件 \(0 < |x - a|\) 把 \(x = a\) 排除在外：\(\frac{x^2-1}{x-1}\) 在 1 沒有定義，極限卻是 2。\(\frac{|x|}{x}\) 的左極限是 \(-1\)、右極限是 \(1\)，兩邊不同，所以在 0 的極限不存在。\(\frac{1}{x^2}\) 越來越大，也沒有（有限的）極限。

夾擠定理

若在 \(a\) 附近 \(g(x) \le f(x) \le h(x)\)，而 \(g\)、\(h\) 都趨近 \(L\)，則 \(f\) 也趨近 \(L\)。因為 \(|\sin t| \le 1\)：\(-|x| \le x\sin\frac1x \le |x|\)，所以 \(x\sin\frac1x \to 0\)；同理 \(-\frac1n \le \frac{\sin n}{n} \le \frac1n\)。當 \(0 < |x| < \frac{\pi}{2}\)：\(\cos x \le \frac{\sin x}{x} \le 1\)，所以 \(\frac{\sin x}{x} \to 1\)。

無窮等比級數

\[ S_n = a + ar + \cdots + ar^{n-1} = \frac{a(1 - r^n)}{1 - r}, \qquad |r| < 1 \;\Rightarrow\; \sum_{k=1}^{\infty} ar^{k-1} = \lim_{n\to\infty} S_n = \frac{a}{1-r}. \]

無窮多項的和，定義成部分和的極限。\(|r| < 1\) 時 \(r^n \to 0\)；\(|r| \ge 1\)（且 \(a \ne 0\)）時部分和沒有極限。例如 \(0.9 + 0.09 + 0.009 + \cdots = \frac{0.9}{1 - 0.1} = 1\)。

觀察重點

  • 不單調：\(\frac{\sin n}{n}\) 會在帶子邊緣進進出出；\(N\) 由最後一個跑出去的項決定，不是第一個進來的項。
  • 很慢：\((1 + \frac1n)^n\) 和 \(e\) 的差大約是 \(\frac{e}{2n}\)，\(\varepsilon = 0.001\) 要一千多項。
  • 放大：把 \(\frac{x^2-1}{x-1}\) 在 \((1, 2)\) 附近放大，永遠是一條有洞的直線；\(x\sin\frac1x\) 一直振盪，但振幅被 \(\pm|x|\) 夾住。

計算方法

  • 最小的 \(N\) 是精確找出來的：先用 \(|a_n - L|\) 的遞減上界找到一個之後全部都在帶子裡的項，再把前面每一項逐一檢查（剛好距離 \(\varepsilon\) 的項算在帶子外）。最大的 \(\delta\) 由誤差公式或左右各自二分法求得；\(x\sin\frac1x\) 用比一次振盪更小的步伐往外找。單元測試用定義逐一核對：\(N\) 以後掃兩萬項、\(\delta\) 以內掃四千個點。
