空間向量：內積、外積與平面

在三維空間裡做出向量，把畫面轉一轉，從各個方向看清楚。用內積量兩個向量的夾角、把一個向量投影到另一個上；用外積做出同時垂直兩個向量的新向量，它的長度剛好是兩個向量圍成的平行四邊形面積；把三個向量疊成一個平行六面體，體積就是純量三重積；再由法向量決定一個平面，算出一個點離它多遠。

背後的數學

空間中的向量

在右手坐標系裡（\(x\)、\(y\)、\(z\) 軸像右手的拇指、食指、中指），向量用分量寫成 \(\vec a = (a_1, a_2, a_3)\)，長度 \(|\vec a| = \sqrt{a_1^2 + a_2^2 + a_3^2}\)——用了兩次畢氏定理。把三維畫在平面上一定會少掉一個方向，所以畫面可以轉動，點線把每個尖端垂直連到地板 \(z = 0\)，看得出高度。

內積：夾角與投影

\[ \vec a \cdot \vec b = a_1 b_1 + a_2 b_2 + a_3 b_3 = |\vec a|\,|\vec b| \cos\theta \]

兩種寫法相等，是因為對邊長 \(\vec a\)、\(\vec b\)、\(\vec a - \vec b\) 的三角形用餘弦定理。所以 \(\cos\theta = \dfrac{\vec a\cdot\vec b}{|\vec a||\vec b|}\)：內積為正是銳角，等於 0 是垂直，為負是鈍角。把 \(\vec b\) 垂直投到 \(\vec a\) 所在的直線上，得到投影；投影向量帶正負號的長度記作 \(\text{comp}_{\vec a}\vec b\)：

\[ \text{proj}_{\vec a}\vec b = \frac{\vec a\cdot\vec b}{|\vec a|^2}\,\vec a, \qquad \text{comp}_{\vec a}\vec b = \frac{\vec a\cdot\vec b}{|\vec a|} = |\vec b|\cos\theta \]

外積：垂直、而且長度是面積

\[ \vec a \times \vec b = \big(a_2 b_3 - a_3 b_2,\ a_3 b_1 - a_1 b_3,\ a_1 b_2 - a_2 b_1\big) \]

驗算 \((\vec a\times\vec b)\cdot\vec a = 0\)、\((\vec a\times\vec b)\cdot\vec b = 0\)：外積和兩個向量都垂直。它的長度是 \(|\vec a||\vec b|\sin\theta\)，正好是 \(\vec a\)、\(\vec b\) 圍成的平行四邊形面積；方向照右手定則：右手四指從 \(\vec a\) 彎向 \(\vec b\)，拇指指的就是 \(\vec a\times\vec b\)。順序交換，方向相反：\(\vec b\times\vec a = -\vec a\times\vec b\)；兩個向量平行時外積是 \(\vec 0\)，圍不出面積。合起來，\(|\vec a\times\vec b|^2 + (\vec a\cdot\vec b)^2 = |\vec a|^2|\vec b|^2\)，因為 \(\sin^2\theta + \cos^2\theta = 1\)。

三個向量：盒子的體積

向量 \(\vec a\)、\(\vec b\)、\(\vec c\) 圍出一個平行六面體。以 \(\vec b\)、\(\vec c\) 為底，底面積是 \(|\vec b\times\vec c|\)，高是 \(\vec a\) 在 \(\vec b\times\vec c\) 方向上的投影長，兩者相乘就是純量三重積，也是一個行列式：

\[ V = \big|\vec a\cdot(\vec b\times\vec c)\big| = \left|\det\begin{pmatrix} a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \\ c_1 & c_2 & c_3 \end{pmatrix}\right| \]

正負號代表方向：\(\vec a, \vec b, \vec c\) 排列得像右手時為正，像左手時為負。體積是 0，表示三個向量在同一個平面上（共平面），盒子被壓扁了。

平面與距離

平面由一個和它垂直的法向量 \(\vec n = (a, b, c)\) 和一個數決定：平面上每一點 \(\vec x\) 都滿足 \(\vec n\cdot\vec x = d\)，也就是 \(ax + by + cz = d\)。點 \(Q\) 沿著 \(\vec n\) 移動時 \(\vec n\cdot Q\) 變得最快，所以 \(Q = (x_0, y_0, z_0)\) 到平面的距離是

\[ \text{dist} = \frac{|a x_0 + b y_0 + c z_0 - d|}{\sqrt{a^2 + b^2 + c^2}}, \qquad F = Q - \frac{\vec n\cdot Q - d}{|\vec n|^2}\,\vec n \]

\(F\) 是從 \(Q\) 作垂線的垂足。把 \(\vec n\) 和 \(d\) 同時乘上一個數，平面不變。

三視圖

工程圖會從正面、側面、上方各畫一張。每一張只是「忘掉」一個坐標：前視圖（從 \(+x\) 看）留下 \((y, z)\)，側視圖（從 \(+y\) 看）留下 \((x, z)\)，俯視圖（從 \(+z\) 看）留下 \((x, y)\)。兩個向量在某一張圖上看起來垂直，在另一張卻不一定。

觀察重點

  • 看起來不像的垂直：用不在坐標軸上的向量調出 \(\vec a\cdot\vec b = 0\)，再轉動畫面。從哪些方向看，直角才像直角？
  • 交換就翻轉：在外積模式按「交換 a、b」，\(\vec a\times\vec b\) 和那個彎箭頭怎麼了？
  • 面積一樣、形狀不同：維持 \(|\vec a\times\vec b|\) 不變，把夾角變小，長度要怎麼變？
  • 壓扁的盒子：取 \(\vec c = \vec a + \vec b\)，體積是多少？為什麼？
  • 平面的哪一側：讓 \(Q\) 穿過平面，看有號距離的正負號怎麼變。

計算方法

  • 所有數值都直接由上面的公式算出。夾角用 \(\operatorname{atan2}(|\vec a\times\vec b|, \vec a\cdot\vec b)\) 計算，在 \(0^\circ\) 和 \(180^\circ\) 附近也準確。單元測試在上百組隨機向量檢查各個恆等式，也檢查每一種視角都是右手系、平面和立方體的截面，以及每一道挑戰題都能用滑桿做到。
  • 2D 斜視圖是可以轉動的正投影：沒有透視的近大遠小，平行線畫出來仍然平行。\(\vec a\times\vec b\) 太長放不進畫面時會縮短畫，標籤會寫縮小幾倍。3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才下載。
