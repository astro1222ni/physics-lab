透鏡與面鏡成像

選擇凸透鏡、凹透鏡、凹面鏡、凸面鏡或平面鏡，沿主軸拖曳物體：主光線會即時找出像的位置、大小、正立或倒立、實像或虛像，並與成像公式 1/p + 1/q = 1/f 互相驗證。

試試看：把物體從遠處拖向凸透鏡，越過 F 時看像怎麼從倒立實像變成正立虛像。

物體 像（虛線：虛像） 平行主軸的光 經過光心的光 射向鏡頂的光 經過（或射向）F 的光 經過（或射向）C 的光 延長線（不是真實光線）

拖曳物體（或點擊元件左側）可改變物距 p，拖曳物體頂端可改變物高；靠近 F 與 2F 時會自動吸附。鍵盤：← → 移動物體、↑ ↓ 改變物高（按住 Shift 移動較多）。長度依實際比例；透鏡與鏡面的彎曲只是示意，光線在通過中心、垂直主軸的平面上轉折（薄透鏡、近軸近似）。

符號約定（課本「實正虛負」）：實物 p > 0；實像 q > 0、虛像 q < 0；會聚元件（凸透鏡、凹面鏡）f > 0、發散元件（凹透鏡、凸面鏡）f < 0；m > 0 正立、m < 0 倒立。

顯示

「多條光線」由物體頂端射出一整束光到整個元件上：每一條都會經過（或反向延長後經過）同一個像點。

背後的物理

物體上每一點都向四面八方發出光。經過透鏡或面鏡後，同一點發出的光若重新會聚於一點，就是實像（可以用屏幕接到）；若只是發散、但反向延長線交於一點，就是虛像（只能看著透鏡或鏡子才看得到）。對薄透鏡、以及光線靠近主軸的球面鏡，物距 \(p\)、像距 \(q\) 與焦距 \(f\) 滿足同一個成像公式：

\[ \frac{1}{p} + \frac{1}{q} = \frac{1}{f}, \qquad m = \frac{h'}{h} = -\frac{q}{p}, \qquad f_{\text{mirror}} = \frac{R}{2} \]

只要約定好正負號，四種元件都用同一個公式。本頁採用臺灣高中課本的「實正虛負」約定：

物理量正（＋）負（－）
物距 \(p\)實物（本頁一律為正）虛物（本頁不討論）
像距 \(q\)實像——透鏡：在另一側；面鏡：在鏡前虛像——透鏡：與物體同側；面鏡：在鏡後
焦距 \(f\)會聚：凸透鏡、凹面鏡發散：凹透鏡、凸面鏡
放大率 \(m\)正立的像倒立的像

平面鏡是 \(f \to \infty\) 的極限：\(1/q = -1/p\)，所以 \(q = -p\)、\(m = 1\)——在鏡後與物體等距處，形成正立、等大的虛像。

主光線作圖

由物體頂端畫出兩條光線就能找到像的頂端；課本使用路徑容易預測的幾條光線：

  • 平行主軸的光 → 經過元件後通過焦點（凸透鏡為 F′、凹面鏡為 F）；發散元件則是反向延長線通過焦點。
  • 經過（或射向）焦點 F 的光 → 平行主軸射出。
  • 透鏡：經過光心的光 → 直線前進。面鏡：經過（或射向）曲率中心 C 的光 → 垂直打在鏡面上，沿原路反射（另一條常用的光線：射向鏡頂的光，對主軸對稱反射）。

光線真的交會處形成實像（實線箭頭）；若光線發散，就把它們反向延長（虛線），延長線的交點就是虛像（虛線箭頭）。由作圖中的相似三角形，可以推導出成像公式與 \(m = -q/p\)。

觀察重點

  • 把物體由遠處移近（凸透鏡或凹面鏡）：在 2F 以外成倒立縮小實像；在 2F 上成等大實像（\(q = 2f\)、\(m = -1\)）；在 F 與 2F 之間成倒立放大實像，越接近 F 像越遠越大；進入 F 以內，突然變成正立放大的虛像——這就是放大鏡與化妝鏡。
  • 物體在焦點上：所有光線平行射出、永不相交，不成像（像在無窮遠）。探照燈、車燈把燈泡放在凹面鏡的焦點，就是利用這個性質。
  • 發散元件（凹透鏡、凸面鏡）：不論物體放在哪裡，都成正立、縮小的虛像，而且像一定在元件與焦點之間。路口的凸面鏡（反光鏡）看得廣、但影像較小，就是這個原因。
  • 驗證數字：面板上的 \(1/p + 1/q\) 與 \(1/f\) 永遠相等。再把物體移到原來像的位置，新的像會出現在原來物體的位置（光路可逆）。
  • 打開「多條光線」：不只三條主光線，物體頂端發出的每一條光線都經過同一個像點；主光線只是最容易作圖的那幾條。
  • 改變物高：\(q\) 與 \(h\) 無關，像高與物高成正比 \(h' = mh\)；改變 \(|f|\) 則整個成像規律依比例縮放。

模擬方法

  • 像的位置與大小直接由成像公式 \(1/q = 1/f - 1/p\) 與 \(m = -q/p\) 計算。
  • 每一條光線都用近軸薄元件的規則各自追跡：在元件上高度 \(y\)、斜率 \(u\) 的光線，出射斜率為 \(u' = u - y/f\)（面鏡則水平方向反轉）。所以畫出的光線確實交於計算出的像點，單元測試對四種元件都驗證過。
  • 這是課本使用的理想薄透鏡、近軸模型。真實的球面鏡與厚透鏡有像差：離主軸很遠的光線不會剛好交於一點。
  • 距離依實際比例繪製（見「10 cm」比例尺）；透鏡與鏡面的彎曲程度與厚度只是示意。
