二次函數：頂點、判別式與配方

拖曳拋物線的頂點，看 y = ax2 + bx + c 和 y = a(x − h)2 + k 一起改變。判別式告訴你圖形和 x 軸——或一條直線——碰到幾次。再用一個正方形和兩個長方形拼出 x2 + px，把缺的那一角補上：「配方」配的就是這一角。

試試看：把紫色的頂點往下拖到剛好碰到 x 軸。兩個根滑到一起合成一個，判別式剛好變成 0。

模式

函數 f(x)

調整

在圖上拖曳紫色的頂點（靠近 0.5 的倍數會吸過去）。a 不能是 0：打 0 會變成 ±0.1。一種式子換算出來的值超出另一種的滑桿時，那個滑桿的範圍會自動放寬。

定義域

閉區間上的最大值和最小值，只可能出現在兩端或頂點——而頂點要在區間裡面才算。

直線 y = mx + n

在圖上上下拖曳直線和 y 軸交點的橘色點。讓兩個式子相等會得到一個一元二次方程式，它的判別式就是交點的個數。

配方：x2 + px = q

步驟

1：x × x 的正方形和 p × x 的長方形。2：長方形切成兩半。3：一半搬到正方形下面。4：補上缺的角。拖曳藍色正方形的角可以改變 x。

背後的數學

同一個函數的兩種寫法

\[ f(x) = ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a} = a(x - h)^2 + k. \]

頂點是 \((h, k) = \left(-\frac{b}{2a},\ c - \frac{b^2}{4a}\right)\)，圖形對直線 \(x = h\) 對稱。\(a > 0\) 時開口向上，\(k\) 是最小值；\(a < 0\) 時開口向下，\(k\) 是最大值。一樣高的兩點，例如 \((0, c)\) 和 \((2h, c)\)，在對稱軸左右等距的地方。

判別式

\[ D = b^2 - 4ac,\qquad x = \frac{-b \pm \sqrt{D}}{2a}. \]

因為 \(k = -\frac{D}{4a}\)，\(D\) 的正負告訴你頂點和開口方向是不是在 x 軸的兩側：\(D > 0\) 穿過兩次，\(D = 0\) 頂點剛好在 x 軸上（二重根），\(D < 0\) 整條圖形都在同一側。\(a > 0\) 且 \(D < 0\) 時，\(f(x)\) 對每個 \(x\) 都大於 0。

拋物線與直線

令 \(ax^2 + bx + c = mx + n\)，得到 \(ax^2 + (b - m)x + (c - n) = 0\)。它的判別式 \((b - m)^2 - 4a(c - n)\) 決定交點有兩個、一個或沒有。等於 0 時直線只碰到拋物線一點——這就是切線，切點的斜率剛好是 \(2ax + b\)。鉛直線和拋物線也只交一點，但它不是切線。

把正方形補完整

\[ x^2 + px + \left(\frac{p}{2}\right)^2 = \left(x + \frac{p}{2}\right)^2 \quad\Rightarrow\quad x^2 + px = q \iff \left(x + \frac{p}{2}\right)^2 = q + \left(\frac{p}{2}\right)^2. \]

把 \(p \times x\) 的長方形切成兩條寬 \(\frac p2\) 的長條，一條放在正方形旁邊、一條放在下面。這個 L 形的面積還是 \(x^2 + px = q\)，只缺了一角，面積 \(\left(\frac p2\right)^2\)。兩邊都加上這一角，L 形就成了邊長 \(x + \frac p2\) 的正方形。大約西元 820 年，花拉子米就是這樣解 \(x^2 + 10x = 39\)：角落是 25，大正方形是 \(39 + 25 = 64\)，邊長 8，所以 \(x = 8 - 5 = 3\)。圖只畫得出正根；用代數還有另一個根 \(x = -\frac p2 - \sqrt{q + \left(\frac p2\right)^2}\)。

觀察重點

  • 根的距離：\(a > 0\) 時把頂點直直往下拖，兩個根對稱地往兩邊分開，距離是 \(\frac{\sqrt D}{|a|}\)。
  • 最小值不一定在頂點：區間不包含 \(h\) 時，最大值和最小值都在兩端。
  • 切線：固定斜率，把直線上下移動，交點從兩個變一個再變沒有，只有一個的那一刻就是切線。

計算方法

  • 所有數值都用上面的公式計算。求根用 \(x_1 = \frac{-b - \operatorname{sgn}(b)\sqrt D}{2a}\)、\(x_2 = \frac{c}{a x_1}\)，避免兩個很接近的數相減失準。滑桿的值都是有限小數，所以判別式和 0 相差 \(10^{-9}\) 以內就當成 0。單元測試用幾千個點的直接計算，核對頂點、根、區間上的最大最小值和交點。
