等差、等比數列與級數

每一項是一根長條。等差數列每次加同樣的量；把它倒過來疊上去，每一對都一樣高——少年高斯就是這樣算出 1 加到 100。等比數列每次乘同樣的倍數；公比在 −1 和 1 之間時，長條越來越短，部分和越來越靠近一個極限。最後數一數排成三角形和正方形的點。

試試看：在「等比」模式設 a1 = 1、r = 0.5，再把 n 調大。長條每次減半，部分和一點一點爬向 2，卻永遠不會超過。

圖形數

挑戰：猜數列

出現一個神祕數列的前四項（虛線長條）。判斷它是等差還是等比，選那個模式，調好 a1 和 d（或 r），讓你的前五項都對得上，再送出。

背後的數學

等差數列

\[ a_k = a_1 + (k - 1)d,\qquad S_n = a_1 + a_2 + \cdots + a_n = \frac{n(a_1 + a_n)}{2} = \frac{n\,[2a_1 + (n - 1)d]}{2}. \]

把和正著寫一次、倒著寫一次，上下對齊相加。每一行都是 \(a_k + a_{n+1-k} = a_1 + a_n\)，因為一項多 \(d\)，另一項就少 \(d\)。一共 \(n\) 行，所以 \(2S_n = n(a_1 + a_n)\)。把 \(S_n\) 看成 \(n\) 的函數，它是二次函數，部分和的點排在一條拋物線上。

等比數列

\[ a_k = a_1 r^{k - 1},\qquad S_n = \frac{a_1(1 - r^n)}{1 - r}\ (r \ne 1),\qquad S_\infty = \frac{a_1}{1 - r}\ \ (|r| < 1). \]

把和乘上 \(r\) 再相減：\(S_n - rS_n = a_1 - a_1 r^n\)，中間的項全部消掉。\(|r| < 1\) 時 \(r^n \to 0\)，部分和越來越接近 \(\frac{a_1}{1 - r}\)；還差的距離剛好是 \(|S_\infty|\,|r|^n\)。\(r < 0\) 時部分和在極限的上下跳動。\(|r| \ge 1\) 時沒有極限——\(r = -1\) 時和只是來回擺盪。

例如 \(0.999\ldots = 0.9 + 0.09 + 0.009 + \cdots\) 是 \(a_1 = 0.9\)、\(r = 0.1\) 的等比級數，所以它等於 \(\frac{0.9}{1 - 0.1} = 1\)。

數點

\[ 1 + 2 + \cdots + n = \frac{n(n + 1)}{2},\qquad 1 + 3 + 5 + \cdots + (2n - 1) = n^2. \]

一個點排成的階梯，和轉過來的同一個階梯，剛好填滿 \(n \times (n + 1)\) 的長方形。每一個奇數 \(2k - 1\) 都是一層 L 形，把 \((k - 1) \times (k - 1)\) 的正方形變成 \(k \times k\)。有些數兩種都是：36 個點可以排成 8 列的三角形，也可以排成 6 × 6 的正方形。

觀察重點

  • 部分和的拋物線：\(a_1 > 0\)、\(d < 0\) 時部分和先升再降，最大的和出現在項剛要變成負數之前。
  • 永遠減半：\(r = \frac12\) 時，每一根新長條剛好是剩下距離的一半，所以總和永遠到不了 \(S_\infty\)，但可以要多近就有多近。
  • 指數成長：\(r = 2\) 時，最後一根長條比前面所有長條加起來還大，因為 \(2^{n-1} > 2^{n-1} - 1\)。

計算方法

  • 長條和部分和是一項一項加出來的；讀數用上面的公式，單元測試用幾千組隨機數列核對兩者相同。很大或很小的數用科學記號顯示。
