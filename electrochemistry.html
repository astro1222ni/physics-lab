化學電池與電解

用兩個半電池和鹽橋組成化學電池，讀出電壓，看電子在導線中流動、離子在溶液中移動；改變濃度驗證能斯特方程式。再切換到電解：讓電流通過硫酸銅溶液，秤陰極的質量驗證法拉第定律。標準還原電位取自 OpenStax《Chemistry 2e》附錄 L。

實驗目的

  1. 用兩個半電池與鹽橋組成化學電池，判斷陽極、陰極，以及電子與離子流動的方向。
  2. 由標準還原電位計算電池電位，並驗證濃度對電位的影響（能斯特方程式）。
  3. 電解硫酸銅溶液，驗證法拉第定律：析出的質量與通過的電量成正比。

原理

化學電池

每個半電池是金屬 M 浸在它的離子 Mz+ 溶液中。還原電位較低的一邊放出電子（氧化，陽極，負極）；另一邊接受電子（還原，陰極，正極）。電子經導線由陽極流向陰極；鹽橋中 K+ 移向陰極、NO3− 移向陽極，使兩杯溶液保持電中性。沒有鹽橋，電路不通，量不到電壓。

\[ E^\circ_\text{cell} = E^\circ_\text{cathode} - E^\circ_\text{anode} \] \[ E = E^\circ + \frac{0.05916\ \mathrm{V}}{z}\log[\mathrm{M}^{z+}] \]

第二式是單一電極在 25 °C 的能斯特方程式。對整個電池則為 \(E_\text{cell} = E^\circ_\text{cell} - \frac{0.05916}{n}\log Q\)，\(n\) 是轉移的電子數、\(Q\) 是反應商。本模擬的伏特計讀 \(E_\text{右} - E_\text{左}\)：讀數是負的，表示右邊才是陽極。

濃差電池

兩邊用同一種金屬時 \(E^\circ_\text{cell} = 0\)，但濃度不同仍有電壓：

\[ E_\text{cell} = \frac{0.05916\ \mathrm{V}}{z}\log\frac{c_\text{cathode}}{c_\text{anode}} \]

稀的一邊是陽極。放電時稀的變濃、濃的變稀，直到兩邊一樣，電壓變成零。

電解與法拉第定律

\[ Q = I\,t \] \[ m = \frac{Q}{zF}\,M \] \[ F = 96485\ \mathrm{C/mol} \]

電解時由外加電源推動反應。陰極（接 −）：Cu2+ + 2e− → Cu。石墨陽極是水被氧化：2H2O → O2 + 4H+ + 4e−，藍色漸漸變淡、溶液變酸。銅陽極則是銅本身溶解：Cu → Cu2+ + 2e−，銅只是由陽極搬到陰極（銅的電解精煉）。Cu2+ 用完後，陰極改為產生氫氣。

本實驗使用的標準還原電位（25 °C）

觀察重點

  • 鋅和銅、都是 1 M：丹尼爾電池 1.10 V。左右對調，讀數變號。
  • 把銅溶液稀釋 1000 倍：電壓下降 3 × 0.0296 = 0.089 V。
  • 接上燈泡、用 ×104 或 ×106：鋅片變薄、銅變厚，藍色變淡，電壓慢慢下降。
  • 電解：1.00 A 通電 3036 秒，析出 1.000 g 的銅。

問題與討論

  1. 拿掉鹽橋時，兩種金屬明明不同，為什麼伏特計是 0？
  2. 半電池中有 Ag+ 時，為什麼鹽橋用 KNO3 而不用 KCl？
  3. 銅鋅電池放電時電壓怎麼變？用能斯特方程式解釋。
  4. 0.50 A 的電流要通過硫酸銅溶液多久，才能析出 0.635 g 的銅？
看參考答案
  1. 沒有鹽橋，電路是斷的：離子無法在兩杯之間移動，電荷無法流通，伏特計量不到電池的電位差。
  2. Cl− 會和 Ag+ 生成 AgCl 沉澱。硝酸鹽都可溶。
  3. Zn2+ 增加、Cu2+ 減少，Q = [Zn2+]/[Cu2+] 變大，E = 1.10 − 0.0296 log Q 下降：一開始很慢，Cu2+ 快用完時下降得很快。
  4. 0.635 g ÷ 63.55 g/mol = 0.0100 mol 銅，需要 0.0200 mol 電子 = 1930 C；t = 1930 C ÷ 0.50 A = 3860 s（約 64 分鐘）。

模擬方法

  • 溫度 25 °C。以濃度代替活性（稀溶液時準確；1 M 時真實的活性明顯較小，真實電池會差幾十毫伏）。
  • 電極電位完全依能斯特方程式。接燈泡時電流 I = E/(R + r)，內電阻 r = 5 Ω；每流過一庫侖，莫耳數依法拉第定律改變。不考慮極化與過電位。
  • 鎂其實會和水慢慢反應，錫、鉛的鹽需要加一點酸才不會水解；這些副反應都不考慮。
  • 電解是定電流、電流效率 100%。Cu2+ 快用完時，陰極有一部分（最後全部）電流改為產生氫氣，這個轉換是示意的。氣體體積以 25 °C、1 atm（24.47 L/mol）計。
  • 畫面上的離子與電子只表示方向：數目依濃度，速度不依比例。
