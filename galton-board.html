背後的數學

從「往左或往右」到二項分布

一顆球往下掉，一路會碰到 \(n\) 根釘子。每一根都以機率 \(p\) 往右、\(1 - p\) 往左，而且和之前怎麼走無關。球落在第 \(k\) 格（從左邊的第 \(0\) 格數起），恰好就是 \(n\) 次裡往右了 \(k\) 次。每一條「往右 \(k\) 次」的路徑機率都是 \(p^{k}(1-p)^{n-k}\)，這樣的路徑共有 \(\binom{n}{k}\) 條，所以格子編號 \(X\) 服從二項分布 \(B(n, p)\)：

\[ P(X = k) = \binom{n}{k} p^{k} (1-p)^{n-k}, \qquad k = 0, 1, \dots, n \]

數路徑：巴斯卡三角形

在每一根釘子上寫下「有幾條不同的路徑會經過它」。一根釘子只能從它上方的兩根釘子過來，所以它的數字是上方兩個數字的和——這正是巴斯卡三角形的規則 \(\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}\)。最底下一排格子的數字加起來是 \(2^{n}\)，也就是所有左右路徑的總數。打開「路徑數」就能在釘子上看到這個三角形；選取一個格子，會亮出所有「去那一格的球可能碰到」的釘子。

期望值與變異數

令第 \(i\) 層往右時 \(X_i = 1\)、往左時 \(X_i = 0\)，那麼 \(X = X_1 + X_2 + \dots + X_n\)。每個 \(X_i\) 的期望值是 \(p\)、變異數是 \(p(1-p)\)，而且各層互相獨立，所以兩者都可以直接相加：

\[ E(X) = np, \qquad \operatorname{Var}(X) = np(1-p), \qquad \sigma = \sqrt{np(1-p)} \]

讀數把它們和實驗比較：目前 \(N\) 顆球的格子編號的平均 \(\bar{x}\)，以及變異數 \(\frac{1}{N}\sum (x_i - \bar{x})^{2}\)。

大數法則

球少的時候長條跳來跳去；球多了，每一格的相對次數 \(f_k\) 會穩定地靠近 \(P(X = k)\)。頁面量的是總差距 \(\frac12\sum_k |f_k - P(X = k)|\)（0 表示完全吻合，1 表示完全不重疊）。它的典型大小隨 \(\dfrac{1}{\sqrt{N}}\) 縮小：球數變成 100 倍，差距大約只剩十分之一，在兩軸都取對數的圖上就是那條虛線直線。

鐘形曲線出現了

\(n\) 很大時，二項分布很接近平均 \(\mu = np\)、標準差 \(\sigma = \sqrt{np(1-p)}\) 的常態分布。每一格寬度是 1，所以一格的機率可以用常態曲線底下從 \(k - \frac12\) 到 \(k + \frac12\) 的面積來近似（連續性修正）：

\[ P(X = k) \approx \Phi\!\left(\frac{k + \frac12 - \mu}{\sigma}\right) - \Phi\!\left(\frac{k - \frac12 - \mu}{\sigma}\right) \]

\(n\) 越大、\(p\) 越接近 \(\frac12\)，近似越好；\(p\) 接近 0 或 1 時分布歪向一邊，對稱的鐘形就對不太上。這是中央極限定理最簡單的例子：很多個獨立的小隨機步伐加起來，會近似常態分布。

倒過來想：從結果估計 p

因為 \(E(X) = np\)，不知道 \(p\) 時最自然的估計是 \(\hat{p} = \bar{x}/n\)。所有 \(nN\) 次碰釘子都是獨立的試驗，所以估計值大約會晃動 \(\sqrt{p(1-p)/(nN)}\)：球越多、層數越多，都會估得越準。

觀察重點

  • 一顆和一千顆：一次放一顆，連放幾次，猜得到它掉在哪一格嗎？再一次放一千顆。
  • 傾斜的板子：把 \(p\) 設成 0.2。最高的長條在哪一格？和 \(\lfloor (n+1)p \rfloor\) 比一比。
  • 兩格一樣高：\(n = 9\)、\(p = 0.3\) 時，有兩格的機率完全相同。為什麼？
  • 越來越小的差距：一直放球，看差距圖。差距會停止縮小嗎？
  • 鐘形什麼時候不準：打開常態曲線，比較 \(n = 16, p = 0.5\) 和 \(n = 4, p = 0.1\)。

計算方法

  • 每一根釘子都用亂數獨立決定往左或往右，和上面描述的完全一樣——放球時從來沒有用到二項分布的公式，所以你看到的吻合是真的。單元測試檢查 \(\sum_k P(X = k) = 1\)、由分布直接算出的期望值與變異數、巴斯卡的遞迴規則、列出全部 \(2^{n}\) 條路徑來數路徑數、常態分布函數 \(\Phi\) 的已知值，以及 20 萬顆球的模擬。
  • 球在釘子之間沿拋物線跳（水平等速、垂直等加速度），這只是為了好看；真正重要的是每根釘子的左右選擇。3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才下載。
