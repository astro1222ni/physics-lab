三角形的四心與歐拉線

三條中線、三條中垂線、三條角平分線、三條高，每一組都交在同一點。拖曳頂點看四個心怎麼移動：其中三個永遠排在同一條直線上，而且在線上一直保持 1 : 2。

背後的數學

四個心

  • 重心 \(G\)：三條中線的交點，把每條中線從頂點起分成 \(2 : 1\)，\(G = \tfrac13(A + B + C)\)；用硬紙板剪的三角形，就是在這一點撐得住。
  • 外心 \(O\)：三條中垂線的交點，到三個頂點一樣遠（\(R\)），是外接圓的圓心。
  • 內心 \(I\)：三條內角平分線的交點，到三邊一樣遠（\(r\)），是內切圓的圓心。\(I = \dfrac{aA + bB + cC}{a + b + c}\)。
  • 垂心 \(H\)：三條高（或高的延長線）的交點。

歐拉線

\[ \vec{OH} = \vec{OA} + \vec{OB} + \vec{OC} = 3\,\vec{OG},\qquad OG : GH = 1 : 2 \]

把原點放在 \(O\)。點 \(A + B + C\) 在每一條高上：\((A + B + C) - A = B + C\) 和 \(C - B\) 垂直，因為 \(|B| = |C| = R\)。所以它就是 \(H\)，而 \(G = \tfrac13(A + B + C)\) 在 \(O\) 到 \(H\) 的三分之一處。歐拉在 1765 年發現這件事。只有正三角形四心重合；等腰三角形的內心也會落在這條線上。

九點圓與歐拉公式

\[ N = \tfrac12(O + H),\quad \text{radius } \tfrac R2;\qquad OI^2 = R(R - 2r)\ \Rightarrow\ R \ge 2r \]

三邊的中點、三條高的垂足、\(AH\)、\(BH\)、\(CH\) 的中點，這九個點在同一個圓上，圓心是 \(OH\) 的中點 \(N\)，半徑 \(R/2\)；它還和內切圓相切（費爾巴哈定理）。外心到內心距離的歐拉公式說明 \(R \ge 2r\)，只有正三角形取等號。

觀察重點

  • 裡面還是外面：\(G\)、\(I\) 永遠在三角形裡面。\(O\)、\(H\) 在銳角三角形裡面、直角三角形的邊上（\(O\) 在斜邊中點，\(H\) 在直角頂點）、鈍角三角形外面。
  • 軌跡：固定兩個頂點，讓第三個頂點沿著和對邊平行的直線走。\(G\) 畫出一條直線，\(O\) 只在中垂線上動，\(H\) 畫出一條拋物線。

計算方法

  • \(O\) 由中垂線求、\(I\) 由邊長加權平均求、\(H\) 直接解兩條高的交點（不是用歐拉線的關係式算出來），所以畫面上的三點共線是真正的驗證，不是先假設好的。
