比熱與熱平衡

把加熱過的金屬塊或冰塊放進量熱器的水中，看兩者的溫度逐漸接近、達到熱平衡——放出的熱量等於吸收的熱量。再用固定功率的加熱器加熱冰塊，畫出有熔化與沸騰平台的加熱曲線、由斜率測出比熱，並比較不同材料吸收同樣的熱量後，溫度各升高多少。

背後的物理

熱量、比熱與熱容量

質量 \(m\) 的物體溫度升高 \(\Delta T\)，需要吸收熱量 \(Q\)。比熱 \(c\) 是每公斤升高 1 K 所需的熱量，熱容量 \(C = mc\) 是整個物體升高 1 K 所需的熱量：

\[ Q = m c\,\Delta T = C\,\Delta T, \qquad C = m c \]

溫度變化 1 °C 與 1 K 相同。水的比熱特別大，\(4186\ \mathrm{J/(kg\cdot K)}\)；舊的熱量單位「卡」就是由水定義的：水的比熱 \(1\ \mathrm{cal/(g\cdot {}^{\circ}C)}\)，\(1\ \mathrm{cal} = 4.186\ \mathrm{J}\)。

熱平衡與混合

溫度不同的物體互相接觸時，熱由高溫流向低溫，直到所有物體的溫度相同（\(T_f\)），稱為熱平衡。在隔熱的量熱器中沒有能量散失，所以放出的熱量等於吸收的熱量。把每個物體的 \(Q = mc\,(T_f - T_i)\) 加起來（吸熱為正）：

\[ \begin{gathered} \sum m c\,(T_f - T_i) = 0 \;\Longrightarrow\; T_f = \frac{\sum m c\,T_i}{\sum m c} \\[4pt] T_f = \frac{m_1 c_1 T_1 + (m_2 c_2 + C_{\text{cup}})\,T_2}{m_1 c_1 + m_2 c_2 + C_{\text{cup}}} \end{gathered} \]

所以 \(T_f\) 是各初溫依熱容量（而不是質量）加權的平均。量熱杯本身也會吸熱，它的熱容量 \(C_{\text{杯}}\) 常用水當量表示：熱容量相同的水的質量 \(C_{\text{杯}}/c_{\text{水}}\)。

如果樣品的比熱未知，量出 \(T_f\) 之後，用同一個式子解出 \(c_1\)：

\[ c_1 = \frac{(m_2 c_2 + C_{\text{cup}})(T_f - T_2)}{m_1 (T_1 - T_f)} \]

潛熱與加熱曲線

熔化與沸騰的過程中，雖然持續吸熱，溫度卻保持不變，因為能量用來改變物質的狀態（相）。所需的熱量稱為潛熱：

\[ \begin{gathered} Q = m L \\[4pt] L_f = 3.34\times10^{5}\ \mathrm{J/kg}\ (\approx 80\ \mathrm{cal/g}) \\ L_v = 2.26\times10^{6}\ \mathrm{J/kg}\ (\approx 539\ \mathrm{cal/g}) \end{gathered} \]

用固定功率 \(P\) 的加熱器加熱、沒有散熱時，經過時間 \(t\) 吸收的熱量 \(Q = Pt\)。溫度對時間的圖上，每一段斜線的斜率是 \(P/(mc)\)，每一段水平的平台持續 \(mL/P\)：

\[ \begin{gathered} \frac{\Delta T}{\Delta t} = \frac{P}{m c} \;\Longrightarrow\; c = \frac{P\,\Delta t}{m\,\Delta T} \\[4pt] t_{\text{plateau}} = \frac{m L}{P} \end{gathered} \]

融化 1 kg 的冰所需的熱量，大約可讓 1 kg 的水升高 80 °C；把水全部煮乾所需的熱量，超過把它從 0 °C 加熱到 100 °C 的五倍——看看沸騰的平台有多長。

冰與水混合

先比較水降到 0 °C 能放出的熱量 \(Q_{\text{放}} = (m_2 c_2 + C_{\text{杯}})(T_2 - 0)\)，與冰升溫到 0 °C 所需的熱量 \(Q_1 = m_1 c_{\text{冰}}(0 - T_1)\)、再全部融化所需的熱量 \(Q_2 = m_1 L_f\)：

  • \(Q_{\text{放}} \ge Q_1 + Q_2\)：冰全部融化，最後溫度高於 0 °C；把熔化的熱量也寫進 \(\sum Q = 0\)。
  • \(Q_1 \le Q_{\text{放}} < Q_1 + Q_2\)：只有部分的冰融化，最後停在 \(T_f = 0\ {}^{\circ}\mathrm{C}\)；融化的質量為 \((Q_{\text{放}} - Q_1)/L_f\)。
  • \(Q_{\text{放}} < Q_1\)：冰太冷了，反而有一部分的水結冰（結冰時放出 \(m L_f\)）。

多快達到熱平衡？

熱流的快慢大約與溫差成正比（牛頓冷卻定律）：\(P = k\,(T_1 - T_2)\)，其中 \(k = hA\) 與接觸面積 \(A\)、有沒有攪拌有關。於是溫差以指數方式減小：

\[ \begin{gathered} T_1 - T_2 = (T_1 - T_2)_0\, e^{-t/\tau} \\[4pt] \tau = \frac{1}{k}\,\frac{C_1 C_2}{C_1 + C_2} \end{gathered} \]

攪拌讓 \(k\) 變大、更快達到熱平衡，但不會改變 \(T_f\)：最後的溫度只由能量守恆決定。

觀察重點

  • 放熱 = 吸熱：把 0.2 kg、100 °C 的鋁塊放進 0.2 kg、20 °C 的水。長條圖兩邊的熱量一樣多，最後溫度只有約 34 °C——比較接近水溫，因為水的熱容量大約是鋁塊的 4.7 倍。
  • 同質量、不同金屬：用相同質量與溫度的鐵、銅、鉛重做一次。比熱越小，水升溫越少；鉛（\(c = 128\)）幾乎不改變水溫。
  • 攪拌：關掉攪拌，達到熱平衡的時間變成約 4 倍，但 \(T_f\) 完全一樣。
  • 冰塊：把 −10 °C 的冰放進溫水，調整兩者的量，試出「冰剩下一些」、「冰剛好全部融化」，甚至「水反而結冰」的情況。
  • 加熱曲線：加熱 0.2 kg、−20 °C 的冰。冰與水的比熱不同，所以斜線的斜率不同；沸騰平台大約是熔化平台的 6.8 倍長，因為 \(L_v/L_f \approx 6.8\)。
  • 由斜率測比熱：在液態的部分記錄兩個點，把 \(P\Delta t/(m\Delta T)\) 與 4186 比較。再打開散熱重做——兩個點要取在哪裡，散熱的影響才最小？
  • 比熱比較：吸收同樣的熱量 \(Q = Pt\) 時，\(\Delta T = Q/(mc)\)；鉛升溫的速度大約是水的 33 倍。

模擬方法

  • 每個物體記錄它所含的熱能（焓 \(H\)）。溫度是 \(H\) 的分段線性函數：升溫時 \(dH = C\,dT\)，水在 0 °C 與 100 °C 各有一段高度為 \(mL\) 的平台。
  • 預測的 \(T_f\) 由總焓守恆精確求出（包括熔化、結冰與沸騰）。
  • 樣品與水之間的熱流為 \(P = k\,(T_1 - T_2)\)，\(k = hA\)（樣品視為正立方體；\(h = 250\)，攪拌時 \(1000\ \mathrm{W/(m^2\cdot K)}\)）。每一段都使用精確的指數解，所以一方放出的熱量正好等於另一方吸收的熱量，最後一定到達預測的 \(T_f\)。每個物體視為溫度均勻；冰融化成的水在計算上仍算在樣品裡，直到最後才與杯中的水同溫。
  • 打開散熱時，水與杯子還會散失 \(k_e\,(T_2 - 25\ {}^{\circ}\mathrm{C})\) 的熱流（量熱杯 \(k_e = 1.5\ \mathrm{W/K}\)，加熱實驗的容器 \(3\ \mathrm{W/K}\)）；散失的熱量也會顯示，能量的帳目仍然平衡。
  • 全部在 1 大氣壓下進行。加熱實驗中水沸騰產生的水蒸氣會跑掉；量熱器中產生的水蒸氣仍算在水的部分。
