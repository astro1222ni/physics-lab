背後的物理

電池推動電荷沿封閉電路流動。電動勢 \(\varepsilon\) 是電池對每庫侖電荷所作的功；其中一部分能量消耗在電池內部，電池的內電阻為 \(r\)。對電阻而言，歐姆定律描述兩端電壓與電流的關係：

\[ V = IR, \qquad P = IV = I^{2}R = \frac{V^{2}}{R} \]

串聯與並聯

串聯時每個電阻的電流相同、電壓相加；並聯時每個支路的電壓相同、電流相加：

\[ R_{\text{series}} = R_{1} + R_{2} + R_{3}, \qquad \frac{1}{R_{\text{parallel}}} = \frac{1}{R_{1}} + \frac{1}{R_{2}} + \frac{1}{R_{3}} \]

克希何夫定律

任何電路都可以用兩條定律解出來。電流定律（電荷守恆）：流入任一接點的電流等於流出的電流。電壓定律（能量守恆）：沿任一封閉迴路繞一圈，電位的升降總和為零：

\[ \sum_{\text{junction}} I_{\text{in}} = \sum_{\text{junction}} I_{\text{out}}, \qquad \sum_{\text{loop}} \Delta V = 0 \]

內電阻與端電壓

接上負載 \(R\) 時，電流與電池兩極之間的電壓（端電壓）為

\[ I = \frac{\varepsilon}{R + r}, \qquad V = \varepsilon - Ir = \frac{R}{R + r}\,\varepsilon, \qquad \eta = \frac{V}{\varepsilon} = \frac{R}{R + r} \]

只有沒有電流時，端電壓才等於電動勢。負載得到的功率在 \(R = r\) 時最大，但此時有一半的能量浪費在電池內部：

\[ P_{\text{out}} = \frac{\varepsilon^{2} R}{(R + r)^{2}} \le \frac{\varepsilon^{2}}{4r}, \qquad \varepsilon I = I^{2} r + I^{2} R \]

惠斯登電橋

兩組分壓電路接在同一個電池上，中點 C、D 之間接檢流計 G。當 C、D 電位相同時，檢流計沒有電流，條件是

\[ \frac{R_{1}}{R_{2}} = \frac{R_{3}}{R_{x}} \quad\Longrightarrow\quad R_{x} = \frac{R_{2}R_{3}}{R_{1}} \]

平衡條件與電池、檢流計都無關，所以電橋可以精確測量未知電阻。

觀察重點

  • 串聯的燈泡分電壓：三個相同燈泡串聯，每個只分到 \(\varepsilon/3\)，功率只有單獨接上時的 \(1/9\)，所以很暗；打開開關，所有燈泡一起熄滅。
  • 並聯的支路互不影響（\(r = 0\) 時）：打開一個支路的開關，其他燈泡亮度完全不變，但總電流變小。再把 \(r\) 設為 \(2\ \Omega\) 重做一次：剩下的燈泡會稍微變亮，因為端電壓上升了。
  • 驗證電流定律：在串並聯混合電路中，流過 L1 的電流等於 L2 與 L3 的電流和；電阻較小的支路分到較多電流。
  • 端電壓：在「電池內電阻」電路，探針一開始就夾在電池兩極。把負載 \(R\) 調小，電流變大、端電壓比 \(\varepsilon\) 小越多；打開開關，電表讀數就正好是 \(\varepsilon\)。
  • 最大功率：改變 \(R\) 時看電路下方的圖，最高點在 \(R = r\)，此時效率只有 50%。
  • 讓電橋平衡：調整 \(R_{x}\) 直到檢流計指針歸零，再驗證 \(R_{1}/R_{2} = R_{3}/R_{x}\)；改變 \(\varepsilon\) 或檢流計的電阻，電橋仍然平衡。

模擬方法

  • 電路以節點分析法精確求解：在每個接點寫克希何夫電流定律，得到節點電位的聯立一次方程式，再用高斯消去法解出。有內電阻的電池換成等效的電流源並聯 \(r\)；理想電池（\(r = 0\)）多加一條方程式 \(V_{+} - V_{-} = \varepsilon\)。
  • 導線與閉合的開關電阻為零，求解前先把它們連接的點合併成同一個節點；斷開的開關沒有電流，與電池斷開的部分沒有電流，電位也沒有定義。
  • 燈泡視為電阻固定的元件（真實燈泡的燈絲變熱後電阻會變大）。電表都是理想電表：電壓表不取電流。
  • 移動的點只表示電流的方向與相對大小；真實電子的漂移速率慢得多（大約每秒 1 毫米或更慢）。
