線性規劃：可行域與目標函數

每一條不等式把平面切成兩半，同時滿足全部不等式的點組成可行域。目標函數 z = px + qy 的等高線是一族平行線；讓它掃過可行域，看它最後離開的地方——最好的值總是在頂點上等你。

試試看：按「掃描」，看橘色的等高線掃過可行域，最後碰到的那一點就是最好的答案。再改 p、q，看最佳解跳到別的頂點。

背後的數學

半平面與可行域

直線 \(ax + by = c\) 把平面分成 \(ax + by < c\) 和 \(ax + by > c\) 兩半。要知道不等式留下哪一邊，拿一個不在線上的點代進去試（原點最方便）。同時滿足所有不等式的點，組成可行域。可行域一定是凸的：任兩個可行點之間的線段整條都在裡面。

目標函數的等高線

\[ z = px + qy = k \quad\Longleftrightarrow\quad \text{a line with normal vector } (p, q). \]

固定 \(z = k\) 得到一條直線，改 \(k\) 只會讓它平移、不會轉動。向量 \((p, q)\) 垂直於這些直線，指向 \(z\) 變大的方向。讓等高線沿著這個方向掃過可行域：最後碰到的可行點給出最大值，最先碰到的給出最小值。

最佳解為什麼在頂點

可行域有界而且不是空的時候，最後的接觸一定發生在頂點，所以只要算出每個頂點的 \(z\) 再比大小。等高線剛好和某一條邊平行時，整條邊同時碰到，最佳解有無限多組。可行域往外無限延伸時，等高線可能永遠離不開它，這時就沒有最大值（或最小值）。

整數解

桌子、椅子只能做整數個。這時只有可行域裡的格子點算數，最好的那一點不一定是把最佳頂點四捨五入——四捨五入的點甚至可能跑到可行域外面。可行域不大時，最穩當的做法是把最佳頂點附近的格子點一個一個算，頁面打開「格子點」時就是這樣做的。

觀察重點

  • 最佳頂點會換人：在工廠生產的題目裡固定 \(q = 2\)，慢慢改 \(p\)。等高線剛好和某一條邊平行的那一刻，最佳頂點就換到隔壁。
  • 最大與最小：「求最大值」和「求最小值」只是掃描的方向相反，兩個答案都在頂點上。
  • 四捨五入不保險：工廠生產的最佳頂點是 \((4.4, 4.8)\)，\(z = 22.8\)；最好的整數解是 \((4, 5)\)，\(z = 22\)。

計算方法

  • 可行域的算法是拿一個很大的正方形，依序用每個半平面去切（Sutherland–Hodgman），再把每個頂點改用它所在的兩條直線精確求交點。大正方形的角如果留下來，可行域就是無界的。最佳值比較各頂點的 \(z\)；可行域無界時，也比較沿著可行域往遠方走的值。整數解是把可行域裡的格子點逐一檢查。
