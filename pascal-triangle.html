挑戰：幾條路？

出一個有路障的格子，數字藏起來。選出從 A 到 B 有幾條最短路徑——在心裡逐點把走法數加起來。

背後的數學

只有一條規則

最上面和兩條斜邊都寫 1，其他每個數都是正上方兩個數的和。第 \(n\) 列第 \(k\) 個數（都從 0 開始數）就是組合數

\[ \binom{n}{k} = C^n_k = \frac{n!}{k!\,(n-k)!}, \qquad \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}. \]

為什麼？從 \(n\) 個東西選 \(k\) 個，先看其中一個：選了它，就從其他 \(n - 1\) 個再選 \(k - 1\) 個；不選它，就從其他 \(n - 1\) 個選 \(k\) 個。

走格子

在 \(m \times n\) 的格子從 \(A\) 走到 \(B\) 的最短路徑，就是 \(m\) 個「右」和 \(n\) 個「上」排成一列。決定 \(m + n\) 步裡哪 \(m\) 步向右，路徑就確定了，所以共有 \(\binom{m+n}{m}\) 條。逐點來看，走到某一點的方法數 = 左邊那點 + 下面那點——和三角形一樣的加法，只是轉了 45°。路障的走法數是 0，加法照樣繞過它進行。

二項式定理

\[ (a x + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^k b^{\,n-k} x^k. \]

把 \(n\) 個括號乘開，每一項是從其中 \(k\) 個括號拿 \(a x\)、其餘拿 \(b\)——有 \(\binom{n}{k}\) 種拿法。代入 \(x = 1\) 得係數和 \((a + b)^n\)；對 \((x + 1)^n\) 就是 \(2^n\)，也就是那一列的和。代入 \(x = -1\) 得交錯和 \((b - a)^n\)，對 \((x + 1)^n\) 是 0。

觀察重點

  • 奇數：依除以 2 的餘數上色，會出現三角形裡套三角形（謝爾賓斯基三角形）。第 1、3、7、15、31、63 列（比 2 的次方少 1）全部都是奇數。
  • 對稱：\(\binom{n}{k} = \binom{n}{n-k}\)——選要拿的，等於選不拿的。
  • 一半的路：正方形格子裡，由對稱性，剛好一半的路徑第一步向右。

計算方法

  • 數值用 JavaScript 的 BigInt 精確計算：第 63 列已經超過 \(2^{53}\)，一般的浮點數到這裡就不精確了。餘數直接用加法規則在餘數上算。單元測試把第 70 列以內的每一個數和階乘公式比對，並檢查列和、曲棍球棒恆等式、淺對角線的和是費氏數、有路障時的路徑數和排容原理一致、隨機路徑每一條出現的機會相同。
