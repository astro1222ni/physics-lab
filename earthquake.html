    背後的物理

    P 波、S 波與表面波

    地震在震源突然釋放能量；震源正上方的地表位置叫震央。在地球內部傳播的「體波」有兩種：P 波（初達波、縱波）讓岩石壓縮與伸張，質點沿傳播方向前後振動；S 波（次達波、橫波）讓岩石剪切變形，質點垂直於傳播方向振動。它們的速度由體積模數 \(K\)、剪切模數 \(\mu\) 與密度 \(\rho\) 決定：

    \[ V_P = \sqrt{\frac{K + \tfrac{4}{3}\mu}{\rho}}, \qquad V_S = \sqrt{\frac{\mu}{\rho}} \]

    所以 \(V_P\) 一定比 \(V_S\) 大，P 波永遠先到。液體不能抵抗剪切（\(\mu = 0\)），所以 \(V_S = 0\)：S 波無法在液體中傳播，P 波卻可以。一般岩石的帕松比約 0.25，此時 \(V_P/V_S = \sqrt{3} \approx 1.73\)；地殼中 \(V_P \approx 6\ \mathrm{km/s}\)、\(V_S \approx 3.5\ \mathrm{km/s}\)。

    沿地表傳播的是表面波。這裡畫的雷利波讓地表的質點沿「向後滾」（逆行）的橢圓運動；在均勻地殼中，\(V_P/V_S = \sqrt{3}\) 時它的速度恰好是 \(V_R = 0.9194\,V_S\)。表面波最晚到，但能量集中在地表附近、擴散得比體波慢，所以離震央較遠處通常振幅最大，破壞也常最嚴重。

    由 S−P 時間差求距離

    震源距離為 \(R\) 的測站，在地震發生後 \(t_P = R/V_P\) 收到 P 波、\(t_S = R/V_S\) 收到 S 波。我們不知道地震何時發生，但兩者的時間差是：

    \[ \Delta t = t_S - t_P = R\left(\frac{1}{V_S} - \frac{1}{V_P}\right) \quad\Longrightarrow\quad R = \frac{V_P V_S}{V_P - V_S}\,\Delta t = k\,\Delta t \]

    \(V_P = 6.0\)、\(V_S = 3.5\ \mathrm{km/s}\) 時 \(k = 8.4\ \mathrm{km/s}\)；\(V_P/V_S = \sqrt{3}\) 時約 \(8.2\ \mathrm{km/s}\)，這就是「S−P 每差 1 秒，距離約 8 km」的經驗法則。兩種波的走時都與 \(R\) 成正比，所以 S−P 時間差隨距離穩定增加。震源深度為 \(h\) 時，震央距離 \(\Delta = \sqrt{R^2 - h^2}\)。

    三站定位震央

    每個測站只知道震源「多遠」，不知道「在哪個方向」，所以震源在以測站 \(i\) 為球心、半徑 \(R_i\) 的球面上：

    \[ (x - x_i)^2 + (y - y_i)^2 + h^2 = R_i^2 \]

    兩個測站的圓交於兩點，還無法決定（把這兩點當成可能的震央，是把震源深度近似為零；深度不能忽略時，震央在兩點之間的共同弦上）；第三個測站才能確定。把兩站的方程式相減，\(x^2\)、\(y^2\)、\(h^2\) 都消去了，剩下一條直線，就是兩圓的共同弦：

    \[ 2(x_j - x_i)\,x + 2(y_j - y_i)\,y = R_i^2 - R_j^2 + (x_j^2 + y_j^2) - (x_i^2 + y_i^2) \]

    震源較深時三個圓會重疊而不交於一點，但三條共同弦仍恰好交於震央，再由 \(h = \sqrt{R^2 - \Delta^2}\) 求深度。實際的讀數有誤差，三個圓會圍出一個小小的「誤差三角形」。模擬用最小平方法找最佳的點：先由共同弦的方程式解出 \((x, y)\)、估計 \(h\)，再修正 \((x, y, h)\) 使 \(\sum_i \big(\sqrt{\Delta_i^2 + h^2} - R_i\big)^2\) 最小。測站越多，誤差越能互相抵消。在模式二，震央要你自己定：在地圖上點出來、按「確認我的震央」，之後才顯示電腦用最小平方法算出的點（灰色十字）當對照；你的深度由你的標記推算：每站 \(h^2 = d_i^2 - \Delta_i^2\)，再取平均。

    地球內部與陰影區

    地球內部的波速隨深度改變，射線因此彎曲。在球對稱分層的地球中，司乃耳定律寫成

    \[ \frac{\sin i_1}{v_1} = \frac{\sin i_2}{v_2} \ \ \text{（每個界面）}, \qquad p = \frac{r \sin i}{v} = \text{定值（整條射線）} \]

    其中 \(i\) 由半徑方向量起。外核（深 2891–5150 km）是液體，S 波進不去，所以離地震約 103° 以外收不到直接的 S 波，稱為 S 波陰影區。P 波進得去，但波速從約 13.7 km/s 突然降到 8.1 km/s，強烈偏向法線，所以約 103°–143° 之間幾乎收不到 P 波，稱為 P 波陰影區。古騰堡（Beno Gutenberg）在 1913 年定出地核的邊界約在 2900 km 深；1936 年雷曼（Inge Lehmann）用陰影區裡微弱的 P 波，推論出固態的內核。

    觀察重點

    • 質點怎麼動：在藍色 P 波前剛經過時暫停，質點沿射線方向前後動；紅色 S 波前經過時，質點垂直射線振動。看測站的「地面運動軌跡」：P 波是一條前後的線段、S 波是與它垂直的線段，表面波則是橢圓。
    • S 波遇到液體就停：剖面下方的長條裡，P 波脈衝穿過界面進入水中（變慢），S 波脈衝卻全部反射回來——液體不能剪切，就沒有 S 波。把右半段換成同樣的岩石，兩個脈衝都直接穿過。
    • S−P 隨距離增加：把測站從 20 km 移到 40 km、80 km，S−P 時間差每次約加倍（當 \(\Delta\) 遠大於 \(h\) 時）；把測站放在震源正上方，S−P 最短。
    • 兩站不夠：只用 2 個測站，兩個圓交於兩點，兩個都可能是震央（「我標的震央」選 2 個，把兩點都點出來）；加入第三站就能決定。把三個測站排成一直線，又會出現鏡像的兩個答案。
    • 深度：較深的地震，三個圓會重疊；打開共同弦，看它們交在震央。離震央近的測站最能定出深度。
    • 誤差：打開「含誤差」或用錯的波速換算，三個圓就不再交於一點；用 4、5 個測站，最小平方的估計更好。
    • 陰影區：沿地表拖曳測站：約 103° 以外收不到 S 波；約 103° 到 143° 之間連 P 波也收不到。試著找出恰好擦過地核的那一條射線。

    模擬方法

    • 地殼（模式一、二）：均勻、平坦的半無限地殼，\(V_P = 6.0\)、\(V_S = 3.5\ \mathrm{km/s}\)（模式一可調）。射線是直線，到達時間 \(t = R/V\) 是精確值。真實的地殼有分層，約 30 km 以下是波速較快的地函，遠處測站最先到的 P 波其實有一段走在地函裡；地球的曲率也忽略不計。
    • 質點運動：P 波位移沿射線、S 波垂直射線（只畫剖面內的 SV 分量），都是在波前「準時」開始的脈衝。雷利波用均勻半空間中雷利波的精確深度分布，速度由雷利方程式求得；並假設它在 S 波到達震源正上方的地表時開始沿地表前進（\(t_R = h/V_S + \Delta/V_R\)）。地表的反射波、SH 波與洛夫波沒有畫出；振幅為示意。
    • 長條是一維的精確解：脈衝正面撞上界面，分成反射與透射脈衝，位移的反射係數 \(r = (Z_1 - Z_2)/(Z_1 + Z_2)\)、透射係數 \(\tau = 2Z_1/(Z_1 + Z_2)\)，\(Z = \rho V\) 為波阻抗；能量守恆：\(r^2 + (Z_2/Z_1)\tau^2 = 1\)。岩石 \(\rho = 2.7\ \mathrm{g/cm^3}\)；水 \(\rho = 1.0\ \mathrm{g/cm^3}\)、\(V_P = 1.5\ \mathrm{km/s}\)、\(V_S = 0\)。
    • 模式二的地震紀錄是示意的單一分量紀錄：到達時間精確，波形與振幅只是示意。「含誤差」會加上背景雜訊，並讓每條路徑的波速有最多 ±3% 的隨機誤差（不均勻的地殼）。臺灣的海岸線是依經緯度簡化描繪的多邊形。
    • 地球模型（模式三）：PREM（Dziewonski & Anderson, 1981, Physics of the Earth and Planetary Interiors 25, 297–356），切成厚度不超過 5 km 的殼層，每層的波速取該層中點的 PREM 值（頂部 3 km 的海水改成地殼）。殼層內射線是直線，角距與走時都精確計算；每個界面都遵守司乃耳定律。殼層再切薄，結果的變化約在 1° 以內。地震發生在地表；繞射波與反射波不計。
    • 3D 立體檢視：位置、半徑與時間都由同一份程式（earthquake-core.js）計算，和 2D 用同一組設定、同一個時刻。模式一的波前是以震源為球心、半徑 \(V_P t\) 與 \(V_S t\) 的球面，它與地表的交線是以震央為圓心、半徑 \(\sqrt{(Vt)^2 - h^2}\) 的圓；地表起伏把每一點到震央的水平距離代入與 2D 地表線相同的位移公式（各方向都一樣）。模式二每個半球的半徑就是 \(d = k\Delta t\)，兩個半球交成直立的半圓，你的標記正下方的小球深度是 \(h = \sqrt{\overline{d^2 - \Delta^2}}\)；確認後，電腦用最小平方法求得的震源以灰色顯示。模式三的切面放的是與 2D 剖面相同的射線追蹤結果，地表的陰影區由同一組臨界射線算出。3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才會下載。
