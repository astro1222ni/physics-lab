熱機循環與熱力學第一定律

汽缸裡的氣體被加熱、膨脹推動活塞，再被冷卻、壓縮，最後回到原來的狀態。轉完一圈，它的內能沒有改變，卻把吸進來的一部分熱變成了功。在 P–V 圖上逐點跟著循環走，用熱力學第一定律 ΔU = Q + W 記下每一段的能量帳，並比較卡諾循環和汽油引擎（奧圖）、柴油引擎（狄塞爾）、史特林引擎、噴射引擎（布雷頓）背後的理想化循環。把任何循環倒過來轉就成了冰箱或熱泵；也可以拖曳頂點畫出自己的循環，或切換到 3D，看每個循環都是狀態曲面 T = PV/(nR) 上的一條路徑。

試試看：先看卡諾循環轉一圈，再勾選「逆向運轉」，看面積的顏色、熱流與箭頭怎麼全部反過來。

拖曳旋轉，滾輪或雙指縮放，右鍵或雙指拖曳平移。氣體的每一個平衡態都在曲面 T = PV/(nR) 上；立體路徑就是 2D 的同一個循環，畫在這個曲面上，底面則是它的 P–V 圖。

實驗目的

  1. 用熱力學第一定律 ΔU = Q + W，記下循環每一段的能量帳。
  2. 從 P–V 圖讀出淨功（循環圍成的面積），並由繞行方向分辨熱機與冰箱。
  3. 比較各種真實引擎背後的理想化循環的效率，驗證沒有一個超過卡諾效率（第二定律）。

原理

1. 熱力學第一定律與符號約定

理想氣體的內能只和溫度有關：\(U = nC_VT\)。熱量 \(Q\) 流進來，或外界對氣體作功 \(W\)，內能就會改變。與「理想氣體分子模擬」頁相同，\(Q\) 是氣體吸收的熱，\(W\) 是外界對氣體作的功（壓縮時為正）：

\[ \Delta U = Q + W, \qquad W = -\int P\,dV \]

轉完一圈，氣體回到原來的狀態，\(\Delta U_{\text{循環}} = 0\)。所以引擎對外輸出的淨功是

\[ W_{\text{out}} = -\sum W = \sum Q = Q_{\text{in}} - |Q_{\text{out}}| = \oint P\,dV \]

\(Q_{\text{in}}\) 是所有吸進來的熱，\(|Q_{\text{out}}|\) 是所有放出去的熱。注意兩種功的方向：表格中的 \(W\) 是外界對氣體作的功，\(W_{\text{out}}\) 是引擎對外作的功。

2. 四種基本過程

\(n\) mol 理想氣體由狀態 1 到狀態 2（單原子 \(C_V = \tfrac32R\)、\(\gamma = \tfrac53\)；雙原子 \(C_V = \tfrac52R\)、\(\gamma = \tfrac75\)；\(C_P = C_V + R\)）：

過程\(W\)\(Q\)\(\Delta U\)
等溫（T 不變）\(-nRT\ln\dfrac{V_2}{V_1}\)\(-W\)\(0\)
等容（V 不變）\(0\)\(nC_V\Delta T\)\(nC_V\Delta T\)
等壓（P 不變）\(-P\Delta V\)\(nC_P\Delta T\)\(nC_V\Delta T\)
絕熱（\(PV^\gamma\) 不變）\(nC_V\Delta T\)\(0\)\(nC_V\Delta T\)

3. 圍成的面積就是淨功

膨脹時氣體對外作的功，是上方曲線底下的面積；壓縮時外界對氣體作的功，是下方曲線底下的面積。兩者的差就是循環圍成的面積。順時針繞（高壓時膨脹、低壓時壓縮），引擎對外作功，是熱機；逆時針繞，外界必須輸入功，是冰箱或熱泵。

4. 效率與第二定律

\[ \eta = \frac{W_{\text{out}}}{Q_{\text{in}}} \;\le\; \eta_C = 1 - \frac{T_{\min}}{T_{\max}} \]

任何熱機都一定要排掉一部分熱。在最高溫 \(T_{\max}\) 與最低溫 \(T_{\min}\) 之間運轉的可逆循環，吸熱時的溫度都不高於 \(T_{\max}\)，放熱時都不低於 \(T_{\min}\)；可逆循環滿足 \(\oint dQ/T = 0\)，所以效率不可能超過卡諾效率。只有卡諾循環（全部在 \(T_{\max}\) 吸熱、全部在 \(T_{\min}\) 放熱）剛好達到。

5. 真實引擎背後的理想化循環

奧圖（汽油引擎）\[ \eta = 1 - \frac{1}{r^{\gamma - 1}} \]
狄塞爾（柴油引擎）\[ \eta = 1 - \frac{1}{r^{\gamma - 1}}\,\frac{r_c^{\gamma} - 1}{\gamma(r_c - 1)} \]
布雷頓（燃氣渦輪、噴射引擎）\[ \eta = 1 - \frac{1}{r_p^{(\gamma - 1)/\gamma}} \]
  • 奧圖：以壓縮比 \(r = V_1/V_2\) 絕熱壓縮，火星塞點火、燃料燒得極快，體積來不及變（等容加熱），接著絕熱膨脹作功，最後排氣把熱帶走（等容放熱）。效率只由 \(r\) 和 \(\gamma\) 決定：在加熱之前，壓縮已經讓溫度升高到 \(r^{\gamma-1}\) 倍。
  • 狄塞爾：只靠壓縮就讓空氣熱到能點燃噴進來的燃料，燃料在活塞後退時燃燒（等壓加熱，截止比 \(r_c = V_3/V_2\)）。同樣的 \(r\) 效率比奧圖低，但不會爆震，所以可以用大得多的 \(r\)。
  • 史特林：兩段等溫加兩段等容。有理想的回熱器時，降溫時放出的熱存起來、升溫時再還給氣體，與外界交換的熱只在 \(T_h\) 吸進、在 \(T_c\) 放出，效率剛好等於卡諾效率。
  • 布雷頓：壓縮機把壓力提高到 \(r_p\) 倍，燃料在等壓下燃燒，熱氣通過渦輪膨脹，排氣在等壓下冷卻。當 \(r_p = r^{\gamma}\) 時，壓縮造成的升溫和壓縮比 \(r\) 的奧圖引擎一樣，效率也一樣。

6. 冰箱與熱泵

把循環倒過來轉，所有箭頭都反向：外界輸入功 \(W_{\text{in}} = |W_{\text{out}}|\)，氣體從冷處吸熱 \(Q_c\)，把 \(|Q_h| = Q_c + W_{\text{in}}\) 送到熱處。冰箱看它搬走多少熱，熱泵看它送出多少熱：

\[ K_R = \frac{Q_c}{W_{\text{in}}} \le \frac{T_c}{T_h - T_c}, \qquad K_{HP} = \frac{|Q_h|}{W_{\text{in}}} = K_R + 1 \le \frac{T_h}{T_h - T_c} \]

冷熱兩邊的溫差 \(T_h - T_c\) 越小，搬同樣多的熱需要的功越少。

觀察重點

  • 看能量帳：每一列都是 Q + W = ΔU；整圈加起來，ΔU 的和是 0，Q 的和就是淨功。
  • 卡諾循環只在兩段等溫過程有熱流；絕熱過程中汽缸放在絕熱墊上，溫度的改變完全來自作功。
  • 把奧圖循環的 T3 調高：圈變大、淨功變多，效率卻不變；改調壓縮比，效率才會上升。
  • 把雙原子氣體換成單原子：同樣的壓縮比，奧圖效率變高，因為 γ 較大，壓縮時升溫較多。
  • 關掉史特林的回熱器：每圈的功不變，吸的熱卻變多，效率掉到卡諾效率以下。
  • 把自訂循環的頂點拖過彼此，做成「8 字形」：一個小圈順時針、另一個逆時針，兩者的面積互相抵銷一部分。
  • 斜的直線段上，氣體可能前半段吸熱、後半段放熱；能量帳與熱流箭頭會顯示在哪裡轉換。
  • 在 3D 中沿著一條等溫線看：它是曲面上的等高線。絕熱過程沿著曲面爬升或滑下；P–V 圖就是從正上方往下看這條立體路徑。

問題與討論

  1. 卡諾熱機在 600 K 與 300 K 之間運轉，效率是多少？把高溫端提高到 900 K 呢？
    參考答案

    \(\eta = 1 - 300/600 = 50\%\)。提高到 900 K：\(\eta = 1 - 300/900 \approx 66.7\%\)。冷的一端沒辦法再往下降 300 K，所以引擎都想辦法讓燃燒更熱。

  2. 使用空氣（γ = 1.4）的奧圖引擎壓縮比為 8，理想效率是多少？為什麼真實的汽油引擎只有約 30%？
    參考答案

    \(\eta = 1 - 8^{-0.4} \approx 56.5\%\)。真實引擎會從汽缸壁散熱、燃燒需要時間、有摩擦與進排氣的損失，而且高溫氣體的 \(\gamma\) 比常溫空氣小。

  3. 某熱機每一圈吸熱 2000 J、放熱 1200 J。求淨功、效率與整圈的 ΔU。
    參考答案

    \(W_{\text{out}} = 2000 - 1200 = 800\ \mathrm{J}\)，\(\eta = 800/2000 = 40\%\)，\(\Delta U = 0\)（氣體回到原來的狀態）。

  4. 熱泵讓室內維持 293 K，室外 273 K。KHP 最大可以是多少？為什麼天氣很冷時熱泵效果變差？
    參考答案

    \(K_{HP} \le 293/(293 - 273) \approx 14.7\)。室外越冷，冷熱溫差 \(T_h - T_c\) 越大，每搬一焦耳的熱要花的功越多。

模擬方法

  • 氣體是理想氣體 \(PV = nRT\)，所有過程都是準靜態、可逆的。每一段的 Q、W、ΔU、ΔS 都由上面的解析式精確算出，不是一步一步積分；單元測試再用數值積分、P–V 圖的鞋帶公式面積、\(\Delta U_{\text{循環}} = 0\) 與 \(\Delta S_{\text{循環}} = 0\) 檢查。
  • 雙原子氣體取 \(C_V = \tfrac52R\)：常溫附近分子會轉動、幾乎不振動。約 1000 K 以上振動開始有影響，真實空氣的 \(\gamma\) 降向 1.3，真實效率也比較低。這裡的奧圖、狄塞爾、布雷頓都是「空氣標準循環」：固定的一團氣體由外界加熱與冷卻，沒有燃料、沒有進氣與排氣衝程，也沒有摩擦。
  • 自訂循環的邊是直線 \(P = a + bV\)。沿這種直線 \(dQ = \big[(C_V/R + 1)a + (2C_V/R + 1)bV\big]dV\)，在 \(V^* = -\dfrac{(C_V/R + 1)a}{(2C_V/R + 1)b}\) 變號。每條邊都在這裡拆開，\(Q_{\text{in}}\) 只算真正吸熱的部分（若只看整條邊 Q 的正負，效率會算錯）。斜邊上的最高溫也可能在邊的中間，而不在頂點。
  • 自己交叉的自訂循環，淨功是有正負的面積：順時針的小圈算正、逆時針的算負（用不同顏色塗）。
  • 回熱器開著時，史特林循環兩段等容過程的熱在引擎內部交換，不算進 \(Q_{\text{in}}\)、\(Q_{\text{out}}\)。冰箱與熱泵的卡諾上限，用循環真正能搭配的冷、熱庫：\(T_c\) 取氣體吸熱時的最高溫，\(T_h\) 取放熱時的最低溫（逆向卡諾、開回熱器的逆向史特林就是兩條等溫線）。兩個溫度範圍重疊時，找不到能搭配的冷熱庫，就不顯示上限。
  • 動畫：時間只是示意（1× 時一圈約 8 秒，每一段分到的時間隨它在圖上的長度增加）。活塞高度與體積成正比；氣體顏色依溫度，色階的亮度由冷到熱單調增加；跑動的小點只是分子的示意，速率與 √T 成正比。熱流箭頭的粗細與這個時間尺度下的熱流率成正比。
  • 3D 檢視（使用 three.js 函式庫，MIT 授權，只有切換到 3D 時才下載）在與 2D 相同的 V、P 範圍上畫出 T = PV/(nR)。曲面在比循環最高溫稍高的等溫線處截斷；曲面上的每一條等溫線就是那個高度的 PV = nRT。循環路徑、移動的狀態點與它在底面的投影，都由與 2D 相同的物理核心函式算出。
  • 音效（預設關閉）：奧圖與狄塞爾循環的燃燒加熱段開始時，有短促的點火聲；每轉完一圈，有一聲輕柔的提示音。
