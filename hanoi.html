河內塔

把整疊盤子搬到另一根柱子上：一次只能搬一個，大盤不能壓在小盤上。最漂亮的想法是遞迴——要搬 n 個盤子，先把上面 n − 1 個搬開。自己動手解解看，再看遞迴一層一層展開、第 k 步搬哪一個盤為什麼跟尺上的刻度一樣，還有所有狀態畫成的地圖裡藏著的謝爾賓斯基三角形。

試試看：按「A 柱」再按「C 柱」（或直接拖曳最上面的盤子）搬一個盤；再連按三次「跳過子問題」，看整疊怎麼搬完。

遞迴樹：節點由左到右的順序就是搬的順序；節點的高度是它搬的盤子（1、2、1、3、1、2、1……）。

狀態圖（最多畫到 7 個盤子，3 的 7 次方 = 2187 個狀態）：最大的盤在 A、B、C 的狀態各自組成小一號的同一張圖，三塊之間只靠最大的盤搬一步相連——謝爾賓斯基三角形。

背後的原理

規則

有三根柱子和 n 個大小不同的盤子，一開始由大到小疊在同一根柱子上。目標是把整疊搬到另一根柱子：一次只能搬一個盤、只能拿某根柱子最上面的那一個，而且大盤不能放在小盤上。因為每個盤子一定壓在比它大的盤子或底座上，只要知道每個盤子在哪一根柱子，整個擺法就決定了：合法的擺法剛好有 \(3^n\) 種。

用遞迴來想

要把 n 個盤從 A 搬到 C，最大的盤總有一刻要搬，那一刻其他 \(n-1\) 個盤一定都不能擋路——全部在 B 上。所以：先把 \(n-1\) 個盤從 A 搬到 B（小一號的同一個問題），把最大的盤從 A 搬到 C，再把 \(n-1\) 個盤從 B 搬到 C（又是同一個問題）。用「更小的同一個問題」來解自己，就是遞迴；只有一個盤時直接搬，是讓遞迴停下來的基本情況。

hanoi(k, from, to, via):
    if k = 0: return
    hanoi(k − 1, from, via, to)
    搬盤 k：from → to
    hanoi(k − 1, via, to, from)

設 \(T(n)\) 是最少步數。上面的做法用了 \(T(n-1) + 1 + T(n-1)\) 步，而且不可能更少：最大的盤第一次搬之前，其他 \(n-1\) 個盤必須全部集中到第三根柱子，至少要 \(T(n-1)\) 步；它最後一次搬完之後，這些盤又要全部搬到它上面，至少再 \(T(n-1)\) 步。所以

\[ T(1) = 1,\qquad T(n) = 2\,T(n-1) + 1 \quad\Longrightarrow\quad T(n) + 1 = 2\bigl(T(n-1) + 1\bigr) \quad\Longrightarrow\quad T(n) = 2^n - 1 \]

每多一個盤，工作量就加倍再加一。遞迴最深只有 \(n\) 層，但總共呼叫 \(2^n - 1\) 次——每一步對應一次呼叫。

尺規函數

把最少步數解法每一步搬的盤子寫下來：1、2、1、3、1、2、1、4、1、2、1、3……和尺上刻度的長短一模一樣。第 \(k\) 步搬的盤子是

\[ d(k) = \nu_2(k) + 1,\qquad \nu_2(k) = k \text{ 的二進位結尾 0 的個數} \]

例如 \(k = 12 = 1100_2\) 結尾有兩個 0，所以第 12 步搬盤 3。盤 \(d\) 一共搬 \(2^{\,n-d}\) 次，而且永遠朝同一個方向繞：整疊從 A 搬到 C 時，\(n - d\) 是偶數的盤照 A → C → B → A 繞，其他的照 A → B → C → A 繞。於是有一個完全不用遞迴的解法：奇數步把最小的盤沿它的方向搬一格；偶數步做「不動最小盤」的那一個合法移動（只有一個）。它搬出來的每一步都和遞迴一樣。

為什麼？在遞迴樹裡，每次呼叫是一個節點，掛在呼叫它的節點下面。依「左子樹、自己這一步、右子樹」的順序讀（中序），讀到的就是搬的順序；搬盤 d 的節點在最上層下面 n − d 層。遞迴樹本身就是那把尺。

狀態圖與謝爾賓斯基三角形

每一種合法擺法畫一個點，一步就能互相變過去的兩個點連一條線。最大的盤在 A 的那些擺法，正好組成 \(n-1\) 個盤的同一張圖；最大的盤在 B、在 C 的也是。這三塊之間只有三條線相連——就是最大的盤的那三種搬法。一直這樣分下去，就是謝爾賓斯基三角形。這張圖有 \(3^n\) 個點、\(\tfrac{3}{2}(3^n - 1)\) 條線；三個角是整疊在 A、B、C，兩個角之間的最短路就是三角形的一條邊：\(2^n - 1\) 步。

從任何擺法出發，要把所有盤集中到柱 \(t\) 最少要幾步，可以由最大的盤往下算：如果盤 \(d\) 已經在它該去的柱子上，就看下一個小一點的盤；如果不在，盤 \(d\) 一定要搬過去一次，而那之前比它小的盤必須全部在第三根柱子上——加上 \(2^{\,d-1}\)，並把第三根柱子當作比它小的盤的新目標。

\[ d = n, n-1, \dots, 1:\quad p_d \ne t \ \text{時}\ \ \text{步數} \mathrel{+}= 2^{\,d-1},\ \ t \leftarrow \text{第三根柱子（不是 } p_d \text{ 也不是 } t\text{）} \]

傳說

這個謎題 1883 年在巴黎推出，作者署名「暹羅的 N. Claus 教授，任教於 Li-Sou-Stian 學院」——那是 Lucas d’Amiens 與 Saint-Louis 的重排字母：法國數學家盧卡斯（Édouard Lucas），當時在聖路易中學任教。不久就流傳著一個傳說：在貝拿勒斯的一座神廟裡，僧侶日夜照同樣的規則搬動 64 片金盤，最後一片放好的那一刻，世界就會結束。那需要 \(2^{64} - 1 = 18\,446\,744\,073\,709\,551\,615\) 步；每秒搬一步，大約要 \(5.85 \times 10^{11}\) 年——宇宙年齡的 42 倍左右。

觀察重點

  • 那把尺：一直按「單步」，看遞迴樹。第 8 步搬哪個盤？第 24 步呢？盤 1 總共搬幾次？
  • 最小的盤往哪邊繞？用「最小盤輪流」解 n = 4 和 n = 5，最小的盤繞的方向一樣嗎？目標換成 B 呢？
  • 呼叫堆疊：n 個盤時，呼叫堆疊最深有幾層？遞迴總共呼叫 \(2^n - 1\) 次，為什麼可以這麼淺？
  • 在地圖上：自動解的時候看狀態圖上的亮點。它在哪裡從一個大三角形跨到另一個？那一刻搬的是哪個盤？
  • 迷路之後：按「打亂」，再按「廣度優先搜尋」。打亂後離目標會不會超過 \(2^n - 1\) 步？離你最遠的狀態有幾步遠？
  • 傳說：64 個盤子每秒搬一步要多久？換成每秒 \(10^9\) 步（大約是電腦一秒能做的簡單運算次數）呢？

計算方法

  • 擺法存成每個盤在哪根柱子（像 AABC 這樣的字串，第 1 個字母是盤 1），或是編號 \(\sum_d p_d\,3^{\,d-1}\)。合法的移動是：拿一根柱子最上面的盤，放到空柱子或比它大的盤上；其他的移動一律擋下並說明原因。
  • 「自動解」先建好整棵遞迴樹，再一步一步走。從整疊開始時就是經典的遞迴；從其他擺法開始時用同樣的想法（先把小盤集中到第三根柱子），得到的一定是最短路。「跳過子問題」一口氣做完目前這一層呼叫的下一個指令：從頭開始時，按三次就能解完任何一座塔（上面 n − 1 個、最大的盤、再 n − 1 個）。
  • 單元測試檢查：遞迴解用 2^n − 1 步、每一步都合法、和廣度優先搜尋找到的最短步數相同（最多 8 個盤子）；上面的距離算法對每一種擺法、每一個目標柱都和廣度優先搜尋相同（最多 8 個盤子，6561 種擺法）；到 10 個盤子為止，每一步搬的盤子都等於尺規函數；最小盤輪流和遞迴每一步都相同；第 k 步與 k 步之後的擺法可以直接算出；狀態圖有 (3/2)(3^n − 1) 條線，畫出來每條線都一樣長。
  • 狀態圖的畫法：由最大的盤往下，盤子所在的柱子決定它在目前三角形的哪一個角（占邊長的 \(2^{\,d-1}\)），進到小三角形後另外兩根柱子的角互換；最後除以 \(2^n - 1\)，每個點就落在謝爾賓斯基三角形上。廣度優先搜尋用佇列走過全部 \(3^n\) 種擺法（10 個盤子是 59 049 種）；自訂目標用它算出的距離表。
  • 傳說的計算用精確的整數算 \(2^N - 1\)（到 \(N = 100\)），一年 365.25 天，宇宙年齡用 138 億年。3D 檢視和 2D 是同一個擺法；盤子的大小與顏色只是畫圖用的。
