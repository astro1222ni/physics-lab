直線與圓：距離、交點與切線

讓一條直線掃過一個圓，用兩種方法判斷它們相離、相切還是相交：比較圓心到直線的距離和半徑，或把直線代入圓的方程式看判別式。再從圓外一點畫出兩條切線。

背後的數學

點到直線的距離

向量 \((a, b)\) 和直線 \(ax + by + c = 0\) 垂直（叫做直線的法向量）。從點 \((x_0, y_0)\) 沿著這個方向直直走到直線，就是最短的距離：

\[ d = \frac{|a x_0 + b y_0 + c|}{\sqrt{a^2 + b^2}}. \]

\(a, b, c\) 同乘一個數，直線不變，\(d\) 也不變。\(a x_0 + b y_0 + c\) 的正負號告訴你點在直線的哪一側。

直線與圓：兩種判斷法

圓 \((x - h)^2 + (y - k)^2 = r^2\)，圓心到直線的距離是 \(d\)。幾何判法：\(d > r\) 相離，\(d = r\) 相切，\(d < r\) 相交兩點，弦長 \(2\sqrt{r^2 - d^2}\)。代數判法：把直線代入圓的方程式，得到一元二次方程式；判別式 \(\Delta\) 小於、等於、大於 0，分別有 0、1、2 個實根。兩種判法一定一致，因為

\[ \frac{\Delta}{4} = b^2\Big[(a^2 + b^2)\,r^2 - (ah + bk + c)^2\Big] \quad (b \ne 0), \]

它大於 0 恰好就是 \(r > d\)。（鉛直線 \(b = 0\) 時改代入 \(x\)、解 \(y\)。）

圓外一點的切線

切線和切點 \(T\) 的半徑垂直。所以三角形 \(P\,T\,C\) 在 \(T\) 是直角，由畢氏定理得到切線長 \(PT = \sqrt{PC^2 - r^2}\)。從 \(P\) 出發的兩條切線對直線 \(PC\) 對稱、一樣長，夾角是 \(2\arcsin\dfrac{r}{PC}\)。\(P\) 在圓上時只有一條切線，在圓內則沒有。

觀察重點

  • 同一個時刻：直線移動時，\(d - r\) 和 \(\Delta\) 一起變號。
  • 弦與距離：通過圓心的弦是直徑（最長）；\(d\) 增加到 \(r\)，弦縮成一個點。
  • 越遠越窄：\(P\) 離圓越遠，兩條切線的夾角越小。

計算方法

  • 交點用「垂足 ± 半弦長」求，直線幾乎相切時也準確。這一頁的「相切」指 \(|d - r| \le 0.005\)。單元測試檢查交點同時在直線與圓上、二次方程式的根就是交點、以及上面的 \(\Delta\) 公式。
