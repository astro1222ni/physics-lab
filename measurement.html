測量與不確定度（游標尺與螺旋測微器）

真正學會讀兩種精密量具：把游標尺夾住圓棒、伸進圓管、插進孔裡，找出對齊的副尺刻線，自己輸入讀數；轉動螺旋測微器夾住細線或薄片，估讀到 0.001 mm。打開「零點誤差」，練習修正系統誤差。再對同一根圓棒反覆測量，看直方圖長出來，算出平均值、標準差與不確定度，分清楚「精密」和「準確」。

試試看：按「夾緊」，在放大鏡找出對齊的副尺刻線，輸入讀數再按「核對」。

讀數成績

讀法

  1. 先檢查零點：合攏夾爪，副尺 0 刻線不在主尺 0 時，這時的讀數就是零點誤差 \(e\)。
  2. 外徑用下方的外測爪、內徑用上方的內測爪、深度用尾端的深度桿，輕輕碰到就好。
  3. 從主尺讀出副尺 0 刻線左邊最近的毫米刻線 \(M\)（整數 mm）。
  4. 沿著副尺找出與主尺刻線對得最齊的那一條：第 \(k\) 條。
  5. 讀數 \(R = M + k \times c\)（精度 \(c\) = 0.05 或 0.02 mm），寫到 0.01 mm 位，末位的 0 也要寫。
  6. 修正零點誤差：\(L = R - e\)。
  1. 轉動套管到測軸快碰到物體，再改轉棘輪，「喀喀」兩三聲就停。
  2. 讀套筒：套管邊緣左邊露出的最後一條刻線（上排整毫米、下排半毫米），得 \(S\)。
  3. 讀套管：與基準線對齊的格數，估讀到十分之一格，得 \(n\)（例如 37.4 格）。
  4. 讀數 \(R = S + n \times 0.01\ \text{mm}\)，寫到 0.001 mm 位。
  5. 有零點誤差時 \(L = R - e\)；合攏時套管邊緣蓋過 0 刻線，\(e\) 為負。
  1. 對同一根圓棒量 \(n\) 次。
  2. 算平均值 \(\bar{x}\) 與樣本標準差 \(s\)（分母 \(n - 1\)）。
  3. A 類 \(u_A = s/\sqrt{n}\)；B 類 \(u_B = d/(2\sqrt{3})\)（\(d\) 為最小刻度）；組合 \(\sqrt{u_A^{2} + u_B^{2}}\)。
  4. 不確定度無條件進位取 2 位有效數字（第 3 位是 0 就捨去），平均值四捨五入到同一位。
  5. 寫成 \(X \pm \Delta X\)，加上單位。

數據與直方圖

長條：落在各區間的讀數個數；曲線：平均值與標準差相同的常態分布；虛線：真值（只有模擬知道）。四個靶說明精密與準確的意思，亮起來的那個符合你的數據。

統計結果

三種儀器比一比

「含真值」：X ± ΔX（A、B 類組合）的範圍有沒有包含真值。

實驗說明

實驗目的

  1. 會正確使用游標尺與螺旋測微器，讀到儀器的精度，並修正零點誤差。
  2. 了解有效數字、精密度與準確度、隨機誤差與系統誤差。
  3. 由多次測量求平均值與標準差，用 A 類、B 類不確定度寫出測量結果。

實驗器材

游標尺（精度 0.05 mm 或 0.02 mm）、螺旋測微器（最小刻度 0.01 mm，估讀到 0.001 mm），以及待測物：圓棒、圓管、有孔的木塊、細金屬線、薄片、鋼珠。

原理

游標尺的原理。主尺每格 1 mm；副尺有 \(N\) 格，總長卻只有 \(N-1\) mm，所以副尺每格比主尺每格短 \(c = 1/N\) mm，這就是精度。副尺 0 刻線超過主尺刻線 \(M\) 剛好 \(k\,c\) 時，副尺第 \(k\) 條刻線恰好和主尺刻線重合，兩旁的刻線依序差 \(c\)、\(2c\)……：

\[ c = 1\ \text{mm} - \frac{N-1}{N}\ \text{mm} = \frac{1}{N}\ \text{mm} \] \[ R = M + k\,c \]

螺旋測微器。套管轉一圈，測軸沿螺紋前進一個螺距 0.5 mm；套管一圈刻 50 格，每格就是 0.01 mm。螺旋把很小的移動放大成很大的轉動，還可以再估讀十分之一格：

\[ \frac{0.5\ \text{mm}}{50} = 0.01\ \text{mm} \] \[ R = S + n \times 0.01\ \text{mm} \]

零點誤差。合攏時讀數不是 0，每一次讀數都會偏同樣的量 \(e\)。這是系統誤差：取平均消不掉，但可以修正：\(L = R - e\)。

隨機誤差與系統誤差、精密度與準確度。隨機誤差（用力稍有不同、視線斜了、物體不是正圓）讓讀數忽大忽小；系統誤差讓讀數都往同一邊偏。精密是讀數彼此很接近（標準差小）；準確是平均值接近真值。多量幾次能對付隨機誤差，對系統誤差卻沒有用。

平均值與標準差。\(n\) 次讀數的平均值是最佳估計，樣本標準差 \(s\) 表示單次讀數的分散程度：

\[ \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i \] \[ s = \sqrt{\frac{1}{n-1}\sum_{i=1}^{n} \left(x_i - \bar{x}\right)^{2}} \]

不確定度（ISO-GUM）。\(n\) 次的平均值比單次讀數穩定得多：A 類不確定度 \(u_A = s/\sqrt{n}\)。儀器本身還有由最小刻度 \(d\) 估計的 B 類不確定度（假設一格之內每個值的機會相同）。兩者像直角三角形的兩股一樣組合：

\[ u_A = \frac{s}{\sqrt{n}} \] \[ u_B = \frac{d}{2\sqrt{3}} \] \[ \Delta X = \sqrt{u_A^{2} + u_B^{2}} \]

\(\Delta X\) 以無條件進位取至多 2 位有效數字（第 3 位是 0 就直接捨去：0.1417 → 0.15，0.1407 → 0.14），再把平均值四捨五入到與 \(\Delta X\) 末位一致，寫成 \(X \pm \Delta X\)。例：單擺週期量 4 次 2.10、2.08、2.09、2.04 s，\(\bar{x} = 2.0775\) s、\(s = 0.0263\) s、\(u_A = 0.0131\) s，結果是 \(2.078 \pm 0.014\) s。

有效數字。非零的數字都是；非零數字之間的 0 是；前綴的 0 不是；小數點後的後綴 0 是。所以 23.40 mm（4 位）比 23.4 mm（3 位）多說了一件事：百分位也量了，而且是 0。

實驗步驟

① 游標尺。合攏夾爪讀出零點。輕輕夾住待測物：圓棒放在下方外測爪之間、圓管套在上方內測爪、深度桿伸進孔底。由主尺讀 \(M\)、找出對齊的副尺刻線 \(k\)，寫出 \(R = M + kc\)（到 0.01 mm）並修正零點。

② 螺旋測微器。用棘輪讓測軸碰到測砧，讀出零點。放入細線或薄片，轉套管到快碰到，再用棘輪轉到「喀喀」聲。讀套筒（別漏了半毫米刻線）、讀套管並估讀一位，最後修正零點。

③ 多次測量。對同一根圓棒量很多次，求 \(\bar{x}\)、\(s\)、\(u_A\)、\(u_B\) 與 \(\Delta X\)，寫出測量結果，比較三種儀器。

注意事項

  • 不要用力夾：太用力會讓夾爪變形、壓扁軟的物體。測微器最後一定用棘輪轉，它每次都在同樣的力打滑。
  • 視線垂直刻度面，避免視差。夾爪要和物體垂直：歪斜時量外徑會偏大、量內徑會偏小。
  • 每次使用前先檢查零點，並記下正負號。
  • 測微器要注意半毫米刻線有沒有露出來；看漏了就剛好差 0.5 mm。
  • 在不同位置、不同方向多量幾次：真實的圓棒和細線都不是完美的圓。

問題與討論

  1. 副尺 10 格總長 9 mm，精度是多少？如果想讓刻線間隔大一倍、精度仍是 0.1 mm，要怎麼設計？
  2. 零點誤差 −0.15 mm 的游標尺量得 23.45 mm，物體實際多長？
  3. 測微器的套管邊緣緊貼著 2.5 mm 刻線，套管讀到約 48 格。讀數是 2.48 mm 還是 2.98 mm？怎麼判斷？
  4. 量 4 次時 \(u_A = 0.020\) mm。要降到 0.010 mm 要量幾次？為什麼量再多次，組合不確定度也不會小於 \(u_B\)？
  5. 你的數據精密但不準確，多量幾次會變準確嗎？應該怎麼做？
  6. 為什麼不確定度要無條件進位，平均值卻用四捨五入？

觀察重點

  • 對齊的對稱：把放大鏡移到對齊的刻線附近，它左邊的刻線往一邊偏、右邊的往另一邊偏，每遠一條就多差 \(c\)。
  • 次數變 4 倍，A 類不確定度減半：σ = 0.050 mm 時，比較量 10 次與量 40 次的 \(u_A\)。
  • 儀器決定的下限：把 σ 設成 0，每次讀數都相同、\(s = 0\)，不確定度只剩 \(u_B\)。
  • 精密但不準確：系統誤差 0.100 mm、σ = 0.005 mm，直方圖很窄，卻離真值的虛線有一段距離。
  • 換精密的儀器不一定有用：σ = 0.100 mm 時三種儀器的不確定度差不多；σ = 0.005 mm 時測微器明顯勝出。

模擬方法

  • 每個待測物的尺寸都剛好在儀器的格點上（0.05 mm、0.02 mm 或 0.001 mm），所以正確讀數只有一個。零點誤差隨機產生：20 格副尺最多 ±0.30 mm、50 格最多 ±0.20 mm、測微器最多 ±0.015 mm。讀數以整數微米儲存，沒有捨入誤差。
  • 副尺刻線的位置完全依比例：第 k 條在 R + k(N − 1)/N mm。游標尺的放大鏡只放大水平方向（刻線長度不變，數字才看得到）；測微器的放大鏡是等比例放大，套管刻線依它在圓柱面上的位置畫在 r sin φ 的高度。
  • 多次測量：讀數 = 真值 + 系統誤差 + 常態分布的隨機誤差（Box–Muller 法），再取到儀器讀得出的值（最對齊的副尺刻線，或測微器的 0.001 mm）。隨機數由可設定種子的產生器產生，測試可以完全重現。
  • 不確定度依選修物理的寫法（ISO-GUM）：A 類 = s/√n，B 類 = 最小刻度/(2√3)，無條件進位取 2 位有效數字。這裡的「精密」指 s ≤ 2 倍最小刻度，「準確」指平均值與真值相差不到 2ΔX。
  • 沒有模擬：螺紋的間隙與磨損、熱脹冷縮、物體受夾時的彈性變形，以及游標尺夾持力大小對讀數的影響。
