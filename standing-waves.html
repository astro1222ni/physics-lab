繩波的反射與駐波

沿著繩子送出一個脈波，看它在固定端（倒立）與自由端（正立）如何反射；再讓振盪器連續送出正弦波，去與回的波疊加成駐波——頻率剛好是共振頻率時，會長出振幅很大、波節與波腹分明的駐波。

顯示

背後的物理

拉緊的繩子上，波以固定的速率 \(v\) 傳播（由張力與線密度決定）。形狀不變、向右傳的波可寫成 \(y = g(x - vt)\)，向左傳的波寫成 \(y = h(x + vt)\)。兩個波相遇時，繩子的位移就是兩者相加——疊加原理；穿過彼此之後，各自保持原來的形狀繼續前進：

\[ y(x,t) = y_{\text{入射}} + y_{\text{反射}} \]

固定端與自由端的反射

讓繩子的端點在 \(x = L\)，脈波 \(g(x - x_0 - vt)\) 向它前進。反射波可以用一個巧妙的方法求得（鏡像法）：想像繩子延伸到端點後面，有一個「鏡像脈波」從另一邊迎面而來。它左右鏡射，並且倒立（固定端）或正立（自由端），使得兩者相加剛好滿足端點的條件：

\[ y_{\text{反射}}(x,t) = s\, g(2L - x - x_0 - vt), \qquad s = \begin{cases} -1 & \text{固定端：}\ y(L,t) = 0 \\ +1 & \text{自由端：}\ \dfrac{\partial y}{\partial x}(L,t) = 0 \end{cases} \]

在固定端，繩子不能動，反射波倒立回來（相位改變 \(\pi\)）。在自由端（套在光滑桿上的輕環），端點的繩子必須保持水平，反射波正立回來；反射的瞬間，端點的位移可達脈波高度的 2 倍。

駐波

讓振盪器連續送出振幅 \(A\)、頻率 \(f\)、波長 \(\lambda = v/f\) 的正弦波，向固定端前進。入射波與反射波振幅相同、方向相反，相加之後的波不再前進：

\[ A\sin(\omega t - kx) - A\sin(\omega t + kx) = -2A\sin(kx)\cos(\omega t), \qquad k = \frac{2\pi}{\lambda},\ \ \omega = 2\pi f \]

（這裡 \(x\) 由固定端量起。）繩上每一點同步振動，振幅 \(2A\lvert\sin kx\rvert\) 隨位置而不同。永遠不動的點是波節，振幅最大（\(2A\)）的點是波腹。相鄰波節相距半個波長，波腹在兩個波節正中間：

\[ \text{波節：}\ x = 0,\ \frac{\lambda}{2},\ \lambda,\ \frac{3\lambda}{2},\ \dots \qquad \text{波腹：}\ x = \frac{\lambda}{4},\ \frac{3\lambda}{4},\ \frac{5\lambda}{4},\ \dots \]

共振頻率

波在兩端之間來回反射。只有每往返一次都和振盪器同相時，一次次的反射才會一直加強，長出振幅很大的駐波——這就是共振。條件是繩長剛好容納整數個半波長（兩端固定，兩端都是波節），或奇數個四分之一波長（一端固定一端自由：固定端是波節、自由端是波腹）：

\[ \text{兩端固定：}\ L = n\frac{\lambda}{2},\quad f_n = \frac{n v}{2L} = n f_1 \] \[ \text{一端固定一端自由：}\ L = (2n-1)\frac{\lambda}{4},\quad f = \frac{(2n-1) v}{4L} \]

兩端固定時，\(f_1 = v/2L\) 的每一個整數倍都會共振，第 \(n\) 諧音有 \(n + 1\) 個波節、\(n\) 個波腹。一端自由時，只有 \(f_1 = v/4L\) 的奇數倍會共振（\(f_1, f_3, f_5, \dots\)），第 \(n\) 個共振頻率有 \(n\) 個波節、\(n\) 個波腹。

觀察重點

  • 固定端倒立：在固定端送出脈波，反射時端點始終不動，入射與反射脈波在端點互相抵消，脈波倒立回來。改成自由端：端點的環上升到脈波高度的 2 倍，脈波正立回來。
  • 左右也鏡射：選「不對稱」脈波，反射脈波也左右鏡射，陡的一邊仍朝向前進方向。
  • 小珠不會前進：盯著一顆小珠，脈波經過時它只上下移動。波傳遞的是能量與形狀，不是繩子本身。
  • 長出駐波：在駐波模式按共振按鈕（例如 \(f_3\)），每往返一次振幅就變大一些，最後穩定成 4 個波節、3 個波腹。紅色與藍色的波都還在前進，但相加起來卻停在原地振動。
  • 偏離共振：把頻率稍微調離共振，回來的波不再同相，一開始繩子亂動，最後只剩很小的振動，而且振盪器端不再是波節。
  • 一端自由只有奇數倍：改成自由端，最低的共振頻率減半（\(v/4L\) 而不是 \(v/2L\)），只有 \(f_1, f_3, f_5, \dots\) 會共振，自由端永遠是波腹。
  • 弦越長音越低：改變 \(L\) 或 \(v\)，共振頻率與 \(v/L\) 成正比——吉他弦按得越長或越鬆，音就越低。

模擬方法

  • 沒有逐步數值積分。每一點的位移都直接由波動方程式 \(\partial^2 y/\partial t^2 = v^2\,\partial^2 y/\partial x^2\) 的行進波解析解加上鏡像法算出，端點條件在每一瞬間都精確成立。
  • 駐波模式中，振盪器端對回來的波而言像固定端，但只反射 \(\rho = 0.7\) 的振幅（其餘被吸收）；若完全沒有損耗，共振時振幅會無限增大。設 \(F(\tau)\) 為由 \(x = 0\) 送出的波、\(T_r = 2L/v\) 為往返時間、\(s = \mp 1\) 為遠端的反射係數，則
\[ F(\tau) = a\sin\omega\tau - \rho s\,F(\tau - T_r) = a\sum_{m=0}^{\lfloor \tau/T_r \rfloor} (-\rho s)^m \sin\omega(\tau - m T_r), \qquad y = F\!\left(t - \frac{x}{v}\right) + s\,F\!\left(t - \frac{2L - x}{v}\right) \]
  • 振盪器振幅 \(a = 1\ \mathrm{cm}\)，共振時每個行進波的穩定振幅為 \(a/(1-\rho) \approx 3.3\ \mathrm{cm}\)，波腹約 \(6.7\ \mathrm{cm}\)。繩子下方的共振曲線畫出穩定振幅與 \(a\) 的比值隨頻率的變化。
  • 脈波高度 3 cm。改變任何設定時，繩子從靜止重新開始。動畫以真實時間播放（慢動作為 0.25 倍）。
  • 繩子視為理想繩：均勻、完全柔軟、位移很小，傳播途中沒有摩擦損耗。
