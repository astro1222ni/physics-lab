電子組態

電子怎麼住進原子裡？照構築原理，電子從能量最低的副層開始一個一個填；包立不相容原理規定每個軌域最多住兩個自旋相反的電子；洪德定則讓電子先分開住、自旋平行，住滿一輪才配對。看 118 個元素的電子一個一個進場，抓出鉻、銅這些不守規矩的例外，算出離子的組態，再自己動手填填看。3D 能階階梯把 n + l 規則立起來。

試試看：把原子序調到 24（鉻），按「逐一填入」。前 23 個電子都照規矩來，注意最後發生了什麼事。

實驗目的

  1. 用構築原理、包立不相容原理與洪德定則，寫出原子的基態電子組態。
  2. 找出不照 n + l 規則的元素，說明為什麼半滿、全滿的副層特別受歡迎。
  3. 寫出離子的電子組態，看看過渡金屬為什麼先失去 4s 電子。

原理

主層、副層與軌域

主量子數 \(n = 1, 2, 3, \dots\) 決定主層。主層裡，角量子數 \(l = 0, 1, 2, 3\) 決定副層 s、p、d、f，一個副層有 \(2l + 1\) 個軌域（\(m_l\) 的值）。每個軌域最多兩個電子，一個自旋 \(m_s = +\tfrac12\)（↑）、一個 \(m_s = -\tfrac12\)（↓）。

\[ \text{副層最多 } 2(2l+1) \text{ 個} \] \[ \text{主層最多 } 2n^2 \text{ 個} \]

三個規則

  • 構築原理：電子先填能量最低的副層。多電子原子的順序照 \(n + l\) 規則：\(n + l\) 小的先填；\(n + l\) 相同時，\(n\) 小的先填。所以 4s（\(4 + 0 = 4\)）比 3d（\(3 + 2 = 5\)）先填。
  • 包立不相容原理：同一個原子裡沒有兩個電子的四個量子數 \((n, l, m_l, m_s)\) 完全相同，所以一個軌域最多兩個電子，而且自旋必須相反。
  • 洪德定則：能量相同的幾個軌域，電子先分開住、自旋平行，每個軌域都有一個以後才開始配對。一個有 \(2l + 1\) 個軌域的副層放 \(k\) 個電子時，未成對電子數是
\[ u = \min\bigl(k,\; 2(2l+1) - k\bigr) \]

例外

4s 與 3d（同樣地 ns、(n−1)d、(n−2)f）的能量非常接近。半滿（d5、f7）或全滿（d10）的副層有許多平行或配對的自旋，特別穩定，所以鉻是 [Ar]3d54s1 而不是 [Ar]3d44s2，銅是 [Ar]3d104s1。118 個元素中有 20 個這樣的例外；勾選「顯示構築原理的預測」可以對照。

離子

陽離子先失去最外面的電子：\(n\) 最大的（\(n\) 相同時 \(l\) 最大的）。對過渡金屬來說，4s 電子比 3d 先失去：Fe 是 [Ar]3d64s2，Fe2+ 卻是 [Ar]3d6。陰離子把多的電子照 \(n + l\) 規則放進下一個空位，通常剛好變成下一個鈍氣的組態。

觀察重點

  • 第 4 週期：鉀、鈣先填 4s，鈧到鋅填 3d，填完才從鎵開始填 4p。
  • 「未成對電子」圖：每一區都升到半滿最高、全滿時回到 0；p 區的高峰在第 15 族（N、P），d 區在中間。
  • 例外全部在 d 區與 f 區，而且同一族的元素不一定有一樣的例外。
  • 電子數相同（等電子）的粒子，電子組態也相同，例如 Na+、Mg2+、F− 和 Ne。
  • 在「自己填」裡，試著把兩個 ↑ 放進同一個軌域，或太早讓電子配對，看看檢查結果怎麼說。

問題與討論

  1. 為什麼鉀的最後一個電子填進 4s，而不是 3d？
  2. 鐵是 [Ar]3d64s2。為什麼 Fe2+ 是 [Ar]3d6，而不是 [Ar]3d44s2？
  3. 為什麼氧原子有兩個未成對電子，而不是零個？
  4. Zn2+ 的化合物多半無色，Cu2+ 的化合物多半是藍色或綠色。兩者的電子組態有什麼不同？
看參考答案
  1. 4s 電子有一部分時間鑽到很靠近原子核的地方（穿透內層），受到的遮蔽比較少。對鉀來說，這讓 4s 的能量比 3d 低。（從鈧開始填 3d 以後，3d 的能量其實又降到 4s 以下。）
  2. 離子中最外層是 n = 4 的 4s 電子；而且帶正電以後，3d 的能量降得比 4s 更多。所以先失去的是兩個 4s 電子。
  3. 4 個 2p 電子照洪德定則：前 3 個分別住進 3 個 2p 軌域、自旋平行，第 4 個才配對。剩下兩個軌域各有一個電子。（O2 會被磁鐵吸引也和未成對電子有關。）
  4. Zn2+ 是 3d10：d 副層全滿，電子沒有空位可以在 d 軌域之間跳。Cu2+ 是 3d9：有一個空位，d 電子吸收可見光就能跳上去，溶液呈現互補色。

模擬方法

  • 填入順序用 n + l 規則（馬德隆規則），1s 到 7p 共 19 個副層，剛好放得下 118 個電子。電子一次放一個；同一副層內照洪德定則（先一格一個 ↑，再配對）。
  • 中性原子的基態組態取自 NIST 原子光譜資料庫。有 20 個元素和 n + l 規則不同：Cr、Cu、Nb、Mo、Ru、Rh、Pd、Ag、La、Ce、Gd、Pt、Au、Ac、Th、Pa、U、Np、Cm、Lr。「逐一填入」時它們先照規則填，最後再把要搬家的電子搬到真正的位置。104 號以後是理論預測。
  • 鐒（Lr）在 NIST 資料中是 [Rn]5f147s27p1（相對論效應讓 7p 低於 6d），不是很多課本寫的 6d1。
  • 陽離子：先拿走鈍氣核心以外的電子，\(n\) 大的先、\(n\) 相同時 \(l\) 大的先。這是課本的規則；少數氣態一價離子（例如 V+、La+）的電子會重新排列，這裡不處理。陰離子照 \(n + l\) 規則加電子，只提供氫與第 15–17 族，最多補到下一個鈍氣。每個元素都可以選 +1 到 +4，即使某些離子在化學上並不常見。
  • 「自己填」的檢查：每個副層的電子數都和基態一樣，而且每個副層都照洪德定則（未成對電子最多、自旋平行），才算基態。不同副層之間的自旋方向不檢查（真實原子通常也平行，鈰是例外）。
  • 2D 圖的上下位置與 3D 階梯的高度只代表填入的先後，不是真實的軌域能量（真實能量隨元素改變）。3D 裡每個副層的高度是 \(0.8\,(n + l - 1) + 0.16\,n\)：同一個 \(n + l\) 是一層平台，同一層裡 \(n\) 大的稍高一點。
  • 未成對電子由軌域圖數：只有一個電子的軌域算一個。有未成對電子的原子或離子是順磁性（會被磁鐵吸引）；沒有的是反磁性。
