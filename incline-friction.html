斜面與摩擦力

木塊放在可以抬高的木板上。改變斜面角度、質量與接觸面的材質，觀察靜摩擦力「需要多少給多少」，直到最大靜摩擦力 μsN 後滑動、改為動摩擦力 μkN。慢慢抬高斜面找出臨界角，用兩個光電門量下滑時間求出動摩擦係數，也可以沿斜面或水平推木塊。

試試看：按「慢慢抬高」，看紅色摩擦力箭頭變長，記下開始滑的角度。

    背後的物理

    把重力 \(mg\) 分解成沿斜面與垂直斜面兩個分量。斜面以正向力 \(N\) 頂住木塊；沒有外力時，正向力剛好抵消垂直分量：

    \[ W_{\parallel} = mg\sin\theta, \qquad W_{\perp} = mg\cos\theta, \qquad N = mg\cos\theta \]

    靜摩擦力：需要多少給多少，但有上限

    木塊靜止時，靜摩擦力是「讓木塊保持靜止所需要的力」——大小、沿斜面向上或向下都可以，但不能超過最大靜摩擦力 \(\mu_s N\)。如果需要的摩擦力比這個還大，木塊就開始滑動，摩擦力改為大小固定、與滑動方向相反的動摩擦力。真實的接觸面 \(\mu_k < \mu_s\)，所以一開始滑動，摩擦力會突然變小：

    \[ 0 \le f_s \le \mu_s N \quad(\text{靜止}), \qquad f_k = \mu_k N \quad(\text{滑動}) \]

    臨界角（休止角）

    沒有外力時，只要 \(mg\sin\theta \le \mu_s\, mg\cos\theta\)，木塊就不會動。慢慢抬高斜面，木塊在臨界角 \(\theta_c\) 開始滑動。質量消掉了，所以同材質的木塊不論輕重都在同一個角度開始滑：

    \[ \tan\theta_c = \mu_s \]

    下滑與測量動摩擦係數

    往下滑動時，沿斜面（向下為正）用牛頓第二定律，得到固定的加速度。由 \(x = 0\) 靜止釋放，木塊在 \(t_1\)、\(t_2\) 通過位置 \(x_1\)、\(x_2\) 的光電門，\(x = \tfrac12 a t^2\)，由此求出 \(a\)，再求出 \(\mu_k\)：

    \[ ma = mg\sin\theta - \mu_k mg\cos\theta \;\Rightarrow\; a = g(\sin\theta - \mu_k\cos\theta) \] \[ a = \frac{2(x_2 - x_1)}{t_2^{2} - t_1^{2}}, \qquad \mu_k = \tan\theta - \frac{a}{g\cos\theta} \]

    若 \(\tan\theta = \mu_k\)，加速度為零：已經在滑的木塊會等速下滑。但因為 \(\mu_s > \mu_k\)，在這個角度靜止放著的木塊不會自己開始動，要輕推一下。若 \(\tan\theta < \mu_k\)，滑動的木塊會減速、停下，然後重新被靜摩擦力「黏住」。

    沿斜面推

    沿斜面往上推，推力為 \(F\)。靜止時需要的摩擦力是 \(f = F - mg\sin\theta\)（向下為正）：\(F\) 小時摩擦力沿斜面向上，\(F > mg\sin\theta\) 之後改為向下。要 \(F > mg(\sin\theta + \mu_s\cos\theta)\) 才推得動；往上滑動時

    \[ F - mg\sin\theta - \mu_k mg\cos\theta = m a_{\text{上}} \]

    水平推

    水平推力 \(F\) 有沿斜面向上的分量 \(F\cos\theta\)，但另一個分量 \(F\sin\theta\) 把木塊壓向斜面，使正向力與摩擦力都變大：

    \[ N = mg\cos\theta + F\sin\theta, \qquad F\cos\theta - mg\sin\theta - \mu_k(mg\cos\theta + F\sin\theta) = m a_{\text{上}} \]

    要推得動需要 \(F(\cos\theta - \mu_s\sin\theta) > mg(\sin\theta + \mu_s\cos\theta)\)。當 \(\cos\theta \le \mu_s\sin\theta\)，也就是 \(\theta \ge 90^\circ - \theta_c\) 時，水平推力再大也推不上去（自鎖現象）。

    摩擦力作功變成熱

    動摩擦力永遠與滑動方向相反，作負功，大小等於產生的熱。它和路徑長有關（上去再下來要算兩段），不是位移。功能定理在任何時刻都成立：

    \[ Q = -W_f = \mu_k N \times (\text{路徑長}), \qquad \Delta\!\left(\tfrac12 m v^2\right) = W_g + W_F + W_f \]

    觀察重點

    • 找臨界角：在小角度放手，再按「慢慢抬高」。木頭（\(\mu_s = 0.50\)）在 \(\theta_c = \tan^{-1}0.50 \approx 26.6^\circ\) 開始滑——不論質量多少。
    • 看摩擦力突然變小：一開始滑，紅色的摩擦力箭頭立刻變短（\(\mu_s N \to \mu_k N\)），所以角度沒變，剛開始滑的木塊也會加速。
    • 經典摩擦力圖：設 \(\theta = 0\)、按「慢慢加力」。摩擦力等於拉力，沿直線上升到 \(\mu_s mg\)，然後降到 \(\mu_k mg\)。在斜面上，這條直線整個往下移 \(mg\sin\theta\)，而且會穿過零——靜摩擦力換了方向。
    • 量 μk：在大於 \(\theta_c\) 的角度靜止釋放，讀光電門的 \(t_1\)、\(t_2\)，算出 \(a\) 與 \(\mu_k\)。試試神秘表面，再核對你的答案。
    • 等速度要先推一下：讓 \(\tan\theta = \mu_k\)（木頭：\(16.7^\circ\)）。靜止放手不會動；給它 \(v_0 > 0\)，殘影的間距就完全相等。
    • 上去再下來：從底端以負的 \(v_0\) 射出。上坡時以 \(g(\sin\theta + \mu_k\cos\theta)\) 減速；若 \(\tan\theta > \mu_s\) 會滑回來，下坡加速度較小，為 \(g(\sin\theta - \mu_k\cos\theta)\)，回到底端時比出發時慢。比較摩擦生熱 \(Q\) 與動能的減少。
    • 水平推：選「水平」，看正向力 \(N\) 隨 \(F\) 變大。斜面很陡時（木頭：超過 \(63.4^\circ\)），推力開到最大也推不上去。

    模擬方法

    • 力不變時加速度固定，位置與速度直接用 \(x = x_0 + v_0 t + \tfrac12 a t^2\) 的精確公式計算；速度歸零、撞到擋板、通過光電門的時刻都由公式精確解出。
    • 速度歸零時，如果需要的靜摩擦力不超過 \(\mu_s N\) 就停住，否則立刻往回滑。「慢慢抬高」與「慢慢加力」時，模擬時間每 2 ms 更新一次角度或外力，所以開始滑動的角度或外力誤差在 0.004° 或 0.02 N 以內。
    • 木塊視為只滑動、不翻倒的質點，畫面上的大小依比例。木板視為緩慢轉動，不考慮木板本身轉動的影響。撞到擋板時木塊立即停止（損失的動能與摩擦生熱分開計算）。靠在擋板上時，靜摩擦力與擋板的推力如何分配在力學上不唯一，模擬取摩擦力為最大值 \(\mu_s N\)。
    • 光電門記錄木塊中心通過的時刻與當時的瞬時速度。\(g = 9.8\ \mathrm{m/s^2}\)。
