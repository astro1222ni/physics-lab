氫原子能階與光譜

背後的物理

波耳的氫原子模型

1913 年，波耳提出：電子受質子的庫侖力吸引做圓周運動，但只能在角動量為 \(h/2\pi\) 整數倍的軌道上。在這些穩定軌道上電子不會輻射；只有在軌道之間躍遷時才放出或吸收光。

\[ \frac{ke^{2}}{r^{2}} = \frac{mv^{2}}{r}, \qquad L = mvr = n\frac{h}{2\pi}\quad(n = 1, 2, 3, \dots) \]

兩式聯立，得到第 n 個軌道的半徑、速率與能量：

\[ r_n = n^{2} a_0 = n^{2}\times 0.529\ \text{Å}, \qquad v_n = \frac{2.19\times10^{6}}{n}\ \mathrm{m/s}, \qquad E_n = -\frac{ke^{2}}{2r_n} = -\frac{13.6\ \mathrm{eV}}{n^{2}} \]

動能為 \(-E_n\)、位能為 \(2E_n\)。能量為負，表示電子被束縛；\(E = 0\)（\(n \to \infty\)）代表電子剛好掙脫。所以基態氫原子的游離能是 13.6 eV。用德布羅意的物質波來看，\(L = nh/2\pi\) 等於說軌道一圈剛好容納 \(n\) 個物質波波長：\(2\pi r_n = n\lambda\)（勾選「物質波」觀察）。

光子與芮得柏公式

電子由 ni 掉到 nf 時放出一個光子，帶走兩能階的能量差；要往上跳，則必須吸收能量剛好相同的光子：

\[ \Delta E = E_{i} - E_{f} = hf = \frac{hc}{\lambda}, \qquad \frac{1}{\lambda} = R_{\mathrm{H}}\left(\frac{1}{n_f^{2}} - \frac{1}{n_i^{2}}\right), \qquad R_{\mathrm{H}} = 1.0968\times10^{7}\ \mathrm{m^{-1}} \]

落到同一個能階的譜線組成一個線系。ni 越大，譜線越擠，最後趨近「系限」；系限光子的能量剛好等於該能階的游離能。

吸收與游離

原子只吸收能量剛好等於「目前能階與某個較高能階之差」的光子，其他光子直接穿過。能量超過游離能 \(|E_n|\) 的光子則一定能被吸收：電子掙脫原子，多出的能量變成動能 \(K = hf - |E_n|\)；\(E > 0\) 的能量是連續的。反過來，自由電子被質子捕獲時放出能量 \(K + |E_n|\) 的光子（在系限之外形成連續光譜）。

發射光譜與吸收光譜

發光的氣體（例如放電管）產生發射光譜：暗背景上的明線。白光穿過氣體則產生吸收光譜：連續光譜上的暗線，位置與明線完全相同，因為它們對應同樣的能階差。但氣體只能從原子實際所在的能階吸收。冷的氫氣幾乎所有原子都在 n = 1，只會吸收來曼系（紫外線），對可見光是透明的；要原子有一部分在 n = 2——例如約 10000 K 的恆星大氣——才看得到巴耳末暗線。

放電管

放電管中，被電壓加速的電子撞擊氫原子。只有當電子的動能 \(K\) 至少等於 \(E_n - E_1\) 時，才能把原子由 n = 1 激發到 n：n = 2 需要 10.2 eV、n = 3 需要 12.09 eV（第一條可見光 Hα 至少要這麼多）、n = 4 需要 12.75 eV……這就是夫蘭克－赫茲實驗的想法。被激發的原子在幾奈秒內掉回來，常常分好幾步（串級）；往哪一層掉由機率決定，機率正比於愛因斯坦係數 \(A\)：

觀察重點

  • 跳得越遠，光子能量越大：從 n = 2 依序跳到 n = 3、4、5、6 再掉回來，巴耳末線由紅變紫，越來越擠，趨近 364.7 nm。
  • 串級時能量守恆：從 n = 4 依序掉到 3、2、1，三個光子的能量加起來（0.66 + 1.89 + 10.20 eV）等於直接 4 → 1 的 12.75 eV。
  • 只吸收剛好的能量：用 10.00 eV 的光子射向基態原子，光子直接穿過；改成 10.20 eV 試試看。
  • 同一個光子，不同的原子：486 nm（Hβ）的光子穿過基態原子，卻會被 n = 2 的原子吸收。
  • 軌道大小 \(\propto n^2\)：電子躍遷時注意比例尺；n = 7 的軌道是 n = 1 的 49 倍大，速率只有 1/7。
  • 放電管的門檻：把 K 降到 12.09 eV 以下，管子在肉眼看來變暗了，雖然仍放出來曼 α 紫外線；降到 10.2 eV 以下則完全不發光。
  • 冷氫氣對可見光透明：在「白光吸收」比較冷、熱兩種氫氣；巴耳末暗線只在熱氫氣出現，位置正是放電管明線的位置。

模擬方法

  • 能量使用考慮質子運動（約化質量）的氫原子芮得柏常數 \(R_{\mathrm{H}} = R_\infty/(1 + m_e/m_p) = 1.09678\times10^{7}\ \mathrm{m^{-1}}\)，所以 \(E_1 = -13.598\ \mathrm{eV}\)，算出的波長與實測值相差約 0.01 nm；常數取自 CODATA 2018。軌道半徑為電子與質子的距離 \(n^{2}a_0(1 + m_e/m_p)\)、速率為 \(\alpha c/n\)，0.05% 的修正在顯示的位數下看不出來。
  • 空氣中的波長用標準空氣的 Edlén（1966）公式換算，與 NIST 原子光譜資料庫相同。
  • 真實的譜線非常窄（室溫下寬度約 \(10^{-4}\) eV）。為了方便操作，本模擬只要光子能量與能階差相差在 ±0.005 eV 以內就算吻合。吸收時考慮到 n = 60 的能階；能階圖只標示 n = 1 到 7。
  • 躍遷機率採用 NIST 原子光譜資料庫（Wiese & Fuhr 2009）n ≤ 7 的愛因斯坦 \(A\) 係數（各次能階依統計權重平均）；本頁的測試以精確的氫原子波函數重新計算驗證。
  • 放電管（簡化模型）：能量足夠的撞擊都會激發原子；激發到哪一層的機率正比於振子強度 \(f_{1n}\)（高能電子的玻恩近似），n ≥ 8 的能階（振子強度合計不到 3%）省略。被激發的原子依 \(A\) 係數隨機串級掉回基態，每個光子都被計數。所以各譜線的相對強度取決於這個激發模型，但每一層往下掉的分支比是精確的。
  • 顏色：可見光的波長用 CIE 1931 配色函數（Wyman、Sloan 與 Shirley 2013 的解析近似）換成螢幕顏色；紫外線、紅外線看不見，以標明的假色表示。放電管的光色是各條可見光譜線依光子能量加權混合的顏色。
  • 波耳模型算出的氫原子能階是正確的，但電子並不是真的在圓形軌道上運動；量子力學以機率分布（電子雲）取代軌道。這裡畫的是波耳模型的圖像。
