背後的原理

      
程式追蹤：把自己當成電腦

      
「程式追蹤」就是用手執行程式：照電腦執行的順序一行一行走，每走一行就記下每個變數現在的值（追蹤表）。這是讀懂別人寫的程式最可靠的方法，也是 APCS「程式識讀」最主要的題型。本頁的畫布就是畫成盒子的追蹤表：每個變數是一個上面寫著名字的盒子，剛剛改變的盒子會閃一下。

      
指定不是等式。a = b; 的意思是：先算出右邊的值，再把它放進左邊的盒子，舊的值就不見了。所以 a = b; b = a; 換不了兩個值——兩個盒子最後都是原本的 b。這就是「交換兩個變數」要多一個盒子 t 的原因。


      
循序、選擇、重複

      
程式由三種控制結構組成：循序（一個敘述接一個）、選擇（if、else if、else：條件只算一次，只執行第一個成立的分支）與重複（while、for）。while 在每一圈之前先判斷條件，所以一開始條件就不成立時，本體一次也不會執行。for 有三段，執行順序是：

      
for (A; B; C) { S }      ≡      A;  while (B) { S  C }

A → B → S → C → B → S → C → … → B（false）

      
兩種寫法只有遇到 continue 時不一樣：在 for 裡，continue 跳過本體剩下的部分，但還是會做第三段 C；改成 while 的寫法時，C 也會被跳過。break 立刻離開迴圈，不做 C。執行到 for 那一行時，畫面會把正在做的那一段（A、B 或 C）標出來。


      
C 和 Python 的整數除法

      
在 C 裡，int 除以 int 還是 int：C99 起規定小數部分直接丟掉、向 0 取整，而 % 要讓 \(a = (a / b) \cdot b + a \,\%\, b\) 永遠成立——所以餘數的正負號跟著 \(a\)。Python 的 // 則是向下取整（往 \(-\infty\)），% 的正負號跟著 \(b\)。兩個數都是正的時候結果一樣；有負數時可能差一：

      
\[ q_{\mathrm{C}} = \operatorname{trunc}\!\left(\frac{a}{b}\right), \qquad q_{\mathrm{Python}} = \left\lfloor \frac{a}{b} \right\rfloor, \qquad r = a - q\,b \]

      
\[ \mathrm{C}:\ -7 / 2 = -3,\ \ -7 \,\%\, 2 = -1 \qquad\quad \mathrm{Python}:\ -7 \,/\!/\, 2 = -4,\ \ -7 \,\%\, 2 = 1 \]

      
本頁的 Python 寫法和 C 程式由同一棵語法樹轉出來，/ 寫成 //。頁面永遠照 C 的規則計算；只要某一步的除法有負數、而 Python 會算出不同的答案，那一行就標上 ⚠，按鈕下方的說明會同時寫出兩邊的結果。（想在 Python 得到 C 的答案，這種大小的整數可以寫 int(a / b)，餘數寫 a - b * int(a / b)。）


      
int 能放多大的數？

      
今天幾乎所有電腦上的 int 都是 32 位元，能放 \(-2^{31} = -2147483648\) 到 \(2^{31} - 1 = 2147483647\) 的整數。C 標準規定：有號整數的計算超出這個範圍，行為是未定義的——什麼事都可能發生，不同的編譯器真的會有不同的結果。多數機器會直接繞回去，但會最佳化的編譯器可以假設它永遠不會發生。Python 的整數則沒有大小限制。本頁遇到溢位就停在那一步並說明原因，不假裝繞回，所以 C 和 Python 兩種寫法不會在你不知道的情況下各算出不同的答案。除以 0、陣列索引超出範圍、讀取還沒給值的變數，也都會停下來說明。


      
優先順序與短路求值

      
沒有括號時，C 照下面的順序計算（上面的先算），同一層由左往右：

&&、|| 先算左邊。&& 的左邊是假、或 || 的左邊是真時，答案已經確定，右邊根本不算（短路）。這不只是比較快：在 i < n && a[i] != t 裡，i 走過頭時左邊就擋住了，a[i] 永遠不會被讀到。畫布上被跳過的右邊寫成「…」。Python 的 and、or 也一樣會短路。

計算方法

      
    
        
  • 程式由本頁自己寫的小直譯器執行（不用 eval、不用 new Function，也不送到任何地方）：掃描器把文字切成記號，遞迴下降剖析器建出語法樹，再一邊執行語法樹、一邊記下每一步。「上一步」只是顯示前一筆紀錄。Python 寫法也是從同一棵語法樹印出來的。
    • 
        
  • 一步的定義：一個宣告、指定、printf、break、continue、return 或函式呼叫；算一次條件（if、while 或 for 的中間那段）；或 for 的第一段、第三段。行號旁的小數字是那一行到目前為止執行了幾步。
    • 
        
  • 上限：10000 步（超過就停，說明可能是無窮迴圈）、輸出 2000 個字元、呼叫 40 層、陣列 64 格、程式 4000 個字元與 80 行。支援 int、bool、一維 int 陣列、if／else、while、for、break、continue、有 return 的函式，以及 printf 的 %d。
    • 
        
  • 單元測試：整數除法與餘數和 Math.trunc 比對 20000 組隨機數（並檢查 (a / b)·b + a % b = a）；3000 個全部加括號的隨機運算式和直接計算比對，包含短路避開除以 0 的情形；運算子優先順序；for 三段的執行順序，以及 continue、break；32 位元 int 的界限（12! 放得下、13! 溢位、(−2) 的 31 次方剛好是最小的 int）；區塊範圍、陣列與遞迴；轉成 Python 的寫法（range 或 while、括號、print）。開發時另外把每一支內建程式各用 40 組數字，放進真的 Python 3.11 執行，和本頁的結果比對。
    • 
        
  • 閃光、飄走的舊值和聲音只是為了好看好聽；每個數值都是直譯器在那一步算出來的。
