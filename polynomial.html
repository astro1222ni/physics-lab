背後的數學

根與圖形

若 \(f(x) = a(x - r_1)^{m_1}(x - r_2)^{m_2}\cdots\)，\(r_i\) 是 \(m_i\) 重根。在 \(r_i\) 附近圖形像 \(c\,(x - r_i)^{m_i}\)：\(m_i\) 是奇數時正負號改變，圖形穿過 x 軸；\(m_i\) 是偶數時正負號不變，圖形只碰到 x 軸。重數越高，根附近越平。

因式 \((x - p)^2 + q^2\)（\(q \ne 0\)）永遠是正的：次數多 2，卻不增加交點，它的根 \(p \pm qi\) 不是實數。\(|x|\) 很大時首項 \(ax^n\) 最重要，所以 \(n\) 是偶數時兩端同方向，奇數時兩端反方向。

多項式不等式

實根把數線切成幾段，每一段上 \(f(x)\) 的正負號不變。從最右邊開始（正負號和 \(a\) 相同）往左走：經過奇數重根就變號，經過偶數重根不變號。例如 \((x + 2)(x - 3)(x - 5)^2 < 0\) 的解剛好是 \(-2 < x < 3\)。

勘根定理與二分法

\[ f(l)\,f(r) < 0 \;\Rightarrow\; \exists\, c \in (l, r),\ f(c) = 0. \]

多項式的圖形是連續不斷的，從 x 軸下方走到上方，中間一定穿過 x 軸。反過來不成立：\(x^4 - 4x^2 + x + 1\) 在 0 和 2 都是正的，中間卻有兩個根。二分法算中點 \(m\) 的值，保留仍然變號的那一半；\(n\) 步以後寬度是 \((r - l)/2^n\)。

平移與伸縮

\(y = a\,f(b(x - h)) + k\)：\(b\) 讓圖形左右壓縮 \(|b|\) 倍（\(b < 0\) 時左右翻轉），\(h\) 往右平移，\(a\) 上下伸縮（\(a < 0\) 時上下翻轉），\(k\) 往上平移。\(x^3\) 和 \(x^3 - 3x\) 對原點對稱，所以新的圖形對點 \((h, k)\) 對稱。

\[ y = Ax^3 + Bx^2 + Cx + D = A(x - h)^3 + p(x - h) + k,\qquad h = -\frac{B}{3A},\ k = f(h). \]

每個三次函數都能這樣改寫，所以每個三次函數的圖形都是 \(y = Ax^3 + px\) 平移過去的，而且對點 \((h, f(h))\) 對稱。

觀察重點

  • 根的合併：把兩個單根拖在一起，兩個交點變成一個切點；再加一個，切點變成壓平的穿過。
  • 同號也可能有根：\(f(l)f(r) > 0\) 時勘根定理不能下結論——可能沒有根，也可能有偶數個。
  • 翻轉的巧合：\(y = x^3\) 用 \(b = -1\) 左右翻轉，和 \(a = -1\) 上下翻轉得到同一個圖形，因為 \((-x)^3 = -x^3\)。

計算方法

  • 根與圖形模式的曲線直接用因式求值；標準式由因式乘開得到。符號圖和解集合只用重數決定，所以是精確的；單元測試用幾百個點的 \(f\) 值核對。二分法用五個多項式的精確值；顯示的實根是把區間細分取樣、在每個變號處二分求得。
