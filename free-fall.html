自由落體與斜面上的運動

課本的必做實驗，在家也能做：先用碼錶與點痕數量出打點計時器相鄰兩點的時間，再讓滑車沿斜面下滑、讓重物自由落下。在紙帶上每隔 4 個點畫一條線，用直尺讀出各點的位置，按「記錄」填進數據表，就能畫出 x–t、v–t、a–t 圖，求出加速度與重力加速度 g。打開「含誤差」，看看量到的 g 為什麼常常比 9.8 小一點。

試試看：按「啟動打點計時器」，再按「放開滑車」，看紙帶上的點距愈來愈大。

    計時器的時距

    實驗說明

    實驗目的

    1. 利用物體運動時在紙帶上留下的點痕，判斷物體的運動狀態。
    2. 用 \(x\)–\(t\)、\(v\)–\(t\)、\(a\)–\(t\) 圖表示位置、速度、加速度與時間的關係，量出斜面上滑車的加速度與自由落體的加速度 \(g\)。

    實驗器材

    打點計時器、碼錶、紙帶一捲、重物、直尺、滑車與滑車軌道；另外需要墊高軌道一端（或把計時器垂直架起來）的支架，以及接住重物的軟墊。

    原理

    相鄰兩點的時間。打點計時器以固定的頻率 \(f\) 敲打紙帶，不論紙帶走得多快，相鄰兩點的時間都是 \(\Delta t = 1/f\)。拉動紙帶 \(T\) 秒打出 \(N\) 個點時，點和點之間只有 \(N - 1\) 個間隔：

    \[ \Delta t = \frac{T}{N - 1} \]

    點數會有大約一個間隔的不確定，碼錶也會有反應時間（約 0.1–0.2 s）的誤差，所以拉得愈久，求出的 \(\Delta t\) 愈準。

    由紙帶求速度。從第 0 點起每隔 \(n\) 個點畫一條線，相鄰兩條線的時間是 \(\tau = n\,\Delta t\)。每一段的位移除以 \(\tau\) 就是這一段的平均速度。等加速度時速度隨時間線性變化，所以平均速度恰好等於這一段中點時刻的瞬時速度：

    \[ \bar v_i = \frac{x_{i+1} - x_i}{\tau} = \frac{v(t_i) + v(t_{i+1})}{2} = v\!\left(t_i + \tfrac{\tau}{2}\right) \] \[ \bar a_i = \frac{\bar v_{i+1} - \bar v_i}{\tau} \]

    於是 \(v\)–\(t\) 圖上的點排成一直線，斜率就是加速度，截距是第 0 點的速度（第 0 點不是放手的瞬間，所以截距不為零）。換個說法：相鄰兩段的位移每次都增加同樣多，\(\Delta x_{i+1} - \Delta x_i = a\tau^{2}\)。

    斜面與自由落體。在傾角 \(\theta\) 的光滑斜面上（軌道長 \(L\)、兩端高度差 \(h\)），只有重力沿斜面的分量使滑車加速。軌道的摩擦（\(\mu\)）與紙帶穿過計時器的摩擦（\(f\)）會使它變慢；自由落體就是 \(\theta = 90^\circ\) 的特例：

    \[ \sin\theta = \frac{h}{L} \] \[ a = g\sin\theta - \mu g\cos\theta - \frac{f}{M} \] \[ \theta = 90^\circ:\ \ a = g - \frac{f}{m} \]

    伽利略用斜面「沖淡」重力，讓運動慢到可以計時。沒有摩擦時，不論角度多大，\(a/\sin\theta = g\)，所以 \(a\)–\(\sin\theta\) 圖是通過原點、斜率為 \(g\) 的直線，一直延伸到自由落體（\(\sin\theta = 1\)）。摩擦使直線往下平移，斜率卻幾乎不變。空氣阻力 \(F = kv^{2}\) 隨速率變大，有空氣阻力時加速度不再固定：\(a = g - \tfrac{f}{m} - \tfrac{k}{m}v^{2}\)，\(a\)–\(t\) 圖會往下斜。

    實驗步驟

    ① 計時器相鄰點痕的時間。把紙帶穿過計時器。啟動計時器、開始拉紙帶並同時按下碼錶，拉一段時間後一起停止。讀出時間 \(T\)、數出點數 \(N\)，記錄並算出 \(\Delta t = T/(N-1)\)；多做幾次取平均。

    ② 斜面上的運動。把軌道一端墊高，計時器固定在斜面頂端，紙帶（約 1 m）一端夾在滑車尾部，其餘部分放平順。先啟動計時器，再放開滑車。在紙帶上選一個清楚的點當第 0 點，每隔 4 個點畫一條線。以第 0 點為 \(t = 0\)、\(x = 0\)，記錄第 0、4、8……點的 \(t\) 與 \(x\)，畫 \(x\)–\(t\) 圖；各段位移除以時間得到平均速度（畫在中點時刻），畫 \(v\)–\(t\) 圖；再由相鄰平均速度的變化得到平均加速度，畫 \(a\)–\(t\) 圖。

    ③ 自由落體。把計時器垂直夾在支架上，紙帶下端接上重物，下方放軟墊。啟動計時器後放開重物，用和 ② 相同的方法分析紙帶。

    注意事項

    • 先啟動計時器再放手，放手時不要推。放手前打的點都會疊在同一個位置。
    • 紙帶要平直穿過計時器的導槽，不可扭轉，減少不必要的摩擦；重物重一點，摩擦的影響就小一點。
    • 直尺沿著紙帶放，0 刻度對準第 0 點；讀數時視線要垂直尺面（避免視差），估計到最小刻度的下一位（毫米尺估讀到 0.1 mm）。
    • 滑車撞到擋板、重物落地之後打的點會疊在一起，不可列入分析。
    • 滑車撞上擋板前最好用手擋住；重物落下的路徑上不可有手。

    問題與討論

    1. 相鄰兩點的時間為什麼是 \(T/(N-1)\) 而不是 \(T/N\)？用 60 Hz 的計時器只拉 1 s，誤差可能有多大？
    2. 每段的平均速度畫在這段時間的中點。為什麼等加速度時這樣做完全準確？空氣阻力很大時還準確嗎？
    3. \(v\)–\(t\) 圖的直線不通過原點，截距代表什麼？你能推算出物體是在第 0 點之前多久放開的嗎？
    4. 實際量到的 \(g\) 通常小於 \(9.8\ \mathrm{m/s^2}\)。原因有哪些？各要怎麼減少？
    5. 如果計時器實際的頻率比標示值快 1%，你卻用標示的 \(\Delta t\) 計算，量到的 \(g\) 偏差幾 %？偏大還是偏小？
    6. 用幾個不同的高度差畫 \(a\)–\(\sin\theta\) 圖。斜率代表什麼？有摩擦的軌道上，截距為什麼是負的？

    觀察重點

    • 時間相等、間距變大：用慢動作、打開音效，打點的「嗒嗒」聲節奏固定，紙帶上的點間距卻愈來愈大。
    • 位移差固定：理想條件下，表格中每個 \(\bar a\) 都相同，相鄰兩段的 \(\Delta x\) 恰好相差 \(a\tau^{2}\)。
    • 重物重一點比較準：打開含誤差，分別讓 0.05 kg 與 1 kg 的重物落下。紙帶摩擦 \(f\) 造成的減速是 \(f/m\)，輕的重物受影響大得多。
    • 伽利略的斜面：用幾個不同的高度差各做一次，再做一次自由落體。理想條件下，\(a\)–\(\sin\theta\) 圖的所有點都在一條通過原點、斜率為 \(g\) 的直線上。
    • 空氣阻力：讓 0.05 kg 的重物在 \(k = 20\ \mathrm{g/m}\) 時落下，\(a\)–\(t\) 圖變成往下斜，\(x\)–\(t\) 圖的點也偏離拋物線。
    • 頻率未知的計時器：選「未知」，先在 ① 量出 \(\Delta t\)，再用它分析自由落體。校正的誤差會以兩倍放大到 \(g\) 上，因為 \(g \propto 1/\Delta t^{2}\)。

    模擬方法

    • 運動由精確的公式計算。沒有空氣阻力時 \(x = \tfrac12 a t^{2}\)；有空氣阻力 \(F = kv^{2}\) 時，\(a = a_0 - \tfrac{k}{m}v^{2}\) 有精確解 \(v = v_T \tanh(t\sqrt{a_0 k/m})\)、\(x = \tfrac{m}{k}\ln\cosh(t\sqrt{a_0 k/m})\)，終端速度 \(v_T = \sqrt{a_0 m/k}\)，\(a_0\) 是沒有空氣阻力時的加速度。沒有數值誤差。
    • 計時器從啟動起每 1/f 秒打一點；放手前、撞到擋板或落地後打的點都疊在同一處。只有沿運動方向的重力分量大於摩擦力時，滑車或重物才會由靜止開始運動（靜摩擦與滾動摩擦取相同的係數）。紙帶質量不計、軌道是直的，g = 9.8 m/s²。
    • 含誤差時：每個尺的讀數加上隨機誤差（標準差 0.3 mm）並取到 0.1 mm；誤差跟著那一點，重讀同一點會得到同一個值。每次按碼錶都會隨機慢 0.10–0.30 s。紙帶摩擦 f 取固定的平均力（計時器一下一下的敲擊平均起來）。理想時讀數完全準確（表格顯示的是取捨後的數字，計算用的是精確值）。
    • 「未知」計時器是電鈴式計時器，每次選它時隨機取 22 到 38 Hz 之間的一個頻率。① 用手拉紙帶的速度忽快忽慢，所以點的間距不均勻——重要的只是點的數目。
    • 裝置圖依比例繪製，用斜投影畫出立體感：沿運動方向的位置完全依比例，深度只是為了看出物體的形狀。計時器放大圖是示意圖，未依比例。
