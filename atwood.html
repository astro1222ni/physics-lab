背後的物理

牛頓第二定律的兩種用法

物體用拉緊的繩子連在一起或互相推擠時，會以相同大小的加速度 \(a\) 一起運動。有兩種等價的算法：

  • 系統觀點：把所有物體當成一個整體，沿運動方向來看。內力（物體之間的繩子張力、木塊之間的接觸力）成對抵消，只剩外力：\[ a = \frac{F_{\text{外力合力}}}{m_{\text{總}}} \]
  • 個別物體：替每個物體畫受力圖，各自寫出 \(\Sigma F = ma\)。張力 \(T\) 這類內力要用這個方法求。

阿特午機

兩個物體跨過輕而無摩擦的滑輪。以「\(m_1\) 往下」為正方向，系統觀點立刻得到 \(a\)，再由任一個物體求出 \(T\)：

\[ a = \frac{(m_1 - m_2)\,g}{m_1 + m_2}, \qquad m_1 g - T = m_1 a \;\Rightarrow\; T = \frac{2 m_1 m_2\, g}{m_1 + m_2} \]

張力永遠介於 \(m_2 g\) 與 \(m_1 g\) 之間。\(m_2 \to 0\) 時 \(a \to g\)（自由落體）；\(m_1 = m_2\) 時 \(a = 0\)，推一下就會等速度運動（牛頓第一定律）。阿特午（1784 年）就是用這種「稀釋的重力」讓落下變慢，才能用手計時。從靜止落下高度 \(h\) 花了時間 \(t\)：

\[ h = \tfrac12 a t^{2} \;\Rightarrow\; a = \frac{2h}{t^{2}}, \qquad g = a\,\frac{m_1 + m_2}{m_1 - m_2} \]

把 10 g 的砝碼從一邊搬到另一邊，\(\Delta m = m_1 - m_2\) 改變而 \(m_1 + m_2\) 不變，所以 \(a\) 與 \(\Delta m\) 成正比：一條通過原點、斜率 \(g/(m_1 + m_2)\) 的直線。

靜摩擦力決定動不動

桌上的木塊 \(M\) 被懸掛物 \(m\) 拉動時，先比較拉力與最大靜摩擦力：若 \(mg \le \mu_s Mg\)，兩者都不動，靜摩擦力恰為 \(mg\)（不是 \(\mu_s Mg\)）。否則：

\[ a = \frac{(m - \mu_k M)\,g}{M + m}, \qquad T = m(g - a) = \frac{Mm\,g\,(1 + \mu_k)}{M + m} \]

在傾角 \(\theta\) 的斜面上，木塊重力沿斜面的分量是 \(Mg\sin\theta\)，正向力是 \(Mg\cos\theta\)，共有三種情況：

\[ \begin{aligned} m > M(\sin\theta + \mu_s\cos\theta) &:\quad a = \frac{m - M(\sin\theta + \mu_k\cos\theta)}{M + m}\,g \ \ \text{（上滑）} \\ m < M(\sin\theta - \mu_s\cos\theta) &:\quad a = \frac{M(\sin\theta - \mu_k\cos\theta) - m}{M + m}\,g \ \ \text{（下滑）} \\ \text{其他} &:\quad a = 0,\ \ f_s = |mg - Mg\sin\theta| \end{aligned} \]

靜摩擦力的方向「看需要」，甚至可以是零（\(m = M\sin\theta\) 時）。動摩擦力永遠與速度相反；往上衝的木塊停下來時，要重新判斷靜摩擦力撐不撐得住，才知道會不會滑回來。

推、拉一列木塊

以外力 \(F\) 推或拉、每塊木塊的 \(\mu_k\) 相同時，加速度都是 \(a = (F - \mu_k\,\Sigma m\,g)/\Sigma m\)。相鄰兩塊之間的力只需要帶動「另一側」的木塊，所以

\[ \text{拉：}\ \ T_{12} = \frac{m_1}{m_1 + m_2 + m_3}\,F,\quad T_{23} = \frac{m_1 + m_2}{m_1 + m_2 + m_3}\,F; \qquad \text{推：}\ \ P_{12} = \frac{m_2 + m_3}{m_1 + m_2 + m_3}\,F,\quad P_{23} = \frac{m_3}{m_1 + m_2 + m_3}\,F \]

越靠近拉力的那條繩子張力越大，而且這些力竟然與 \(\mu_k\) 無關。接觸力遵守牛頓第三定律：木塊 1 以 \(P\) 往前推木塊 2，木塊 2 也以同樣大小的 \(P\) 往後推木塊 1；這兩個力作用在不同物體上，所以不會在同一張受力圖裡互相抵消。

落地之後

\(m_1\) 落地時繩子鬆掉（\(T = 0\)），\(m_2\) 因慣性像鉛直上拋一樣繼續上升 \(v^{2}/2g\)；落回來時繩子突然拉緊，沿繩方向就像一次完全非彈性碰撞：\(m_A v_A + m_B v_B = (m_A + m_B)\,v'\)，之後還會彈跳幾次、越來越輕。

觀察重點

  • 稀釋的重力：\(m_1 = 0.60\ \mathrm{kg}\)、\(m_2 = 0.40\ \mathrm{kg}\) 時 \(a = g/5 = 1.96\ \mathrm{m/s^2}\)。比較「系統觀點」與兩張受力圖：\(m_1 g - T\) 與 \(T - m_2 g\) 都等於各自的 \(ma\)。
  • Δm 實驗：一直按「\(m_2 \to m_1\)」，每次都用光電計時器量一次。量到的 \(a\) 等量增加，而表格每一列推算出的 \(g\) 都一樣。
  • 用手計時：改用手按碼錶，在 \(m_1\) 落地的瞬間按「停錶」。\(\Delta m\) 大時反應時間讓誤差很大；\(\Delta m\) 小時要落好幾秒，推算的 \(g\) 準得多——這正是阿特午要讓運動變慢的原因。
  • 找臨界值：桌上 \(M = 1\ \mathrm{kg}\)、\(\mu_s = 0.40\)，\(m = 0.40\ \mathrm{kg}\) 時木塊不動（靜摩擦力恰為 \(mg\)），\(m = 0.41\ \mathrm{kg}\) 時開始動，摩擦力立刻變成 \(\mu_k Mg\)。
  • 哪一條繩子比較緊？拉三塊木塊：靠近手的繩子張力一定比較大。改變 \(\mu_k\)：加速度改變，張力卻不變。
  • 第三定律力對：推動木塊，看接觸處的綠色箭頭——等長、反向、作用在不同的木塊上。木塊受到的正向力與木塊壓桌面的力是另一對（空心箭頭）。
  • 上去、停下、回來：35° 斜面、懸掛物很輕，給木塊沿斜面向上的初速。它減速、停下，再滑回來——在折返點摩擦力換了方向。

模擬方法

  • 繩子輕而不可伸長、滑輪輕而無摩擦，\(g = 9.8\ \mathrm{m/s^2}\)。運動分成好幾段等加速度運動，每一段都用解析解精確計算（沒有逐步累積的數值誤差）。每一段在某個事件結束——停下、落地、撞到擋板、繩子鬆掉或突然拉緊——再重新判斷受力，包括靜摩擦力撐不撐得住。
  • 地板與擋板是完全非彈性的；鬆掉的繩子突然拉緊，沿繩方向也是完全非彈性。繩子拉緊後速度小於 2 mm/s，或第一次撞擊後超過 10 s，就停止模擬（剩下的運動太小或太久）。
  • 靜止時若有幾個面可以分擔受力（靜止的一列木塊，或靠在擋板上的木塊），靜摩擦力如何分配無法只由牛頓定律決定。本模擬假設外力是慢慢加上的：直接受力的木塊先用掉自己的靜摩擦力，剩下的才傳下去。
  • 推拉連體實驗中，前方木塊通過終點線時計時停止、畫面凍結，之後的運動不模擬。
  • 光電計時器讀到 0.001 s；手按碼錶由你親手停錶，包含你真實的反應時間（用過慢動作或暫停的那一次會在表格中標示，不算公平的手按量測）。
  • 物體的大小只是隨質量變大以便分辨，不影響運動。
