電流的磁效應：直導線、線圈與螺線管的磁場

1820 年，厄斯特發現導線通電時，下方的磁針會偏轉。在這裡重做他的實驗：把導線南北向放在磁針上方或下方，改變電流的大小、方向與導線位置，先用安培右手定則預測磁針往哪邊偏。記下偏角 θ，用 tan θ = BI/BH（BI 是導線的磁場）量出你所在地的地磁水平分量。接著用探測點逐點量長直導線、圓線圈與螺線管的磁場，切換到 3D 看立體的磁力線。

試試看：把電流 I 慢慢調到 3 A，看磁針往哪邊偏；再按「反向」和「磁針下方」比比看。

拖曳旋轉，滾輪或雙指縮放，右鍵或雙指拖曳平移。長度依實際尺寸（公分）繪製；磁力線、小磁針與鐵粉都由與 2D 相同的畢歐–沙伐磁場計算而來。

數據表與分析

實驗目的

  1. 觀察電流會產生磁場（厄斯特，1820 年），並用安培右手定則判斷磁場方向。
  2. 用磁針與長直導線量出地磁的水平分量（正切法）。
  3. 找出長直導線、圓線圈與螺線管的磁場如何隨電流與位置改變。

原理

1. 厄斯特的發現與安培右手定則

載流導線周圍有磁場，磁力線是以導線為中心的同心圓。用右手握住導線、拇指指向電流，四指彎曲的方向就是 \(\vec B\) 的方向。磁針的 N 極指向它所在處的「水平合磁場」。電流向北時，導線正下方的磁場向西，正上方的磁場向東。

2. 畢歐–沙伐定律

每一小段電流 \(I\,\Delta\vec\ell\) 在距離 \(r\) 處產生的磁場是

\[ \Delta B = \frac{\mu_0}{4\pi}\,\frac{I\,\Delta\ell\,\sin\theta}{r^2} \]

\(\theta\) 是 \(\Delta\vec\ell\) 與 \(\vec r\) 的夾角。把所有小段加起來，得到下面三個結果。

3. 長直導線、圓線圈、螺線管

長直導線\[ B = \frac{\mu_0 I}{2\pi r} \]
圓線圈中心\[ B = \frac{\mu_0 N I}{2R} \]
長螺線管內部\[ B = \mu_0 n I \]

圓線圈軸上、距中心 \(x\) 處：\(B = \dfrac{\mu_0 N I R^2}{2(R^2+x^2)^{3/2}}\)。長 \(L\)、每公尺 \(n = N/L\) 匝的螺線管，軸上 \(B = \tfrac12\mu_0 n I(\cos\alpha_1 - \cos\alpha_2)\)，\(\alpha_1, \alpha_2\) 是從該點看兩端的角度；細長螺線管的內部接近 \(\mu_0 n I\)，管口大約只剩一半。

4. 正切法

導線南北向、放在磁針正上方（或正下方），距離 \(r\)。導線在磁針處的磁場 \(B_I = \mu_0 I/(2\pi r)\) 是水平的、指向東或西，正好與地磁水平分量 \(B_H\) 垂直。磁針沿兩者的合磁場，偏轉角 \(\theta\) 滿足

\[ \tan\theta = \frac{B_I}{B_H} \] \[ \Longrightarrow\quad B_I = B_H\tan\theta \]

以 \(B_I\)（由 \(I\)、\(r\) 算出）對 \(\tan\theta\) 作圖，應是一條通過原點的直線，斜率就是 \(B_H\)。偏角 45° 時，導線的磁場剛好等於 \(B_H\)。

步驟（正切法）

  1. 不通電，等磁針靜止。轉動刻度盤讓指針對準 0°，再把導線沿著磁針（南北向）放在它的正上方。
  2. 量出導線到磁針的鉛直距離 r。
  3. 通電並調好電流 I，等磁針停穩後讀出偏角 θ，按「記錄」。把電流反向，讀另一邊的偏角，再記錄一次。
  4. 換幾個不同的電流（偏角最好在 30°～60° 之間），以及兩、三個不同的 r，重複上面的步驟。
  5. 以 \(B_I\) 對 \(\tan\theta\) 作圖，由斜率求出 \(B_H\)。

注意事項

  • 導線一定要沿著磁針靜止時的方向（磁北，不是地理北），而且在轉軸的正上方或正下方，否則 tan θ = BI/BH 不成立。
  • 鐵器、磁鐵、手機與電源的導線都要遠離羅盤；通往導線的兩條引線要並在一起，讓它們的磁場互相抵消。
  • 磁針停穩後再讀偏角，視線垂直刻度盤以免視差。
  • 偏角太小不容易讀準，接近 90° 時 tan θ 變化太快：45° 附近求出的 BH 最可靠。
  • 大電流不要開太久，導線會發熱。

觀察重點

  • 把導線從磁針上方移到下方，磁針改往另一邊偏；電流反向，又再反過來。
  • 把導線轉成東西向：磁針在正下方時，導線的磁場與地磁同一直線，磁針完全不偏——除非電流大到讓合磁場反向。
  • 把羅盤往旁邊移：磁針離導線變遠，磁場本身變弱；而且有一部分磁場變成鉛直方向，水平放的磁針感覺不到。兩者都讓偏角變小：水平分量是 \(B_h = \dfrac{\mu_0 I\,r}{2\pi(r^2 + d^2)}\)，\(r\) 是鉛直距離、\(d\) 是側移。
  • 合磁場越強，磁針擺得越快（週期與 1/√B 成正比）。
  • 直導線：距離加倍，\(B\) 減半。圓線圈：沿軸移到 \(x = R\)，\(B\) 只剩中心的 \(1/(2\sqrt2)\)。螺線管：比較中央、管口與管外。
  • 把螺線管做得又細又長：管內越來越接近均勻的 μ0nI，管外的磁場幾乎消失。

問題與討論

  1. 厄斯特實驗中，導線為什麼要南北向放置，而不是東西向？
    參考答案

    導線在磁針處的磁場與導線垂直。南北向的導線產生東西向的磁場，與地磁垂直，所以磁針偏轉；東西向的導線產生的磁場沿著磁針，只是加強（或減弱）地磁，磁針不會轉。

  2. \(r = 2.0\ \mathrm{cm}\) 時，3.6 A 的電流使磁針偏 45°。估計 \(B_H\)。
    參考答案

    \(B_H = B_I/\tan 45^\circ = \mu_0 I/(2\pi r) = (2.0\times10^{-7})(3.6)/0.020 \approx 3.6\times10^{-5}\ \mathrm{T}\)，約 36 μT。

  3. 為什麼要把電流反向、取兩邊偏角的平均？
    參考答案

    如果刻度盤的零點有一點偏，一邊的讀數都多了同樣的角度，另一邊都少了同樣的角度。兩邊平均就把零點誤差（以及導線些微沒對準）消掉了。

  4. 50 匝、半徑 5.0 cm 的圓線圈通 2.0 A，求中心與軸上距中心 5.0 cm 處的磁場。
    參考答案

    中心：\(\mu_0 NI/(2R) = (1.2566\times10^{-6})(50)(2.0)/0.10 \approx 1.26\ \mathrm{mT}\)。在 \(x = R\) 處為中心的 \(1/(2\sqrt2) \approx 0.354\) 倍，約 0.44 mT。

  5. 為什麼長螺線管管口的磁場大約只有中央的一半？
    參考答案

    把兩個一樣的長螺線管頭尾相接：接口處是完整的 \(\mu_0 nI\)，由對稱性兩邊各貢獻一半，只有一個時就是一半。（由公式：管口處 \(\cos\alpha_1 \approx 1\)、\(\cos\alpha_2 = 0\)。）

模擬方法

  • 常數：\(\mu_0 = 1.256\,637\,061\,27\times10^{-6}\ \mathrm{N/A^2}\)（CODATA 2022）。2019 年國際單位制改版後，\(\mu_0\) 變成量測值，比 \(4\pi\times10^{-7}\) 小約 \(10^{10}\) 分之 1.3，在這裡完全看不出差別，所以手算時用 \(\mu_0/2\pi \approx 2.0\times10^{-7}\ \mathrm{T\,m/A}\) 就可以。
  • 地磁：World Magnetic Model WMM2025（美國 NOAA NCEI 與英國地質調查所）算出的 2026 年 11 月海平面數值。水平分量：臺北 36.18 μT、臺中 36.60 μT、員林 36.68 μT、高雄 37.20 μT、花蓮 36.59 μT；磁偏角約偏西 4.4°～5.1°。實際教室裡的鋼筋、電纜可能讓數值相差百分之幾。
  • 厄斯特實驗與正切法：導線視為無限長直導線，\(\vec B = \mu_0 I/(2\pi\rho^2)\,\hat u\times\vec\rho\)；磁針只感受水平分量。磁針的轉動 \(\ddot\varphi = (m/J)(B_x\cos\varphi - B_y\sin\varphi) - (c/J)\dot\varphi\)，用四階 Runge–Kutta 法、步長不超過 1/600 s 積分（不加阻尼時，每分鐘能量漂移不到 \(10^9\) 分之 1）。在臺北的地磁下，磁針擺動週期 1.6 s。
  • 「理想」儀器：電流表準確、刻度盤已歸零、轉軸沒有摩擦。「含誤差」：電流表最多 ±0.4% 校正誤差；刻度盤零點偏 1°～2°（轉動刻度盤可以修正）；轉軸有摩擦，只有地磁時磁針可能停在離真正方向 ±0.15° 內（磁場越強越小）。每次打開頁面誤差都不同。
  • 圓線圈：每一匝是精確的圓電流（完全橢圓積分 \(K\)、\(E\)），並與 20000 邊的多邊形用畢歐–沙伐定律相加的結果比對。螺線管：繞線視為面電流，磁場用 Derby 與 Olbert（Am. J. Phys. 78, 229, 2010）的閉合解（Bulirsch 廣義完全橢圓積分），並與數千個圓線圈相加及安培定律比對。
  • 磁力線沿磁場方向用四階 Runge–Kutta 法描出。2D 剖面中，起點排在中央平面上，相鄰兩線之間的 ∫B dy 相等，所以那裡的疏密代表磁場強弱（離開中央平面後只是近似；強度色階以對數刻度精確表示 |B|）。直導線周圍的同心圓間距使疏密與 1/r 成正比。磁力線的條數與電流成正比。
  • 3D 檢視使用 three.js 函式庫（MIT 授權），只有切換到 3D 時才下載。圓線圈與螺線管的每條立體磁力線都從中央圓盤出發、帶著相同的磁通量（向日葵排列），所以空間中的疏密與 B 成正比。小磁針沿當地磁場方向；鐵粉沿磁場排列，磁場越強放得越密（示意，不是模擬鐵粉互相吸引聚集的過程）。
  • 音效（預設關閉）：記錄時「喀」一聲，磁針停穩時有輕柔的提示音。
