背後的數學

複數是平面上的點

複數 \(z = a + bi\) 對應平面上的點 \((a, b)\)：實部在橫軸、虛部在縱軸。它到 0 的距離是絕對值 \(|z| = \sqrt{a^2 + b^2}\)，從正實軸轉到它的角度是幅角 \(\arg z = \theta\)。所以 \(z = r(\cos\theta + i\sin\theta)\)，其中 \(r = |z|\)。

加法是平移，乘法是旋轉

\[ z + w:\ \text{parallelogram},\qquad |zw| = |z|\,|w|,\qquad \arg(zw) = \arg z + \arg w \]

加上 \(w\) 是讓每一點都沿著同一個箭頭移動：\(0, z, z + w, w\) 圍成平行四邊形。乘以 \(z\) 就不同了：每一點都繞 0 轉過 \(\arg z\)，到 0 的距離變成 \(|z|\) 倍。所以三角形 \((0, 1, z)\) 和三角形 \((0, w, zw)\) 相似；\(i\) 的絕對值是 1、幅角 90°，乘以 \(i\) 就是把整個平面轉一個直角，\(i^2 = -1\)。

棣美弗定理

\[ \bigl[r(\cos\theta + i\sin\theta)\bigr]^n = r^n(\cos n\theta + i\sin n\theta) \]

一直乘以 \(z\)，每次都加上同一個角度、距離乘上同一個倍數，所以 \(1, z, z^2, \dots\) 排在一條螺線上。\(|z| < 1\) 時螺線往內捲，\(|z| > 1\) 時往外，\(|z| = 1\) 時點沿著單位圓走。

n 次方根

\[ w^n = z \quad\Longleftrightarrow\quad w_k = \sqrt[n]{|z|}\Bigl(\cos\frac{\theta + 360^\circ k}{n} + i\sin\frac{\theta + 360^\circ k}{n}\Bigr),\quad k = 0, 1, \dots, n-1 \]

每一個不是 0 的 \(z\) 都恰好有 \(n\) 個不同的 \(n\) 次方根。它們的絕對值都一樣，幅角相差 \(360^\circ/n\)，所以是以 0 為中心的正 \(n\) 邊形的頂點，加起來是 0。

觀察重點

  • 相似三角形：在「乘法」裡把 \(w\) 拖到任何地方，塗色的三角形 \((0, w, zw)\) 永遠和 \((0, 1, z)\) 一樣形狀。
  • 共軛：\(z\) 乘以它的共軛 \(\bar z\)，先轉過去再轉回來，剩下實數 \(|z|^2\)。
  • 回到原點：\(|z| = 1\)、\(\theta = 360^\circ/n\) 時，\(z\) 的次方剛好走 \(n\) 步回到 1。

計算方法

  • 次方用一次一次的乘法算，和畫面上一步一步畫的一樣。方根用上面的極式公式。「播放」乘法時，\(t\) 從 0 走到 1，畫面轉過 \(t\arg z\)、伸縮 \(|z|^t\) 倍，所以每一點都沿著一小段對數螺線移動。
