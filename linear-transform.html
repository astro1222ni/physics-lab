矩陣與線性變換

矩陣是一次搬動整個平面的方法：它的兩行說出兩個基底箭頭被搬到哪裡，每一格方格都跟著走。看行列式就是面積（在空間裡是體積）放大的倍數，再找出只被拉長、方向不變的特別方向——特徵向量。

試試看：把綠色 j 箭頭的尖端拖到紅色 i 箭頭的另一側，看小旗子在行列式變成負數的那一刻翻成鏡子裡的樣子。

i ↦ 第 1 行 j ↦ 第 2 行 k ↦ 第 3 行 單位正方形（立方體）的像 小旗子（看翻面） 探針 x、它的像 Ax 特徵向量方向

背後的數學

矩陣一次搬動所有的點

乘上 \(A = \begin{bmatrix} a & b \\ c & d \end{bmatrix}\) 把 \((x, y)\) 送到 \((ax + by,\; cx + dy)\)。因為 \((x, y) = x\,\mathbf i + y\,\mathbf j\)，而且這個變換是線性的：\(A(x\mathbf i + y\mathbf j) = x\,A\mathbf i + y\,A\mathbf j\)。只要知道 \(\mathbf i\)、\(\mathbf j\) 被搬到哪裡（也就是 A 的兩行），就知道每一個點被搬到哪裡。直線還是直線、平行線還是平行、等距的格線還是等距，原點永遠不動。

行列式是面積的倍率

單位正方形變成由兩行 \((a, c)\)、\((b, d)\) 張成的平行四邊形，它的有號面積是

\[ \det A = ad - bc. \]

每一格方格都變成同樣的平行四邊形，所以任何圖形（小旗子、圓、什麼都可以）面積都乘上 \(|\det A|\)。\(\det A < 0\) 時整張紙被翻面，像照鏡子；\(\det A = 0\) 時整個平面被壓到一條線（或一點）上，再也還原不了。兩個矩陣相乘時 \(\det(AB) = \det A \cdot \det B\)。在空間裡，\(3 \times 3\) 矩陣把單位立方體變成由三行張成的平行六面體，\(\det A\) 就是它的有號體積。

特徵向量：方向不變的向量

大部分的向量被 \(A\) 轉了方向。若非零向量 \(\mathbf x\) 滿足 \(A\mathbf x = \lambda\mathbf x\)，它只被拉長（倍數 \(\lambda\)，負的就反向），叫做特徵向量，\(\lambda\) 是特徵值。特徵值是下面方程式的根：

\[ \lambda^2 - (\operatorname{tr} A)\,\lambda + \det A = 0, \qquad \operatorname{tr} A = a + d. \]

所以 \(\lambda_1 + \lambda_2 = \operatorname{tr} A\)、\(\lambda_1 \lambda_2 = \det A\)。若 \((\operatorname{tr} A)^2 - 4\det A < 0\)，沒有實數特徵值，每個方向都被轉走（旋轉就是這樣）。剪切有重根 1，但只有一個特徵向量的方向。

觀察重點

  • 翻面：把 j 拖過 i 所在的直線；兩者共線的那一刻平行四邊形面積是 0（\(\det A = 0\)），再過去小旗子就變成鏡像。
  • 圓變橢圓：單位圓變成半軸 \(\sigma_1 \ge \sigma_2\)（奇異值）的橢圓，\(\sigma_1\sigma_2 = |\det A|\)。
  • 對稱矩陣（\(b = c\)）一定有兩個實數特徵值，兩個特徵向量互相垂直，剛好沿著橢圓的軸。

計算方法

  • 特徵值由上面的二次方程式求出；判別式和 0 相差 \(10^{-9}\) 以內算重根，所以打字到小數兩位的矩陣會得到正確的判斷。\(3 \times 3\) 矩陣的秩用部分選主元的高斯消去法求。單元測試檢查行列式等於變形後正方形與小旗子的鞋帶公式面積、等於變形後立方體的體積、\(A\mathbf v = \lambda\mathbf v\)，並用細密掃過單位圓的方式核對奇異值。
