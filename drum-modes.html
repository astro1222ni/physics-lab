鼓與板的振動模態

為什麼小鼓、大鼓沒有明確的音高，定音鼓卻可以調音、和樂團一起演奏？鼓面同時用很多種形狀振動，每一種有自己的頻率，而且彼此不是整數倍。敲在鼓面不同的地方、看每個模態的形狀和永遠不動的節線，比一比理想的圓膜、定音鼓和方形金屬板。

試試看：按「▶ 敲一下」，再把「離中心 r/a」設成 0 再敲，看頻譜少了哪些長條。

戴耳機的同學先把音量調小：小而緊的鼓、方板的高次模態可能很尖。聲音是把各個模態加起來合成的近似。

往上 往下 節線（單一模態） 敲擊點 整數倍的位置

長條高度：敲一下後各模態振動的幅度（\(\propto\) 模態在敲擊點的值 ÷ 頻率）。外框是「在目前的敲擊點敲下去」會得到的大小；敲過之後實心部分逐漸衰減，高次模態先消失。底下的小空心記號是完全沒被敲出來的模態。橫軸是頻率 ÷ 參考基音 \(f_\mathrm{ref}\)：如果是整數倍的泛音，每根長條都會剛好落在虛線上。

背後的科學

圓形鼓膜的模態

鼓皮是一張被張力 \(T\)（鼓邊每公尺的拉力）張緊、每平方公尺質量 \(\sigma\) 的薄膜。鼓面上的小起伏以 \(c = \sqrt{T/\sigma}\) 傳開，鼓面的高度 \(w\) 遵守二維波動方程式 \(\partial^2 w/\partial t^2 = c^2 \nabla^2 w\)，而鼓框讓邊緣固定不動：\(w(a) = 0\)。能夠自己一直振動下去的形狀叫做模態：

\[ w_{m,n}(r,\theta,t) = J_m\!\left(j_{m,n}\frac{r}{a}\right)\cos m\theta\,\cos 2\pi f_{m,n}t, \qquad f_{m,n} = \frac{j_{m,n}}{2\pi a}\sqrt{\frac{T}{\sigma}}, \qquad J_m(j_{m,n}) = 0 \]

\(J_m\) 是 \(m\) 階的貝索函數；因為鼓邊 \(r = a\) 一定要是零點，所以用到它的第 \(n\) 個零點 \(j_{m,n}\)。模態 \((m, n)\) 有 \(m\) 條直徑節線與 \(n\) 個節圓（包含鼓邊），這些線永遠不動。前幾個零點是 \(j_{0,1} = 2.405\)、\(j_{1,1} = 3.832\)、\(j_{2,1} = 5.136\)、\(j_{0,2} = 5.520\)、\(j_{3,1} = 6.380\)、\(j_{1,2} = 7.016\)，頻率比是 1 : 1.593 : 2.136 : 2.295 : 2.653 : 2.917……，不像弦那樣是 1 : 2 : 3 : 4。所以一般的鼓聽起來是「咚」一聲，沒有明確的音名。這一頁自己算出貝索函數與零點，並和數學手冊的表對照。

敲哪裡決定哪些模態會響

在 \((r_s, \theta_s)\) 快速敲一下，每個模態得到的速度和「模態在敲擊點的值」成正比，接著以「速度 ÷ \(2\pi f\)」的幅度振動：

\[ w(r,\theta,t) = \sum_{m,n} \frac{\hat\phi_{m,n}(r_s)}{2\pi f_{m,n}}\,\hat\phi_{m,n}(r,\theta-\theta_s)\, e^{-t/\tau_{m,n}} \sin 2\pi f_{m,n}t \]

\(\hat\phi\) 是把模態的大小調成「在整個鼓面上的均方根 = 1」。敲在某個模態的節圓上，那個模態就不會響。敲在正中心，所有 \(m \ge 1\) 的模態都不響（因為 \(J_m(0) = 0\)），只剩圓對稱、像在「呼吸」的 \((0, n)\) 模態。直徑節線卻不一樣：\(m \ge 1\) 的模態都是成對的（\(\cos m\theta\) 與 \(\sin m\theta\)），頻率完全相同，敲下去被激發的永遠是「波峰剛好通過敲擊點」的那個組合。直徑節線會轉個方向躲開鼓棒——躲不掉的只有節圓和中心。

定音鼓

定音鼓的鼓皮一樣，但鼓皮要推動上方的空氣、還有底下銅製鼓腔裡封住的空氣。這個額外的負載讓各模態的頻率降低不同的量。真實定音鼓的實測：\((1,1)\)、\((2,1)\)、\((3,1)\)、\((4,1)\)、\((5,1)\) 的頻率比是 1.00 : 1.50 : 1.98 : 2.44 : 2.94（Fletcher 與 Rossing；Rossing 1982），幾乎就是 2 : 3 : 4 : 5 : 6，像同一個音的第 2 到第 6 泛音。\((1,1)\) 叫做主音（principal tone），\((2,1)\) 比它高五度、\((3,1)\) 幾乎高八度。圓對稱的 \((0, n)\) 模態讓空氣進出鼓腔，能量很快就散掉，主要貢獻剛敲下去的那一聲「咚」，所以這裡沒有放進來。這一頁用實測的比值，配上理想膜的模態形狀。

方形薄板

薄板不是靠張力，而是靠「抗彎曲的硬度」恢復原狀，所以波動方程式不同，頻率和波數的平方成正比。邊長 \(L\)、厚度 \(h\)、四邊簡支的方形鋁板：

\[ w_{m,n} = \sin\frac{m\pi x}{L}\sin\frac{n\pi y}{L}, \qquad f_{m,n} = \frac{\pi}{2}\sqrt{\frac{D}{\rho h}}\;\frac{m^2+n^2}{L^2}, \qquad D = \frac{E h^3}{12(1-\nu^2)} \]

邊長加倍，每個模態都低兩個八度；厚度加倍，高一個八度。\((m, n)\) 與 \((n, m)\) 的頻率相同，敲一下會把它們混成新的圖形——這就是克拉尼圖形的道理，小提琴、吉他的製琴師也用它檢查面板（本站另有克拉尼圖形的實驗）。有些頻率相同純粹是數字的巧合：\(1^2 + 7^2 = 5^2 + 5^2 = 50\)。

音樂上的意義

有音高與沒有音高的鼓

小鼓、大鼓、中鼓在打擊樂譜上不寫音名：它們的模態以非整數比散開，耳朵沒辦法把它們合成一個音高。定音鼓卻寫真正的音符，而且要依樂曲的調來調音。演奏者轉動調音把手或踩踏板改變張力；因為 \(f \propto \sqrt{T}\)，要升高一個五度（3 : 2），張力要變成 \((3/2)^2 = 2.25\) 倍。管弦樂團常用兩個定音鼓，分別調在曲子的主音與屬音，相差四度或五度。

打在哪裡

敲在鼓的正中心，聲音悶而短：只有圓對稱的模態被敲出來。越往鼓邊移動，敲出來的高次模態越多，聲音越亮。定音鼓手敲在中心和鼓邊之間、比較靠近鼓邊的地方，那裡有音高的 \((1,1)\)、\((2,1)\)、\((3,1)\) 都很強；他們也會選軟或硬的鼓槌——軟槌貼在鼓皮上的時間比較長，敲出來的高次模態比較少（這裡沒有模擬）。

觀察重點

  • 不是兩倍：單獨看 \((1,1)\) 模態。它是 \((0,1)\) 的幾倍？永遠不動的線在哪裡？
  • 正中心：在 \(r/a = 0\) 敲一下，和靠近鼓邊敲比一比頻譜。少了哪些長條？哪一個比較亮？
  • 會躲的直徑：單獨看 \((1,1)\)，改變敲擊點的方位角 θ。它的直徑節線怎麼了？
  • 理想膜與定音鼓：在同一點各敲一下，比較長條和虛線的位置，以及「偏離整數倍」的讀數。
  • 方板上的雙胞胎：在方形薄板上比較 \((1,2)\) 和 \((2,1)\) 模態，再敲在對角線上、敲在中線上試試。

計算方法

  • 貝索函數：\(J_m(x) = \frac{1}{2\pi}\int_0^{2\pi}\cos(m t - x\sin t)\,dt\) 用梯形法計算（週期函數取足夠的點，準確到電腦的精度）；零點 \(j_{m,n}\) 先找變號再用二分法。單元測試把 \(J_m\) 和冪級數、數學手冊的數值比對，零點和 Abramowitz 與 Stegun 的表比對到 \(10^{-5}\) 以內，並檢查遞迴關係 \(J_{m-1} + J_{m+1} = (2m/x) J_m\)、模態彼此正交而且正規化（在圓面與方板上做數值積分）、敲在中心只剩 \(m = 0\)、敲在 \((0,2)\) 的節圓上它就消失、定音鼓的比值離 2 : 3 : 4 : 5 : 6 都在 45 音分以內而理想膜不是，以及 \(f \propto \sqrt{T}/a\)、\(f \propto h/L^2\) 的縮放關係。
  • 「偏離整數倍」：每個被敲出來的模態和參考基音 \(f_\mathrm{ref}\) 最接近的整數倍比較（理想膜用 \(f_{0,1}\)、定音鼓用 \(f_{1,1}/2\)、方板用 \(f_{1,1}\)），把相差的音分以振幅加權平均。「頻譜重心」是以振幅加權的平均頻率除以最低模態的頻率。
  • 畫面：鼓面以慢動作畫出（最低模態大約兩秒擺一次，畫面上標示放慢倍數），高度放大示意；各模態的頻率比、形狀、誰先消失都依照公式，只是衰減也放慢了 5 倍。3D 檢視用同一個核心：鼓面是同一個模態疊加，鼓棒落在敲擊點上，單一模態時節線在鼓面上發光。
  • 聲音（近似）：「敲一下」把每個被敲出來的模態用各自的頻率、上面的振幅與衰減時間合成成正弦波。真實的鼓還有鼓棒接觸的時間、各模態把聲音輻射到空氣的效率、鼓身的共鳴，這裡沒有計入。
